# الترجمات
{: #translations }

تُدار الترجمات عبر Crowdin:
<https://crowdin.com/project/sdmaid-se>

تُسحب الترجمات بانتظام قبل نشر تحديثات جديدة للتطبيق. ستُضمَّن النصوص المكتملة على Crowdin تلقائيًا في الإصدارات القادمة.

## الأسئلة والمشكلات
{: #questions--issues }

إذا كانت لديك أسئلة أو وجدت مشكلات، فيُرجى التعليق مباشرةً على النص المعني في Crowdin.  
تمنح التعليقات على النصوص سياقًا، وتسهّل حل مشكلات الترجمة بسرعة.

استخدم بلاغات GitHub فقط لمشكلات الترجمة العامة، وليس للنصوص الفردية.

## الأخطاء الشائعة
{: #common-pitfalls }

**يجب أن تبقى العناصر النائبة دون تغيير**

لا تترجم العناصر النائبة (placeholders) ولا تغيّر ترتيبها.

أمثلة:
- `%s`، `%d`، `%1$s`
- `{0}`، `{name}`
- `$value`

صحيح:
`Delete %s files` ← `Supprimer %s fichiers`

خطأ:
`Supprimer %d fichiers`

**تسلسلات الهروب**

أبقِ تسلسلات الهروب (escape sequences) كما هي تمامًا.

أمثلة:
- `\n` = سطر جديد
- `\t` = مسافة جدولة (tab)
- `\"` = علامة اقتباس داخل النص
- `\\` = شرطة مائلة عكسية

لا تحذفها ولا تكررها.

**الأسطر الجديدة**

إذا كان النص المصدر يحتوي على فواصل أسطر، فأبقِ عليها.

مثال:
`Line1\nLine2`

لا تدمجها في جملة واحدة إلا إذا نصّت إرشادات اللغة على ذلك صراحةً.

**التنسيق والترميز**

لا تُفسد:
- وسوم HTML ‏(`<b>` و`<i>` و`<br>`)
- علامات Markdown
- تنسيق Android ‏(`%1$s` و`&lt;` و`&amp;`)

## اللغات
{: #languages }

تتطلب بعض اللغات خيارات محددة في الصياغة أو التنسيق أو النبرة. راجع الإرشادات الخاصة بكل لغة في هذا الويكي قبل الترجمة للحفاظ على اتساق المصطلحات والأسلوب. إذا لم توجد إرشادات بعد، يمكن للمساهمين اقتراح إرشادات.
