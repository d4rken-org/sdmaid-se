# العثور على الملفات المتبقية (Corpse Finder)
{: #corpse-finder }

تعثر أداة `العثور على الملفات المتبقية` (CorpseFinder) على الملفات التابعة لتطبيقات لم تعد مثبتة.


## مستوى المخاطرة
{: #risklevel }

جميع خيارات مستوى المخاطرة معطّلة افتراضيًا. لا تفعّلها إلا إذا كنت تعرف ما تفعله، وتحقق من النتائج قبل حذف أي شيء.
تفعيل أحد خيارات مستوى المخاطرة يزيد احتمال حذف ملفات لم تكن تريد حذفها.

تنطبق مستويات المخاطرة غالبًا على مواقع القائمة البيضاء، مثل جذر وحدة التخزين العامة (`/storage/emulated/0`). لا يوجد نمط تسمية شائع لمثل هذه المواقع، ولا يستطيع SD Maid تحديد المالك إلا من خلال قاعدة بيانات تُحدَّث يدويًا.


### قم بتضمين البقايا المرغوبة
{: #include-desirable-remnants }

البقايا المرغوبة هي ملفات معروفة المالك لتطبيقات غير مثبتة، لكن SD Maid يضع عليها داخليًا علامة `KEEPER`. عادةً ما تكون هذه ملفات أنشأها المستخدم، مثل الصور التي التقطتها.

### قم بتضمين الأسماء الشائعة
{: #include-common-names }

بعض التطبيقات تستخدم أسماء شائعة جدًا. ربما توجد مئات من تطبيقات تدوين الملاحظات التي تنشئ مجلدًا باسم `/sdcard/Notes` لحفظ البيانات فيه. قد يعرف SD Maid أحد هذه التطبيقات ويكون غير مثبت على هاتفك، لكن SD Maid لا يمكنه التأكد من عدم وجود تطبيق آخر على هاتفك لا يزال يستخدم ذلك المجلد، ولا يعرف SD Maid أن هذا التطبيق يستخدم ذلك المجلد أيضًا. 

## المرشحات
{: #filter }

كل مرشح مسؤول عن منطقة بيانات محددة. بتفعيل أحد المرشحات، ستبحث أداة العثور على الملفات المتبقية في تلك المنطقة الإضافية.

### بطاقة الذاكرة SD
{: #sdcard }

* عادةً المكان الذي يضع فيه المستخدم ملفاته
* وحدة التخزين العامة (المدمجة والقابلة للإزالة على حد سواء)، باستثناء مجلدات فرعية محددة في `Android/data`.
* لا يوجد مخطط تسمية للملفات هنا.

أمثلة:

```bash
/storage/emulated/0/SDMaid
/storage/DEAD-BEEF/SDMaid
/sdcard/SDMaid
```

### الوسائط العامة
{: #public-media }

* تخزّن الوسائط العامة للتطبيقات، مثل الوسائط المستلمة عبر WhatsApp. تُسمّى المجلدات بأسماء حزم التطبيقات.
* مجلد فرعي من وحدة التخزين العامة له معنى خاص لدى نظام التشغيل. 

أمثلة:

```bash
/storage/emulated/0/Android/media/eu.darken.sdmse
/storage/DEAD-BEEF/Android/media/eu.darken.sdmse
/sdcard/Android/media/eu.darken.sdmse
```

### بيانات التطبيق العامة
{: #public-app-data }

* ملفات إضافية للتطبيقات.
* تُسمّى المجلدات بأسماء حزم التطبيقات.
* مجلد فرعي من وحدة التخزين العامة له معنى خاص لدى نظام التشغيل.

أمثلة:

```bash
/storage/emulated/0/Android/data/eu.darken.sdmse
/storage/DEAD-BEEF/Android/data/eu.darken.sdmse
/sdcard/Android/data/eu.darken.sdmse
```

### موارد OBB
{: #obb-resources }

* عادةً ملفات موارد إضافية للألعاب.
* تُسمّى المجلدات والملفات بأسماء حزم التطبيقات.
* مجلد فرعي من وحدة التخزين العامة له معنى خاص لدى نظام التشغيل.

أمثلة:

```bash
/storage/emulated/0/Android/obb/eu.darken.sdmse
/storage/DEAD-BEEF/Android/obb/eu.darken.sdmse
/sdcard/Android/obb/eu.darken.sdmse
```

### بيانات التطبيق الخاصة
{: #private-app-data }

* تُسمّى المجلدات والملفات بأسماء حزم التطبيقات.
* مجلد فرعي من وحدة التخزين العامة له معنى خاص لدى نظام التشغيل.

أمثلة:

```bash
/data/data/eu.darken.sdmse
```

### مخبأ Dalvik
{: #dalvik-cache }

* يخزّن نسخًا محسّنة من شيفرة التطبيقات لتنفيذ أسرع.
* يقع في قسم النظام، وغالبًا تحت مجلدات خاصة بكل معمارية.
* تُسمّى الملفات باستخدام اسم حزمة التطبيق.

أمثلة:

```bash
/data/dalvik-cache/arm64/data@app@eu.darken.sdmse@base.apk@classes.dex
/data/dalvik-cache/arm/data@app@eu.darken.sdmse@base.apk@classes.dex
```

### مكتبات التطبيقات
{: #app-libraries }

* تحتوي على المكتبات الأصلية (native) التي تستخدمها التطبيقات، مثل ملفات `.so`.
* تقع عادةً في مجلد بيانات التطبيق تحت مجلد `lib`.
* تُسمّى الملفات وفقًا للمعمارية ومتطلبات المكتبة.

أمثلة:

```bash
/data/app/eu.darken.sdmse-1/lib/arm64/libexample.so
/data/app/eu.darken.sdmse-2/lib/arm/libexample.so
```

### موارد التطبيق
{: #app-sources }

* تشير إلى ملفات APK التي تُعدّ المصدر البرمجي للتطبيقات.
* تُخزَّن في مجلدات محددة لتطبيقات النظام أو المستخدم أو المصنّع (vendor).
* تُسمّى الملفات باسم حزمة التطبيق وإصداره.

أمثلة:

```bash
/data/app/eu.darken.sdmse-1/base.apk
/system/app/ExampleApp/ExampleApp.apk
```

### موارد التطبيق الخاصة
{: #private-app-sources }

* مشابهة لموارد التطبيق، لكنها مخزّنة في مجلدات محمية لتعزيز الأمان.
* لا يمكن الوصول إليها إلا من قِبل النظام أو التطبيق المعني.
* تُسمّى الملفات باسم حزمة التطبيق.

أمثلة:

```bash
/data/app-private/eu.darken.sdmse/base.apk
```
