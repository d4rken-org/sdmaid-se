# الإحصائيات والسجل
{: #stats-and-history }

يتتبّع SD Maid 2/SE عدد الملفات المحذوفة وإجمالي المساحة التي حُرّرت أثناء عمليات التنظيف. يتيح ذلك للمستخدمين متابعة أثر عمليات التنظيف التي يجرونها بمرور الوقت.

<img src="/assets/images/stats/overview-1.webp" width="150">
<img src="/assets/images/stats/overview-2.webp" width="150">

## الميزات الرئيسية:
{: #key-features }

- **الملفات المحذوفة والمساحة المحرّرة**: يسجّل SD Maid إجمالي عدد الملفات المحذوفة ومقدار مساحة التخزين المحرّرة في كل جلسة تنظيف.
  
- **سجل العمليات**: يمكنك مراجعة سجل العمليات المنفّذة، والذي يُظهر عدد الملفات المتأثرة، ومقدار المساحة المحرّرة، وما إذا كانت العملية ناجحة أو حدث خطأ.

- **سجلات مفصّلة**: لكل مهمة تنظيف، يتوفر سجل مفصّل في قسم **السجل**، يمكن أن يساعد المستخدمين على فهم ما نُظِّف وتحديد أي مشكلات محتملة.

للوصول إلى هذه الميزة، انتقل إلى قسم **السجل** في SD Maid 2/SE.
