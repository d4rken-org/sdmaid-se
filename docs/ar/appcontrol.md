# إدارة التطبيق (AppControl)
{: #appcontrol }
أداة إدارة التطبيق (AppControl) هي وجهتك الشاملة لكل الإجراءات المتعلقة بالتحكم في التطبيقات المثبتة. بعد الفحص ستحصل على قائمة قابلة للبحث بتطبيقاتك المثبتة. لا تُعرض تطبيقات النظام افتراضيًا، ويجب تفعيل ذلك من الإعدادات.
قد لا تتوفر بعض الخيارات (أو لا تكون ممكنة) إلا إذا مُنح SD Maid صلاحيات الجذر (root).

يمكن تنفيذ بعض الإجراءات على عدة تطبيقات، وبعضها على عنصر واحد فقط. لتنفيذ إجراءات على عدة تطبيقات، اضغط مطولًا على أحد التطبيقات ثم اضغط لتحديد تطبيقات إضافية.

## الإجراءات
{: #actions }
لا يمكن الوصول إلى بعض هذه الإجراءات إلا من تفاصيل التطبيق، والتي يمكن فتحها بالضغط على أحد العناصر في القائمة.

### تشغيل التطبيق
{: #run-app }
يشغّل التطبيق، أي نشاطه الأساسي، وهو عادةً الإجراء نفسه الذي ينفّذه المشغّل (launcher) أيضًا.

### إيقاف إجباري
{: #force-stop }
يحاول إيقاف التطبيق إجباريًا. يعمل بأفضل شكل مع الجذر (root) أو ADB/Shizuku، وإلا فإنه يستخدم خدمة إمكانية الوصول.

### تصدير ملف APK
{: #export-apk }
يحاول نسخ ملف `.apk` الخاص بالتطبيق من وحدة التخزين الداخلية الخاصة إلى مجلد التنزيلات في وحدة التخزين العامة. إذا كان التطبيق مشفّرًا، فإن هذا الإجراء يتطلب صلاحية الجذر، أما التطبيقات غير المشفّرة فيمكن تصديرها دون صلاحية الجذر أيضًا.

### تجميد التطبيق
{: #freeze-app }
يتطلب صلاحية الجذر أو ADB/Shizuku. يعطّل التطبيق. لن يكون التطبيق مرئيًا ولن يتمكن من تشغيل نفسه. يجب تفعيله مجددًا كي يعمل. لا تُفقد أي بيانات، ويبقى هذا الوضع قائمًا حتى لو ألغيت تثبيت SD Maid. يستطيع أي تطبيق جيد لتفعيل التطبيقات وتعطيلها تفعيل التطبيقات التي عُطّلت باستخدام SD Maid، والعكس صحيح.

### حذف التطبيق
{: #delete-app }
يحذف التطبيق وبياناته.


## الإعدادات
{: #settings }
### تحديد الأحجام
{: #determine-size }
يمكن تعطيله لتسريع تحميل قائمة التطبيقات. تحديد حجم التطبيق يستغرق وقتًا طويلًا.

### تحديد النشاط
{: #determine-activity }
يمكن تعطيله لتسريع تحميل قائمة التطبيقات. تحديد ما إذا كان التطبيق نشطًا مؤخرًا يستغرق وقتًا طويلًا.
