# منظف النظام (System Cleaner)
{: #system-cleaner }

أداة منظف النظام (SystemCleaner) هي في الأساس محرك بحث متعدد الأغراض. تزحف عبر كل وحدات التخزين التي يمكن الوصول إليها وتطابق الملفات والمجلدات التي تعثر عليها مع مجموعة من المرشحات.

على عكس الأدوات الأخرى مثل العثور على الملفات المتبقية (CorpseFinder) أو منظف التطبيقات (AppCleaner)، فهي لا تعرف شيئًا عن التطبيقات المثبتة. تعمل حصرًا على مسارات الملفات وخصائصها. لهذا السبب لا يمكن تطبيق إلا استثناءات المسارات والأجزاء على منظف النظام.

يُمرَّر أي ملف يُعثر عليه عبر المرشحات المفعّلة، ويُنسب إلى أول مرشح يطابقه.

## الإعدادات
{: #settings }

### المرشحات العامة
{: #general-filters }

تبحث المرشحات العامة **في جميع مناطق التخزين التي يمكن الوصول إليها** عن أنواع معينة من الملفات يمكن أن تظهر في أي مكان على الجهاز.

| المرشح | الوصف |
|--------|-------------|
| **مجلدات فارغة** | المجلدات الفارغة من جميع أنحاء الجهاز. قد تتطلب المجلدات المتداخلة عدة جولات فحص. |
| **لقطات الشّاشة** | لقطات الشاشة الأقدم من عمر قابل للضبط، من تطبيقات ومواقع متعددة. |
| **الملفات المحذوفة** | ملفات في سلال المحذوفات لتطبيقات ومواقع مختلفة، عليها علامة الحذف لكنها لم تُزل نهائيًا بعد. |
| **ملفات APK زائدة** | ملفات التثبيت (APK) التي يكون إصدارها أقدم من إصدار التطبيق المثبت بالفعل أو مساويًا له. |
| **LOST.DIR مجلدات** | ملفات مؤقتة تُنشأ عند نقل البيانات بين أجهزة Android. |
| **ملفات لينكس** | ملفات ومجلدات تُنشأ عند توصيل وحدة التخزين بحاسوب يعمل بنظام Linux. |
| **ملفات ماك** | ملفات ومجلدات تُنشأ عند تصفح وحدة التخزين باستخدام تطبيق Finder من Apple (مثل `.DS_Store`). |
| **ملفات ويندوز** | بيانات قد ينشئها مستكشف ملفات Windows على وحدة التخزين المتصلة (مثل `Thumbs.db`). |
| **صور مصغرة** | معاينات مخزّنة مؤقتًا للصور ومقاطع الفيديو (مثل مجلدات `.thumbnails`). |
| **ملفات النظام المؤقتة** | ملفات مؤقتة متعلقة بالنظام، عادةً ذاكرة تخزين مؤقت قصيرة العمر للعمليات الجارية. |
| **ملفات التحليل** | بيانات متعلقة بالتحليلات وتتبّع الأخطاء. |
| **ملفات الإعلانات** | ملفات أُنشئت للإعلانات أو بواسطتها. |
| **ملفات سجل النظام** | ملفات سجل النظام وخدمات النظام (مثل `*.log`) في مواقع مختلفة. |

### المرشحات المحددة
{: #specific-filters }

تستهدف المرشحات المحددة **مسارات ثابتة ومعروفة** على الجهاز تُخزَّن فيها أنواع معينة من البيانات.

| المرشح | الوصف |
|--------|-------------|
| **بقايا أخطاء النظام** | عند تعطّل العمليات الأصلية (native) فجأة (مثل الألعاب)، تُنشأ هنا ملفات "tombstone". |
| **بيانات الاستخدام** | ملفات متعلقة بإحصائيات استخدام التطبيقات. |
| **سجلات الأخطاء** (ANR) | آثار أحداث "التطبيق لا يستجيب" (Application Not Responding). |
| **ملفات مؤقتة محلية** | ملفات مؤقتة متعلقة بالنظام (مثل تلك الصادرة من Android Studio). |
| **ملفات سجل النظام (datalogger)** | ملفات سجل خاصة بخدمات النظام. |
| **تخزين التنزيل المؤقت** | مجلد ذاكرة تخزين مؤقت في النظام يُستخدم لأغراض مختلفة (مثل تحديثات OTA). |
| **صندوق إسقاط السجل** | منطقة يُسقط فيها النظام ملفات السجل. |
| **ذاكرة تخزين مؤقت للمثبت** | بيانات مخزّنة مؤقتًا متعلقة بالتطبيقات المثبتة، يستخدمها نظام إدارة الحزم في النظام. |
| **المهام الأخيرة** | بيانات متعلقة بسجل المهام في مبدّل المهام في النظام. |

### المرشحات المخصصة
{: #custom-filters }

بالإضافة إلى المرشحات العامة التي يوفرها التطبيق، يمكنك إنشاء مرشحات مخصصة بمعاييرك الخاصة. يمكن إنشاء المرشحات المخصصة من **الإعدادات > منظف النظام > إدارة المرشح المخصص**.

> **تحذير**: قد تكون المرشحات المخصصة محفوفة بالمخاطر. تحقق دائمًا من نتائج الفحص قبل الحذف!

#### المعايير المتاحة
{: #available-criteria }

| المعيار | الوصف |
|-----------|-------------|
| **تسمية الفلتر** | اسم لمرشحك |
| **مناطق البيانات** | مواقع التخزين المراد فحصها (اتركها فارغة لجميع المناطق التي يمكن الوصول إليها) |
| **قيود نوع الملف** | استهداف الملفات أو المجلدات أو الروابط الرمزية (اتركها فارغة للجميع) |
| **معايير المسار** | قواعد لمطابقة مسارات الملفات |
| **استثناءات المسار** | مسارات تُستثنى من المطابقة |
| **معايير الاسم** | قواعد لمطابقة أسماء الملفات |
| **الحجم الأدنى** | مطابقة الملفات الأكبر من هذا فقط |
| **الحجم الأقصى** | مطابقة الملفات الأصغر من هذا فقط |
| **العمر الأدنى** | مطابقة الملفات الأقدم من هذا فقط |
| **العمر الأقصى** | مطابقة الملفات الأحدث من هذا فقط |
| **التعبيرات النمطية للمسار** (Path Regex) | متقدم: تعبيرات نمطية (regex) لمطابقة المسارات |

#### أوضاع معايير المسار
{: #path-criteria-modes }

| الوضع | الوصف | مثال |
|------|-------------|---------|
| **يبدأ بـ** | يبدأ المسار بالكلمة المفتاحية | `Downloads/temp` يطابق `/sdcard/Downloads/temp/file.txt` |
| **يحتوي على** | يتضمن المسار الكلمة المفتاحية | `cache` يطابق `/sdcard/app/cache/data.bin` |
| **ينتهي بـ** | ينتهي المسار بالكلمة المفتاحية | `backup/old` يطابق `/sdcard/backup/old` |
| **يساوي** | يطابق المسار الكلمة المفتاحية تمامًا | `Download/temp` يطابق ذلك المسار بالضبط فقط |

#### أوضاع معايير الاسم
{: #name-criteria-modes }

| الوضع | الوصف | مثال |
|------|-------------|---------|
| **يبدأ بـ** | يبدأ اسم الملف بالكلمة المفتاحية | `temp_` يطابق `temp_file.txt` |
| **يحتوي على** | يتضمن اسم الملف الكلمة المفتاحية | `.bak` يطابق `document.bak.old` |
| **ينتهي بـ** | ينتهي اسم الملف بالكلمة المفتاحية | `.tmp` يطابق `cache.tmp` |
| **يساوي** | يطابق اسم الملف تمامًا | `thumbs.db` يطابق `thumbs.db` فقط |

جميع عمليات المطابقة **غير حساسة لحالة الأحرف** افتراضيًا.

#### مناطق البيانات
{: #data-areas }

المناطق الشائعة التي يمكنك استهدافها:

| المنطقة | الوصف |
|------|-------------|
| **SDCARD** | التخزين الأساسي (الداخلي أو بطاقة SD) |
| **PUBLIC_MEDIA** | مجلدات الوسائط (DCIM وPictures وMusic وغيرها) |
| **PUBLIC_DATA** | بيانات التطبيقات المشتركة |
| **PRIVATE_DATA** | التخزين الخاص بالتطبيقات (يتطلب صلاحية الجذر) |
| **DOWNLOAD_CACHE** | ذاكرة التخزين المؤقت للتنزيلات في النظام (يتطلب صلاحية الجذر) |
| **PORTABLE** | وحدات التخزين القابلة للإزالة (USB/microSD) |

#### نصائح
{: #tips }

- **الأداء**: لا تحدد إلا المعايير الضرورية. كثرة أنماط regex تبطئ الفحص.
- **معايير متعددة**: يجب أن تتطابق جميع المعايير المحددة (منطق AND).
- **الضغط المطوّل**: اضغط مطولًا على العناصر للحصول على خيارات إضافية.
- **الاختبار**: استخدم معاينة الفحص قبل تفعيل الحذف.
- **الاستيراد/التصدير**: يمكن تصدير المرشحات ومشاركتها مع مستخدمين آخرين.

#### الخيارات المهملة
{: #deprecated-options }

خيار `rootOnly` من SD Maid 1 **لم يعد متاحًا**. استخدم **مناطق البيانات** بدلًا منه للتحكم في مواقع التخزين التي تُفحص.
