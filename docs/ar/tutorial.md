# دليل البدء السريع لـ SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

مرحبًا بك في SD Maid 2/SE! اتبع هذه الخطوات البسيطة للبدء:

## 1. **التثبيت وإكمال الإعداد**
{: id="1-install-and-complete-setup" }

- نزّل SD Maid 2/SE وثبّته.
- افتح التطبيق، وسيُرشدك خلال عملية **إعداد أولي**.
  - امنح الأذونات المطلوبة مثل **الوصول إلى التخزين** حتى يتمكن SD Maid من فحص جهازك والعمل عليه.
  - أكمل أي خطوات إعداد إضافية، مثل تفعيل الميزات الاختيارية حسب تفضيلاتك (مثل خدمة إمكانية الوصول وخيارات الجدولة).

## 2. **تشغيل فحص**
{: id="2-run-a-quick-access-scan" }

- بعد اكتمال الإعداد، اضغط على زر الفحص الدائري (أيقونة العدسة المكبّرة) في منتصف الشريط السفلي من لوحة التحكم لبدء فحص على مستوى النظام بالكامل.
- سيفحص SD Maid جهازك بحثًا عن الملفات غير المرغوب فيها، وبيانات التطبيقات المتبقية، وذاكرة التخزين المؤقت للنظام، وغيرها من الملفات غير الضرورية.

## 3. **مراجعة النتائج**
{: id="3-review-the-results" }

- بعد الفحص، سيصنّف SD Maid ما عثر عليه:
  - **منظف التطبيقات** (AppCleaner): يعثر على ملفات التطبيقات المخزّنة مؤقتًا والمتبقية.
  - **العثور على الملفات المتبقية** (CorpseFinder): يكتشف ملفات التطبيقات المُلغى تثبيتها.
  - **منظف النظام** (SystemCleaner): يحدد ملفات النظام التي يمكن إزالتها.

  اضغط على كل قسم لمراجعة التفاصيل، واستبعد أي ملفات تريد الاحتفاظ بها.

## 4. **رتّب جهازك**
{: id="4-tidy-your-device" }

- بعد مراجعة النتائج، اضغط على زر **حذف** لإزالة الملفات غير المرغوب فيها المكتشفة.

## 5. **إعداد الجدولة (اختياري)**
{: id="5-set-up-the-scheduler-optional" }

- لأتمتة عمليات الفحص المنتظمة، استخدم **الجدولة** (Scheduler).
- اضغط على أيقونة **+** لإنشاء جدول، واختر الأدوات (منظف التطبيقات ومنظف النظام وغيرها) التي ستعمل على فترات منتظمة.
