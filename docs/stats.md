# Stats and History

SD Maid 2/SE keeps track of the amount of deleted files and the total space that has been freed during cleanups. This allows users to monitor the impact of their cleanups over time.

<img src="/assets/images/stats/overview-1.webp" width="150">
<img src="/assets/images/stats/overview-2.webp" width="150">

## Key Features:

- **Deleted Files and Freed Space**: SD Maid logs the total number of files deleted and the amount of storage space freed during each cleanup session.
  
- **Operation History**: You can review a history of executed operations, showing how many files were affected, how much space was freed, and whether the operation was successful or if an error occurred.

- **Detailed Logs**: For each cleanup task, a detailed log is available in the **Stats** section, which can help users understand what was cleaned and identify any potential issues.

To access this feature, go to the **Stats** section in SD Maid 2/SE.
