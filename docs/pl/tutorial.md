# Szybki start z SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Witaj w SD Maid 2/SE! Wykonaj te proste kroki, aby zacząć:

## 1. **Zainstaluj aplikację i dokończ konfigurację**
{: id="1-install-and-complete-setup" }

- Pobierz i zainstaluj SD Maid 2/SE.
- Otwórz aplikację, a przeprowadzi cię ona przez proces **wstępnej konfiguracji**.
  - Przyznaj wymagane uprawnienia, takie jak **dostęp do pamięci**, aby SD Maid mógł skanować twoje urządzenie i na nim pracować.
  - Wykonaj dodatkowe kroki konfiguracji, takie jak włączenie opcjonalnych funkcji zgodnie z twoimi preferencjami (np. usługi ułatwień dostępu, opcji harmonogramu).

## 2. **Uruchom skanowanie**
{: id="2-run-a-quick-access-scan" }

- Po zakończeniu konfiguracji dotknij okrągłego przycisku skanowania (ikona lupy) na środku dolnego paska panelu, aby rozpocząć skanowanie całego systemu.
- SD Maid przeskanuje twoje urządzenie w poszukiwaniu śmieci, pozostałości danych aplikacji, systemowej pamięci podręcznej i innych niepotrzebnych plików.

## 3. **Przejrzyj wyniki**
{: id="3-review-the-results" }

- Po skanowaniu SD Maid pogrupuje znaleziska:
  - **Sprzątanie aplikacji** (AppCleaner): znajduje pliki pamięci podręcznej i pozostałości aplikacji.
  - **Wyszukiwanie pozostałości** (CorpseFinder): wykrywa pliki odinstalowanych aplikacji.
  - **Sprzątanie systemu** (SystemCleaner): wskazuje pliki systemowe, które można usunąć.

  Dotknij każdej sekcji, aby przejrzeć szczegóły, i wyklucz pliki, które chcesz zachować.

## 4. **Uporządkuj urządzenie**
{: id="4-tidy-your-device" }

- Po przejrzeniu wyników dotknij przycisku **Usuń**, aby usunąć wykryte śmieci.

## 5. **Skonfiguruj Harmonogram (opcjonalnie)**
{: id="5-set-up-the-scheduler-optional" }

- Aby zautomatyzować regularne skanowanie, użyj **Harmonogramu** (Scheduler).
- Dotknij ikony **+**, aby utworzyć harmonogram, i wybierz, które narzędzia (Sprzątanie aplikacji, Sprzątanie systemu itp.) mają być uruchamiane regularnie.

---

Wszystko gotowe! Po dokończeniu konfiguracji i wykonaniu tych kroków możesz łatwo utrzymywać porządek na urządzeniu za pomocą SD Maid 2/SE.
