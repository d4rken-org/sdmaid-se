# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (inaczej SD Maid 2) to narzędzie do zarządzania plikami na Androida, które specjalizuje się w konserwacji. Jego głównym celem jest zwalnianie miejsca i usuwanie niechcianych danych.

* Dopiero zaczynasz z SD Maid? Zacznij od [samouczka](/pl/tutorial).
* Potrzebujesz pomocy z przyznaniem dostępu? Zobacz [Konfigurację](/pl/setup).
* Masz pytanie? Sprawdź [FAQ](/pl/faq) albo zapytaj na [Discordzie](https://discord.gg/8Fjy6PTfXu) lub w [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Znalazłeś błąd? W sekcji [Błędy](/pl/bugs) dowiesz się, jak go zgłosić i nagrać dziennik debugowania.

## Narzędzia
{: #tools }

* [Sprzątanie aplikacji (AppCleaner)](/pl/appcleaner): usuwa zbędne pliki, np. pamięć podręczną
* [Wyszukiwanie pozostałości (CorpseFinder)](/pl/corpsefinder): usuwa dane należące do aplikacji, które nie są już zainstalowane
* [Sprzątanie systemu (SystemCleaner)](/pl/systemcleaner): konfigurowalne przez użytkownika filtry dla dowolnych plików
* [Analiza pamięci (StorageAnalyzer)](/pl/storageanalyzer): przegląd pamięci
* [Usuwanie duplikatów (Deduplicator)](/pl/deduplicator): znajduje zduplikowane dane
* [Kompresja multimediów (Media Squeeze)](/pl/mediasqueeze): kompresuje zdjęcia i filmy
* [Przesuwacz (Swiper)](/pl/swiper): usuwanie wspomagane przesuwaniem
* [Zarządzanie aplikacjami (AppControl)](/pl/appcontrol): kontroluje i wyłącza aplikacje
* [Harmonogram (Scheduler)](/pl/scheduler): planuje czynności czyszczenia
