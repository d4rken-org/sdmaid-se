# Estatísticas e histórico
{: #stats-and-history }

O SD Maid 2/SE registra a quantidade de arquivos apagados e o espaço total liberado durante as limpezas. Isso permite que os usuários acompanhem o impacto de suas limpezas ao longo do tempo.

<img src="/assets/images/stats/overview-1.webp" width="150">
<img src="/assets/images/stats/overview-2.webp" width="150">

## Principais recursos:
{: #key-features }

- **Arquivos apagados e espaço liberado**: o SD Maid registra o número total de arquivos apagados e a quantidade de espaço de armazenamento liberado em cada sessão de limpeza.
  
- **Histórico de operações**: você pode revisar um histórico das operações executadas, mostrando quantos arquivos foram afetados, quanto espaço foi liberado e se a operação foi bem-sucedida ou se ocorreu um erro.

- **Logs detalhados**: para cada tarefa de limpeza, há um log detalhado disponível na seção **Histórico**, que pode ajudar os usuários a entender o que foi limpo e a identificar possíveis problemas.

Para acessar esse recurso, vá até a seção **Histórico** do SD Maid 2/SE.
