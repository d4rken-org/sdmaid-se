# SD Maid 2/SE
{: #sd-maid-2se }

O SD Maid SE (também conhecido como SD Maid 2) é uma ferramenta de gerenciamento de arquivos para Android especializada em manutenção. Seu objetivo principal é liberar espaço e remover dados indesejados.

* Novo no SD Maid? Comece pelo [tutorial](/pt-br/tutorial).
* Precisa de ajuda para conceder acesso? Veja [Configuração](/pt-br/setup).
* Tem uma pergunta? Consulte as [perguntas frequentes](/pt-br/faq) ou pergunte no [Discord](https://discord.gg/8Fjy6PTfXu) ou nas [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Encontrou um bug? Veja em [Bugs](/pt-br/bugs) como relatá-lo e gravar um log de depuração.

## Ferramentas
{: #tools }

* [Limpador de Aplicativos (AppCleaner)](/pt-br/appcleaner): apaga arquivos dispensáveis, por exemplo caches
* [Localizador de Cadáver (CorpseFinder)](/pt-br/corpsefinder): remove dados que pertencem a aplicativos que não estão mais instalados
* [Limpador do sistema (SystemCleaner)](/pt-br/systemcleaner): filtros configuráveis pelo usuário para arquivos diversos
* [Analisador de Armazenamento (StorageAnalyzer)](/pt-br/storageanalyzer): visão geral do armazenamento
* [Desduplicador (Deduplicator)](/pt-br/deduplicator): encontra dados duplicados
* [Compressor de Mídia (Media Squeeze)](/pt-br/mediasqueeze): comprime fotos e vídeos
* [Deslizador (Swiper)](/pt-br/swiper): exclusão assistida por deslize
* [Gerenciamento de aplicativos (AppControl)](/pt-br/appcontrol): controla e desativa aplicativos
* [Agendador (Scheduler)](/pt-br/scheduler): agenda ações de limpeza
