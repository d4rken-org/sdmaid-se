# Tutorial de início rápido do SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Bem-vindo ao SD Maid 2/SE! Siga estes passos simples para começar:

## 1. **Instale e conclua a configuração**
{: id="1-install-and-complete-setup" }

- Baixe e instale o SD Maid 2/SE.
- Abra o aplicativo, e você será guiado por um processo de **configuração inicial**.
  - Conceda as permissões necessárias, como **acesso ao armazenamento**, para que o SD Maid possa escanear e trabalhar no seu dispositivo.
  - Conclua as etapas adicionais de configuração, como ativar recursos opcionais de acordo com suas preferências (por exemplo, serviço de acessibilidade, opções de agendamento).

## 2. **Faça uma verificação**
{: id="2-run-a-quick-access-scan" }

- Depois de concluir a configuração, toque no botão redondo de escanear (ícone de lupa) no centro da barra inferior do painel para iniciar uma verificação de todo o sistema.
- O SD Maid vai escanear seu dispositivo em busca de arquivos inúteis, dados restantes de aplicativos, caches do sistema e outros arquivos desnecessários.

## 3. **Revise os resultados**
{: id="3-review-the-results" }

- Após a verificação, o SD Maid vai categorizar o que encontrou:
  - **Limpador de Aplicativos (AppCleaner)**: encontra arquivos de cache e arquivos residuais de aplicativos.
  - **Localizador de Cadáver (CorpseFinder)**: detecta arquivos de aplicativos desinstalados.
  - **Limpador do sistema (SystemCleaner)**: identifica arquivos do sistema que podem ser removidos.

  Toque em cada seção para revisar os detalhes e crie exceções para os arquivos que você quiser manter.

## 4. **Arrume seu dispositivo**
{: id="4-tidy-your-device" }

- Depois de revisar os resultados, toque no botão **Apagar** para remover o lixo detectado.

## 5. **Configure o Agendador (opcional)**
{: id="5-set-up-the-scheduler-optional" }

- Para automatizar verificações regulares, use o **Agendador (Scheduler)**.
- Toque no ícone **+** para criar um agendamento, selecionando quais ferramentas (Limpador de Aplicativos, Limpador do sistema etc.) devem ser executadas em intervalos regulares.

---

Agora está tudo pronto! Concluindo a configuração e seguindo estes passos, você pode manter seu dispositivo arrumado facilmente com o SD Maid 2/SE.
