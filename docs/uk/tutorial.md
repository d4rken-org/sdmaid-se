# Посібник швидкого старту для SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Ласкаво просимо до SD Maid 2/SE! Виконайте ці прості кроки, щоб почати:

## 1. **Встановіть і завершіть налаштування**
{: id="1-install-and-complete-setup" }

- Завантажте та встановіть SD Maid 2/SE.
- Відкрийте додаток, і вас буде проведено через процес **початкового налаштування**.
  - Надайте необхідні дозволи, наприклад **доступ до сховища**, щоб SD Maid міг сканувати ваш пристрій і працювати з ним.
  - Виконайте додаткові кроки налаштування, наприклад увімкніть необов'язкові функції відповідно до своїх уподобань (як-от сервіс спеціальних можливостей чи параметри планування).

## 2. **Запустіть сканування**
{: id="2-run-a-quick-access-scan" }

- Коли налаштування завершено, торкніться круглої кнопки сканування (значок лупи) посередині нижньої смуги панелі, щоб запустити сканування всієї системи.
- SD Maid просканує ваш пристрій на наявність непотрібних файлів, залишків даних додатків, системних кешів та інших зайвих файлів.

## 3. **Перегляньте результати**
{: id="3-review-the-results" }

- Після сканування SD Maid розподілить знахідки за категоріями:
  - **Очищувач додатків (AppCleaner)**: знаходить кешовані та залишкові файли додатків.
  - **Пошук рештків (CorpseFinder)**: виявляє файли видалених додатків.
  - **Очищувач системи (SystemCleaner)**: визначає системні файли, які можна видалити.

  Торкніться кожного розділу, щоб переглянути подробиці, і виключіть файли, які хочете зберегти.

## 4. **Наведіть лад на пристрої**
{: id="4-tidy-your-device" }

- Переглянувши результати, торкніться кнопки **Видалити**, щоб прибрати знайдене сміття.

## 5. **Налаштуйте Планувальник (необов'язково)**
{: id="5-set-up-the-scheduler-optional" }

- Щоб автоматизувати регулярні сканування, скористайтеся **Планувальником (Scheduler)**.
- Торкніться значка **+**, щоб створити розклад, і виберіть, які інструменти (Очищувач додатків, Очищувач системи тощо) запускати через регулярні проміжки часу.

---

Тепер усе готово! Завершивши налаштування та виконавши ці кроки, ви зможете легко підтримувати порядок на пристрої за допомогою SD Maid 2/SE.
