# Переклади
{: #translations }

Переклади ведуться через Crowdin:
<https://crowdin.com/project/sdmaid-se>

Переклади регулярно завантажуються перед публікацією нових оновлень додатка. Завершені рядки на Crowdin автоматично потрапляють до наступних випусків.

## Запитання та проблеми
{: #questions--issues }

Якщо у вас є запитання або ви знайшли проблему, залиште коментар безпосередньо до відповідного рядка на Crowdin.  
Коментарі до рядків дають контекст і допомагають швидко вирішувати проблеми з перекладом.

Використовуйте issues на GitHub лише для загальних проблем перекладу, а не для окремих рядків.

## Поширені помилки
{: #common-pitfalls }

**Заповнювачі мають залишатися незмінними**

Не перекладайте заповнювачі та не змінюйте їхній порядок.

Приклади:
- `%s`, `%d`, `%1$s`
- `{0}`, `{name}`
- `$value`

Правильно:
`Delete %s files` → `Supprimer %s fichiers`

Неправильно:
`Supprimer %d fichiers`

**Екранування**

Зберігайте escape-послідовності точно такими, як вони є.

Приклади:
- `\n` = новий рядок
- `\t` = табуляція
- `\"` = лапки всередині рядка
- `\\` = зворотна скісна риска

Не видаляйте та не подвоюйте їх.

**Нові рядки**

Якщо вихідний текст містить розриви рядків, зберігайте їх.

Приклад:
`Line1\nLine2`

Не об'єднуйте їх в одне речення, якщо настанови для мови прямо цього не вимагають.

**Форматування та розмітка**

Не пошкоджуйте:
- HTML-теги (`<b>`, `<i>`, `<br>`)
- Маркери Markdown
- Форматування Android (`%1$s`, `&lt;`, `&amp;`)

## Мови
{: #languages }

Деякі мови потребують особливого добору слів, форматування чи тону. Перед перекладом ознайомтеся з настановами для конкретної мови в цій вікі, щоб термінологія та стиль залишалися послідовними. Якщо настанов ще немає, учасники можуть їх запропонувати.
