# Очищувач системи (SystemCleaner)
{: #system-cleaner }

Очищувач системи (SystemCleaner) по суті є пошуковою системою загального призначення. Він обходить усе доступне сховище та перевіряє знайдені файли й папки за набором фільтрів.

На відміну від інших інструментів, як-от Пошук рештків (CorpseFinder) чи Очищувач додатків (AppCleaner), він нічого не знає про встановлені додатки. Він працює виключно зі шляхами та атрибутами файлів. Саме тому до Очищувача системи можна застосовувати лише винятки шляхів і сегментів.

Кожен знайдений файл проходить через увімкнені фільтри й зараховується до першого фільтра, з яким збігається.

## Налаштування
{: #settings }

### Загальні фільтри
{: #general-filters }

Загальні фільтри шукають **у всіх доступних областях сховища** певні типи файлів, які можуть з'являтися будь-де на пристрої.

| Фільтр | Опис |
|--------|-------------|
| **Порожні папки** | Порожні папки з усього пристрою. Для вкладених папок може знадобитися кілька проходів сканування. |
| **Знімки екрану** | Знімки екрана, старші за налаштований вік, з кількох додатків і розташувань. |
| **Видалені файли** | Файли в кошиках різних додатків і розташувань, позначені для видалення, але ще не видалені остаточно. |
| **Зайві додатки APK** | Інсталяційні файли (APK), версія яких старіша або дорівнює версії вже встановлених додатків. |
| **Папки LOST.DIR** | Тимчасові файли, створені під час передавання даних між пристроями Android. |
| **Файли Linux** | Файли та папки, створені під час підключення сховища до комп'ютера з Linux. |
| **Файли Mac** | Файли та папки, створені під час перегляду сховища в додатку Finder від Apple (наприклад, `.DS_Store`). |
| **Файли Windows** | Дані, які провідник Windows може створювати на підключеному сховищі (наприклад, `Thumbs.db`). |
| **Ескізи зображень** | Кешовані попередні перегляди зображень і відео (наприклад, папки `.thumbnails`). |
| **Тимчасові системні файли** | Тимчасові файли, пов'язані із системою, зазвичай короткочасні кеші для активних операцій. |
| **Файли аналітики** | Дані, пов'язані з аналітикою та відстеженням помилок. |
| **Рекламні файли** | Файли, створені для реклами або рекламою. |
| **Файли системного журналу** | Файли журналів системи та системних служб (наприклад, `*.log`) у різних розташуваннях. |

### Спеціальні фільтри
{: #specific-filters }

Спеціальні фільтри націлені на **фіксовані, відомі шляхи** на пристрої, де зберігаються певні типи даних.

| Фільтр | Опис |
|--------|-------------|
| **Залишки аварійного завершення системи** | Якщо нативні процеси аварійно завершуються (наприклад, ігри), тут створюються файли «tombstone». |
| **Статистика користування** | Файли, пов'язані зі статистикою використання додатків. |
| **Помилки ANR** | Трасування подій «Application Not Responding» (додаток не відповідає). |
| **Локальні тимчасові файли** | Тимчасові файли, пов'язані із системою (наприклад, від Android Studio). |
| **Файли системного журналу (datalogger)** | Файли журналів окремих системних служб. |
| **Завантаження кешу** | Системна папка кешу, що використовується для різних цілей (наприклад, оновлень OTA). |
| **Випадаюче вікно журналу** | Область, куди система скидає файли журналів. |
| **Кеш встановлювача додатків** | Кешовані дані про встановлені додатки, які використовує система керування пакетами. |
| **Нещодавні завдання** | Дані, пов'язані з історією завдань у системному перемикачі завдань. |

### Власні фільтри
{: #custom-filters }

Окрім загальних фільтрів, які надає додаток, можна створювати власні фільтри з власними критеріями. Власні фільтри створюються в розділі **Налаштування > Очищувач системи > Керування власними фільтрами**.

> **Попередження**: власні фільтри можуть бути ризикованими. Завжди перевіряйте результати сканування перед видаленням!

#### Доступні критерії
{: #available-criteria }

| Критерій | Опис |
|-----------|-------------|
| **Мітка** | Назва вашого фільтра |
| **Області даних** | Розташування сховища для сканування (залиште порожнім, щоб сканувати всі доступні області) |
| **Обмеження типів файлів** | Цільові файли, папки або символічні посилання (залиште порожнім для всіх) |
| **Критерії шляху** | Правила зіставлення шляхів до файлів |
| **Винятки** | Шляхи, які слід виключити зі зіставлення |
| **Критерії назви** | Правила зіставлення назв файлів |
| **Мінімальний розмір** | Збігаються лише файли, більші за цей розмір |
| **Максимальний розмір** | Збігаються лише файли, менші за цей розмір |
| **Мінімальний вік** | Збігаються лише файли, старіші за цей вік |
| **Максимальний вік** | Збігаються лише файли, новіші за цей вік |
| **Регулярний вираз шляху** | Для досвідчених: регулярні вирази для зіставлення шляхів |

#### Режими критеріїв шляху
{: #path-criteria-modes }

| Режим | Опис | Приклад |
|------|-------------|---------|
| **Починається з** | Шлях починається з ключового слова | `Downloads/temp` збігається з `/sdcard/Downloads/temp/file.txt` |
| **Містить** | Шлях містить ключове слово | `cache` збігається з `/sdcard/app/cache/data.bin` |
| **Закінчується на** | Шлях закінчується ключовим словом | `backup/old` збігається з `/sdcard/backup/old` |
| **Дорівнює** | Шлях точно збігається з ключовим словом | `Download/temp` збігається лише з цим точним шляхом |

#### Режими критеріїв назви
{: #name-criteria-modes }

| Режим | Опис | Приклад |
|------|-------------|---------|
| **Починається з** | Назва файлу починається з ключового слова | `temp_` збігається з `temp_file.txt` |
| **Містить** | Назва файлу містить ключове слово | `.bak` збігається з `document.bak.old` |
| **Закінчується на** | Назва файлу закінчується ключовим словом | `.tmp` збігається з `cache.tmp` |
| **Дорівнює** | Назва файлу точно збігається | `thumbs.db` збігається лише з `thumbs.db` |

За замовчуванням усі зіставлення **не враховують регістр**.

#### Області даних
{: #data-areas }

Поширені області, на які можна націлитися:

| Область | Опис |
|------|-------------|
| **SDCARD** | Основне сховище (внутрішнє або SD-карта) |
| **PUBLIC_MEDIA** | Медіапапки (DCIM, Pictures, Music тощо) |
| **PUBLIC_DATA** | Спільні дані додатків |
| **PRIVATE_DATA** | Приватне сховище додатків (потребує root) |
| **DOWNLOAD_CACHE** | Системний кеш завантажень (потребує root) |
| **PORTABLE** | Знімне сховище (USB/microSD) |

#### Поради
{: #tips }

- **Продуктивність**: задавайте лише необхідні критерії. Забагато шаблонів регулярних виразів сповільнюють сканування.
- **Кілька критеріїв**: мають збігатися всі задані критерії (логіка «І»).
- **Довге натискання**: довго натисніть на записи, щоб побачити додаткові параметри.
- **Тестування**: скористайтеся попереднім переглядом сканування, перш ніж вмикати видалення.
- **Імпорт/експорт**: фільтри можна експортувати та ділитися ними з іншими користувачами.

#### Застарілі параметри
{: #deprecated-options }

Параметр `rootOnly` із SD Maid 1 **більше не доступний**. Натомість використовуйте **Області даних**, щоб керувати тим, які розташування сховища скануються.
