# Винятки
{: #exclusions }

Функція винятків у SD Maid 2/SE дає змогу визначити окремі папки або файли, які додаток має ігнорувати під час сканування системи та виконання завдань з обслуговування. Це корисно, якщо є дані, які мають залишатися незачепленими процесами додатка. Якщо задати винятки, SD Maid 2/SE пропускатиме ці папки або файли під час таких завдань, як Пошук рештків (CorpseFinder), Очищувач додатків (AppCleaner) та інших функцій керування системою.

Найпростіше додати виняток прямо з результатів. Можна скористатися кнопкою «Виключити» на окремих елементах або довго натиснути чи вибрати кілька записів, а потім вибрати дію «Виключити». Крім того, винятки можна додати вручну в налаштуваннях додатка, вказавши шляхи або шаблони з символами підстановки для більшого контролю.

Винятки можна експортувати та імпортувати з меню. Імпорт винятків підтримується лише між схожими версіями SD Maid. Якщо між версіями імпорту та експорту забагато оновлень, може виникнути помилка. У такому разі можна спробувати імпортувати на старішій версії, а потім знову експортувати винятки.

## Типи
{: #types }

SD Maid підтримує 3 різні типи винятків:

### Винятки додатків
{: #app-exclusions }

Винятки додатків базуються на назві пакета кожного додатка. Їх можна створити за допомогою інструмента Управління додатками (AppControl). Просто виберіть додаток зі списку та скористайтеся відповідною дією `Виключити`.

### Винятки шляхів
{: #path-exclusions }

Винятки шляхів можна створити, вибравши (довгим натисканням) шляхи в інструменті Аналізатор сховища (StorageAnalyzer).

### Винятки сегментів 
{: #segment-exclusions }
Винятки сегментів є різновидом винятків шляхів, які не потребують точного збігу. Сегмент є частиною шляху, наприклад папкою. Шлях `/sdcard/DCIM/Camera` складається з 3 сегментів. Ви можете виключити всі фото з камери як у внутрішньому сховищі (`/storage/emulated/0/DCIM/Camera`), так і в зовнішньому (`/sdcard/DCIM/Camera`), створивши виняток сегментів для `DCIM/Camera`.

Якщо позначити параметр `Дозволити часткові збіги`, можна створити виняток для `DCIM/Cam`, який збігатиметься і з папкою `Cam`, і з папкою `Camera`.

## Інструменти
{: #tools }

Кожен інструмент SD Maid по-своєму бачить дані. Не всі винятки однаково впливають на всі інструменти.

### Пошук рештків
{: #corpsefinder }

Пошук рештків знає, що таке «додаток» і які файли належать додатку. Він враховує всі типи винятків. Створення винятку додатка означає, що всі файли, знайдені Пошуком рештків, які, на його думку, належать виключеному додатку, буде виключено.

Підтримувані типи винятків: `APP`, `PATH`, `SEGMENTS`

### Очищувач системи
{: #systemcleaner }

Очищувач системи (SystemCleaner) працює лише з даними шляхів. Він не знає, що таке «додаток» або які файли належать додатку.

Підтримувані типи винятків: `PATH`, `SEGMENTS`

### Очищувач додатків
{: #appcleaner }

Очищувач додатків враховує всі типи винятків. Винятки можна використовувати, щоб прискорити сканування, якщо є додатки з великою кількістю файлів для сканування.

Підтримувані типи винятків: `APP`, `PATH`, `SEGMENTS`

### Дублікати
{: #deduplicator }

Інструмент «Дублікати» (Deduplicator) не знає, що таке «додатки», і працює лише з даними файлів.

Підтримувані типи винятків: `PATH`, `SEGMENTS`

### Стиснення медіа
{: #media-squeeze }

Стиснення медіа (Media Squeeze) працює лише з даними файлів. Виключені файли не стискаються.

Підтримувані типи винятків: `PATH`, `SEGMENTS`

### Swiper
{: #swiper }

Swiper працює лише з даними файлів. Виключені файли не потрапляють до нових сесій. Довге натискання `Пропустити` під час свайпів виключає поточний файл.

Підтримувані типи винятків: `PATH`, `SEGMENTS`

### Аналізатор сховища
{: #storageanalyzer }

Аналізатор сховища не підтримує винятки, оскільки для обчислення правильних загальних розмірів потрібно сканувати весь вміст.
