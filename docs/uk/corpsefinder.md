# Пошук рештків (CorpseFinder)
{: #corpse-finder }

Інструмент `Пошук рештків` (CorpseFinder) знаходить файли, що належать додаткам, які більше не встановлені.


## Рівень ризику
{: #risklevel }

За замовчуванням усі параметри рівня ризику вимкнені. Вмикайте їх, лише якщо знаєте, що робите, і перш ніж щось видаляти, спочатку перевірте результати.
Увімкнення параметра рівня ризику підвищує ймовірність видалення файлів, які ви не хотіли видаляти.

Рівні ризику здебільшого стосуються місць із білого списку, наприклад кореня вашого загальнодоступного сховища (`/storage/emulated/0`). Такі місця не мають спільної схеми іменування, і SD Maid може визначити власника лише за допомогою бази даних, яка ведеться вручну.


### Включити бажані залишки
{: #include-desirable-remnants }

Бажані залишки є файлами з відомими власниками, які не встановлені, але внутрішньо позначені SD Maid як `KEEPER`. Зазвичай це файли, створені користувачем, наприклад зроблені вами фото.

### Включити загальні назви
{: #include-common-names }

Деякі додатки просто використовують дуже поширені назви. Існують, мабуть, сотні додатків для нотаток, які створюють папку `/sdcard/Notes` для збереження даних. SD Maid може знати один із таких додатків, і він не встановлений на вашому телефоні, але SD Maid не може бути певним, що на телефоні немає іншого додатка, який досі використовує цю папку і про який SD Maid не знає, що він теж її використовує. 

## Фільтр
{: #filter }

Кожен фільтр відповідає за певну область даних. Увімкнувши фільтр, ви змушуєте Пошук рештків шукати і в цій додатковій області.

### SD карта
{: #sdcard }

* Зазвичай місце, куди користувач кладе файли
* Загальнодоступне сховище (як вбудоване, так і знімне), за винятком певних підпапок в `Android/data`.
* Файли тут не мають схеми іменування.

Приклади:

```bash
/storage/emulated/0/SDMaid
/storage/DEAD-BEEF/SDMaid
/sdcard/SDMaid
```

### Загальнодоступні медіафайли
{: #public-media }

* Зберігає загальнодоступні медіафайли додатків, наприклад медіа, отримані через WhatsApp. Папки названо за назвами пакетів додатків.
* Підпапка загальнодоступного сховища, що має особливе значення для ОС. 

Приклади:

```bash
/storage/emulated/0/Android/media/eu.darken.sdmse
/storage/DEAD-BEEF/Android/media/eu.darken.sdmse
/sdcard/Android/media/eu.darken.sdmse
```

### Загальнодоступні дані додатку
{: #public-app-data }

* Додаткові файли додатків.
* Папки названо за назвами пакетів додатків.
* Підпапка загальнодоступного сховища, що має особливе значення для ОС.

Приклади:

```bash
/storage/emulated/0/Android/data/eu.darken.sdmse
/storage/DEAD-BEEF/Android/data/eu.darken.sdmse
/sdcard/Android/data/eu.darken.sdmse
```

### OBB файли ресурсів
{: #obb-resources }

* Зазвичай додаткові файли ресурсів для ігор.
* Папки та файли названо за назвами пакетів додатків.
* Підпапка загальнодоступного сховища, що має особливе значення для ОС.

Приклади:

```bash
/storage/emulated/0/Android/obb/eu.darken.sdmse
/storage/DEAD-BEEF/Android/obb/eu.darken.sdmse
/sdcard/Android/obb/eu.darken.sdmse
```

### Особисті дані додатку
{: #private-app-data }

* Папки та файли названо за назвами пакетів додатків.
* Підпапка загальнодоступного сховища, що має особливе значення для ОС.

Приклади:

```bash
/data/data/eu.darken.sdmse
```

### Dalvik кеш
{: #dalvik-cache }

* Зберігає оптимізовані версії коду додатків для швидшого виконання.
* Розташований у системному розділі, часто в папках для певних архітектур.
* Файли названо за назвою пакета додатка.

Приклади:

```bash
/data/dalvik-cache/arm64/data@app@eu.darken.sdmse@base.apk@classes.dex
/data/dalvik-cache/arm/data@app@eu.darken.sdmse@base.apk@classes.dex
```

### Бібліотеки додатків
{: #app-libraries }

* Містить нативні бібліотеки, які використовують додатки, наприклад файли `.so`.
* Зазвичай розташовані в папці даних додатка, у папці `lib`.
* Файли названо відповідно до архітектури та вимог бібліотеки.

Приклади:

```bash
/data/app/eu.darken.sdmse-1/lib/arm64/libexample.so
/data/app/eu.darken.sdmse-2/lib/arm/libexample.so
```

### Джерела додатку
{: #app-sources }

* Стосується файлів APK, які є джерелом коду додатків.
* Зберігаються в окремих папках для системних, користувацьких або вендорних додатків.
* Файли названо за назвою пакета та версією додатка.

Приклади:

```bash
/data/app/eu.darken.sdmse-1/base.apk
/system/app/ExampleApp/ExampleApp.apk
```

### Приватні джерела додатків
{: #private-app-sources }

* Подібні до джерел додатків, але зберігаються в захищених папках для підвищеної безпеки.
* Доступні лише системі або відповідному додатку.
* Файли названо за назвою пакета додатка.

Приклади:

```bash
/data/app-private/eu.darken.sdmse/base.apk
```
