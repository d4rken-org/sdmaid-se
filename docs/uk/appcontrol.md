# Управління додатками (AppControl)
{: #appcontrol }
Управління додатками (AppControl) є єдиним місцем для всіх дій, пов'язаних із керуванням встановленими додатками. Після сканування ви отримаєте список встановлених додатків із пошуком. Системні додатки за замовчуванням не показуються, це потрібно ввімкнути в налаштуваннях.
Деякі параметри можуть бути доступні (можливі) лише тоді, коли SD Maid отримав права root.

Деякі дії можна виконувати для кількох додатків одночасно, деякі лише для окремих елементів. Щоб виконати дію для кількох додатків, довго натисніть на додаток, а потім торкайтеся інших додатків, щоб вибрати їх.

## Дії
{: #actions }
Деякі з цих дій доступні лише в подробицях додатка, які відкриваються натисканням на запис у списку.

### Запустити додаток
{: #run-app }
Запускає додаток, тобто його основну активність; зазвичай це та сама дія, яку виконав би і лаунчер.

### Примусова зупинка
{: #force-stop }
Намагається примусово зупинити додаток. Найкраще працює з root або ADB/Shizuku, інакше використовує сервіс спеціальних можливостей.

### Експорт APK
{: #export-apk }
Намагається скопіювати файл `.apk` додатка з внутрішнього приватного сховища до папки завантажень вашого загальнодоступного сховища. Якщо додаток зашифрований, ця дія потребує root; незашифровані додатки можна експортувати й без root.

### Заморозити додаток
{: #freeze-app }
Потребує root або ADB/Shizuku. Вимикає додаток. Додаток не буде видно, і він не зможе запуститися сам. Щоб він працював, його потрібно знову ввімкнути. Дані не втрачаються, і цей стан зберігається навіть після видалення SD Maid. Будь-який добрий додаток для вмикання та вимикання додатків може ввімкнути додатки, вимкнені за допомогою SD Maid, і навпаки.

### Видалити додаток
{: #delete-app }
Видаляє додаток і його дані.


## Налаштування
{: #settings }
### Визначення розмірів
{: #determine-size }
Можна вимкнути, щоб прискорити завантаження списку додатків. Визначення розміру додатка займає багато часу.

### Визначення активності
{: #determine-activity }
Можна вимкнути, щоб прискорити завантаження списку додатків. Визначення того, чи був додаток нещодавно активним, займає багато часу.
