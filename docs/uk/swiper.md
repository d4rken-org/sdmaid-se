# Swiper
{: #swiper }

Swiper допомагає розібрати окремі папки швидше, ніж файловий менеджер. Ви переглядаєте файли по одному і свайпом вирішуєте для кожного: зберегти, видалити чи пропустити. Нічого не видаляється, доки ви не переглянете свої рішення та не підтвердите їх.

## Початок сесії
{: #starting-a-session }

1. Відкрийте Swiper з панелі та торкніться `Вибрати папки`. Можна вибрати папки, окремі файли або і те, і інше.
2. За бажанням задайте на картці сесії фільтр типів файлів і порядок сортування.
3. Торкніться `Сканувати`. Пошук у папках виконується з урахуванням усіх підпапок.
4. Торкніться `Почніть прокручувати`.

Сесію можна також створити з [Аналізатора сховища (StorageAnalyzer)](/uk/storageanalyzer): виберіть там елементи та виберіть `Створити сесію Swiper`.

Добре починати з галереї камери, папки Downloads і знімків екрана.

### Типи файлів
{: #file-types }

`Показувати лише ці типи файлів` обмежує сесію зображеннями, відео, аудіо, документами або архівами. Можна також ввести власні розширення, наприклад `apk, apks`. Якщо нічого не позначено, показуються всі файли. Файли зіставляються лише за розширенням.

### Порядок сортування
{: #sort-order }

За замовчуванням файли показуються від найстаріших, за датою останньої зміни. Можна також сортувати від найновіших, за назвою або від найбільших.

Фільтр і порядок сортування не можна змінити після того, як сканування знайшло файли. Щоб змінити їх, почніть нову сесію.

### Сканування всього сховища
{: #scanning-a-whole-storage }

Якщо вибрати верхній рівень сховища, наприклад усе внутрішнє сховище, то до сесії потрапить кожен файл на ньому, зокрема фото та медіафайли додатків. SD Maid попросить підтвердження перед скануванням. Коли згодом ви видалятимете файли з такої сесії, спочатку потрібно буде позначити `Я розумію, що ці файли будуть остаточно видалені.`

## Свайпи
{: #swiping }

| Жест | Дія за замовчуванням |
|---|---|
| Свайп праворуч | Зберігати |
| Свайп ліворуч | Видалити |
| Свайп угору | Пропустити |
| Свайп униз | Скасувати останнє рішення |

Кнопки внизу роблять те саме. Якщо ввімкнено [Змінити напрямок прокручування](#swap-swipe-directions), ліво та право міняються місцями.

* **Пропустити** залишає файл без рішення. Пропущені файли повертаються після решти.
* **Скасувати** повертає назад ваші останні рішення, до 50.
* **Довге натискання на «Пропустити»** виключає файл із майбутніх сканувань Swiper. Це створює [виняток](/uk/exclusions) шляху та прибирає файл із сесії.
* Кнопки на картці відкривають файл в іншому додатку або показують повноекранний перегляд.
* Торкніться мініатюри на стрічці, щоб перейти до цього файлу. Повторний свайп замінює ваше попереднє рішення.

Ви можете вийти будь-коли. Ваші рішення зберігаються разом із сесією, і продовжити можна пізніше. Під час перезапуску SD Maid файли, яких він більше не може знайти, вилучаються із сесії. До того часу сесія може ще містити файли, які було видалено або переміщено чимось іншим.

## Перегляд і видалення
{: #reviewing-and-deleting }

Торкніться `Огляд`, щоб побачити всі рішення. Коли файлів без рішення не залишилося, огляд відкривається сам.

* Змінюйте рішення для кожного файлу окремо або довго натисніть, щоб вибрати кілька файлів одночасно.
* Торкніться файлу, щоб повернутися до нього.
* `Видалити` показує, скільки файлів і скільки місця буде зачеплено та в яких папках, перш ніж щось станеться.

Видалення остаточне. Файли не переміщуються до кошика, і SD Maid не може їх відновити.

Після видалення збережені та видалені файли залишають сесію. Файли без рішення залишаються на потім. Коли нічого не залишилося, сесія видаляється. Якщо деякі файли не вдалося видалити, вони залишаються в сесії, і можна спробувати ще раз.

Видалення сесії лише відкидає ваші рішення. Воно не зачіпає жодних файлів.

### Що варто знати
{: #things-to-know }

* **«Зберігати» діє лише в поточній сесії.** Якщо почати нову сесію для тієї самої папки, збережені файли з'являться знову. Щоб приховати файл назавжди, виключіть його (довге натискання на «Пропустити»).
* **Сесія не підхоплює нові файли.** Файли, додані до папки після сканування, не з'являються. Почніть нову сесію, щоб включити їх.
* **Архіви включають файли APK.**
* **Приховані файли включено.**

## Безкоштовна версія
{: #free-version }

Без оновлення до Pro Swiper обмежено 2 сесіями по 50 файлів кожна. Якщо задано порядок сортування, ви отримаєте перші 50 файлів у цьому порядку.

## Налаштування
{: #settings }

### Змінити напрямок прокручування
{: #swap-swipe-directions }

Свайп ліворуч зберігає, праворуч видаляє. За замовчуванням вимкнено.

### Показати деталі файлу
{: #show-file-details }

Показує на екрані свайпів назву файлу, розмір, дату та папку. За замовчуванням увімкнено.

### Вібровідгук
{: #haptic-feedback }

Вібрує, коли ви зберігаєте або видаляєте файл. За замовчуванням увімкнено.
