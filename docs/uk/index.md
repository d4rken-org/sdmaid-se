# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (також відомий як SD Maid 2) є інструментом керування файлами для Android, що спеціалізується на обслуговуванні пристрою. Його основне призначення полягає у звільненні місця та видаленні непотрібних даних.

* Вперше користуєтеся SD Maid? Почніть із [посібника](/uk/tutorial).
* Потрібна допомога з наданням доступу? Див. [Налаштування](/uk/setup).
* Маєте запитання? Перегляньте [FAQ](/uk/faq) або запитайте в [Discord](https://discord.gg/8Fjy6PTfXu) чи в [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Знайшли помилку? На сторінці [Помилки](/uk/bugs) описано, як про неї повідомити та записати журнал налагодження.

## Інструменти
{: #tools }

* [Очищувач додатків (AppCleaner)](/uk/appcleaner): видаляє непотрібні файли, наприклад кеші
* [Пошук рештків (CorpseFinder)](/uk/corpsefinder): видаляє дані, що належать додаткам, які більше не встановлені
* [Очищувач системи (SystemCleaner)](/uk/systemcleaner): налаштовувані користувачем фільтри для будь-яких файлів
* [Аналізатор сховища (StorageAnalyzer)](/uk/storageanalyzer): огляд сховища
* [Дублікати (Deduplicator)](/uk/deduplicator): знаходить дубльовані дані
* [Стиснення медіа (Media Squeeze)](/uk/mediasqueeze): стискає фото та відео
* [Swiper](/uk/swiper): видалення за допомогою свайпів
* [Управління додатками (AppControl)](/uk/appcontrol): керує додатками та вимикає їх
* [Планувальник (Scheduler)](/uk/scheduler): планує дії з очищення
