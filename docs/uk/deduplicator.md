# Дублікати (Deduplicator)
{: #deduplicator }

Інструмент «Дублікати» (Deduplicator) знаходить на вашому пристрої дубльовані файли: точні копії, а за бажанням і зображення, відео чи аудіо, які схожі на вигляд або на слух. Він групує їх у набори та видаляє всі файли в наборі, крім одного.

Сканування безкоштовне. Видалення потребує оновлення до Pro.

## Методи визначення
{: #detection-methods }

Кожен метод можна ввімкнути в `Налаштування > Дублікати`.

### Контрольна сума вмісту
{: #content-checksum }

За замовчуванням увімкнено. Знаходить файли з абсолютно однаковим вмістом, байт у байт, незалежно від їхніх назв. Це безпечний метод: кожен файл у такому наборі є справжньою копією.

### Хеш сприйняття
{: #perceptual-hash }

За замовчуванням вимкнено. Знаходить зображення, схожі на вигляд, наприклад те саме фото, збережене в іншому форматі чи розмірі або з невеликими змінами. Зображення порівнюються у відтінках сірого, тож зображення, які відрізняються лише кольором, можуть збігатися.

### Медіа-відбиток
{: #media-fingerprint }

За замовчуванням вимкнено. Знаходить відео та аудіофайли, схожі на слух, а також відео без звуку, схожі на вигляд. Порівнюються лише файли приблизно однакової тривалості.

Схожі файли не ідентичні. Серійні знімки, відредаговані версії або копії зі зміненим розміром можуть опинитися в одному наборі. **Перевіряйте набори, знайдені хешем сприйняття або медіа-відбитком, перш ніж їх видаляти.** Для кожного схожого файлу показано, наскільки близько він збігається.

## Що сканується
{: #what-gets-scanned }

За замовчуванням «Дублікати» шукають у всьому доступному сховищі: внутрішньому сховищі, на SD-картах, USB-накопичувачах, в `Android/data` та `Android/media`. `Android/obb` не включено. Пошук можна обмежити в параметрі [Місця пошуку](#search-locations).

Доступ до `Android/data` на Android 13 і новіших потребує [root](/uk/setup#root-access) або [доступу ADB](/uk/setup#shizuku).

Враховуються лише файли, більші за [мінімальний розмір](#minimum-size). За замовчуванням включаються лише поширені типи файлів, див. [Пропускати рідкісні типи файлів](#skip-uncommon-file-types).

## Який файл зберігається
{: #which-file-is-kept }

Під час видалення набору SD Maid зберігає один файл і видаляє решту. Який саме файл буде збережено, визначає стратегія видалення в `Налаштування > Дублікати > Стратегія видалення`.

SD Maid перевіряє правила по черзі. Вирішує перше правило, яке дає однозначного переможця. Перетягуйте правила, щоб змінити їхній порядок, і торкніться правила, щоб змінити його режим.

| Правило | За замовчуванням |
|---|---|
| Тип дубліката | Зберігати точні збіги, а не схожі файли |
| Бажані місця розташування | Зберігати файли в папках, які ви виберете. За замовчуванням папки не задано. |
| Індексація медіа | Зберігати файли, про які знають ваша галерея та інші медіадодатки |
| Місце зберігання | Зберігати файли у внутрішньому сховищі. SD-карти та USB-накопичувачі вважаються зовнішніми. |
| Глибина папки | Зберігати файли в папках меншої вкладеності |
| Дата зміни | Зберігати старіші файли |
| Розмір файлу | Зберігати більші файли |

**Бажані місця розташування** допомагають вибрати, який файл зберегти в межах групи, разом з іншими правилами. Вони не вибирають між групами. У наборі, де є і точні копії, і схожі файли, правило «Тип дубліката» вирішує, яку групу зберегти: за замовчуванням кожен файл у групі схожих файлів видаляється, навіть якщо він у бажаному місці. Наприклад, якщо ваше фото з камери та дві однакові копії зі зміненим розміром із месенджера опинилися в одному наборі, за замовчуванням буде збережено одну копію з месенджера, а оригінал з камери видалено. Перевіряйте такі набори перед видаленням і [виключайте](/uk/exclusions) папки, файли з яких ніколи не можна видаляти.

Неможливо позначити окремий файл як той, що має бути збережений. Щоб зберегти інший файл, змініть стратегію видалення або самостійно виберіть файли для видалення.

Зміна стратегії видалення скидає поточні результати. Після цього проскануйте знову.

## Видалення
{: #deleting }

### Видалення всього набору
{: #deleting-a-whole-set }

Видалення набору зберігає один файл і видаляє **всі інші файли в цьому наборі**. У наборі зі схожими файлами це стосується й файлів, які лише схожі на збережений, а не ідентичні йому.

Перемкніть список результатів на вигляд списку, щоб побачити значок видалення на кожному файлі, який буде видалено разом із цілим набором. Типовий вигляд сітки не показує цих значків.

### Видалення окремих файлів
{: #deleting-individual-files }

Виберіть файли довгим натисканням і видаліть їх. У кожному наборі має залишитися принаймні один файл, якщо ви не ввімкнете [Зробити можливим «Видалити все»](#make-delete-all-possible).

У подробицях набору вигляд `Папки` групує файли за папками. Видалення папки там видаляє дублікати в цій папці. Якщо папка містить усі файли набору, файл, який зберігся б під час видалення всього набору, не видаляється. Якщо ввімкнено [Зробити можливим «Видалити все»](#make-delete-all-possible), у підтвердженні можна видалити їх усі.

### Видалення з панелі
{: #deleting-from-the-dashboard }

Видалення з картки «Дублікати» на панелі видаляє всі файли, крім одного, у кожному наборі після підтвердження. Чи запускає головна кнопка панелі також «Дублікати», задається в розділі [Одним дотиком](#one-tap).

## Винятки
{: #exclusions }

Шляхи, виключені для «Дублікатів» або загалом, не скануються. Виключення набору з результатів виключає кожен файл у ньому, зокрема й той, який мав би бути збережений. Див. [Винятки](/uk/exclusions).

«Дублікати» не можна запускати через [Планувальник](/uk/scheduler).

## Одним дотиком
{: #one-tap }

`Налаштування > Загальні > Інструменти одним дотиком` визначає, чи включають «Дублікати» головна кнопка панелі, ярлик `Сканувати + Видалити` та віджет. За замовчуванням вимкнено. Ярлик і віджет сканують і видаляють без підтвердження, використовуючи вашу стратегію видалення. На панелі `Режим одним дотиком` робить те саме, але якщо результати вже очікують, «Видалити» все одно спочатку запитує підтвердження. Включайте «Дублікати», лише якщо [Контрольна сума вмісту](#content-checksum) є єдиним методом визначення.

## Налаштування
{: #settings }

### Місця пошуку
{: #search-locations }

Папки для пошуку. За замовчуванням усі доступні області. Довге натискання скидає параметр.

### Стратегія видалення
{: #deletion-strategy }

Який файл у наборі зберігається, див. [Який файл зберігається](#which-file-is-kept).

### Зробити можливим «Видалити все»
{: #make-delete-all-possible }

Показує параметри для видалення кожного файлу в наборі, щоб не залишилося жодної копії. За замовчуванням вимкнено.

### Мінімальний розмір
{: #minimum-size }

Пропускати файли, менші за цей розмір. За замовчуванням 512 КБ.

### Пропускати рідкісні типи файлів
{: #skip-uncommon-file-types }

Включати лише поширені зображення, відео, аудіофайли, документи, архіви та APK-файли. За замовчуванням увімкнено. Тип визначається за розширенням файлу.

### Метод визначення
{: #detection-method }

Увімкніть [Контрольна сума вмісту](#content-checksum), [Хеш сприйняття](#perceptual-hash) та [Медіа-відбиток](#media-fingerprint).
