# Statistiche e cronologia
{: #stats-and-history }

SD Maid 2/SE tiene traccia del numero di file eliminati e dello spazio totale liberato durante le pulizie. In questo modo puoi monitorare nel tempo l'effetto delle tue pulizie.

<img src="/assets/images/stats/overview-1.webp" width="150">
<img src="/assets/images/stats/overview-2.webp" width="150">

## Funzioni principali:
{: #key-features }

- **File eliminati e spazio liberato**: SD Maid registra il numero totale di file eliminati e la quantità di spazio di archiviazione liberata in ogni sessione di pulizia.
  
- **Cronologia delle operazioni**: puoi consultare una cronologia delle operazioni eseguite, che mostra quanti file sono stati interessati, quanto spazio è stato liberato e se l'operazione è riuscita o se si è verificato un errore.

- **Log dettagliati**: per ogni attività di pulizia è disponibile un log dettagliato nella sezione **Cronologia (Stats)**, che può aiutarti a capire cosa è stato pulito e a individuare eventuali problemi.

Per accedere a questa funzione, vai alla sezione **Cronologia** in SD Maid 2/SE.
