# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (alias SD Maid 2) è uno strumento di gestione dei file per Android specializzato nella manutenzione. Il suo scopo principale è liberare spazio e rimuovere i dati indesiderati.

* Sei nuovo su SD Maid? Inizia dal [tutorial](/it/tutorial).
* Hai bisogno di aiuto per concedere l'accesso? Consulta [Configurazione](/it/setup).
* Hai una domanda? Consulta le [FAQ](/it/faq) oppure chiedi su [Discord](https://discord.gg/8Fjy6PTfXu) o nelle [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Hai trovato un bug? Consulta [Bug](/it/bugs) per sapere come segnalarlo e registrare un log di debug.

## Strumenti
{: #tools }

* [Pulizia App (AppCleaner)](/it/appcleaner): elimina i file superflui, ad es. le cache
* [Resti delle applicazioni (CorpseFinder)](/it/corpsefinder): rimuove i dati che appartengono ad app non più installate
* [Pulitore di sistema (SystemCleaner)](/it/systemcleaner): filtri configurabili dall'utente per file di ogni tipo
* [StorageAnalyzer](/it/storageanalyzer): panoramica dell'archivio
* [Deduplicatore (Deduplicator)](/it/deduplicator): trova i dati duplicati
* [Media Squeeze](/it/mediasqueeze): comprime foto e video
* [Swiper](/it/swiper): eliminazione assistita con lo scorrimento
* [AppControl](/it/appcontrol): controlla e disattiva le app
* [Pianificazione (Scheduler)](/it/scheduler): pianifica le operazioni di pulizia
