# Tutorial rapido per SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Benvenuto in SD Maid 2/SE! Segui questi semplici passaggi per iniziare:

## 1. **Installa e completa la configurazione**
{: id="1-install-and-complete-setup" }

- Scarica e installa SD Maid 2/SE.
- Apri l'app e verrai guidato attraverso una procedura di **configurazione iniziale**.
  - Concedi i permessi necessari, come l'**accesso all'archivio**, così SD Maid può scansionare e lavorare sul tuo dispositivo.
  - Completa gli eventuali passaggi di configurazione aggiuntivi, come l'attivazione di funzioni facoltative in base alle tue preferenze (ad es. servizio di accessibilità, opzioni di pianificazione).

## 2. **Esegui una scansione**
{: id="2-run-a-quick-access-scan" }

- Una volta completata la configurazione, tocca il pulsante rotondo di scansione (icona della lente d'ingrandimento) al centro della barra inferiore della dashboard per avviare una scansione dell'intero sistema.
- SD Maid scansionerà il tuo dispositivo alla ricerca di file spazzatura, dati residui delle app, cache di sistema e altri file non necessari.

## 3. **Controlla i risultati**
{: id="3-review-the-results" }

- Dopo la scansione, SD Maid suddividerà i risultati in categorie:
  - **Pulizia App (AppCleaner)**: trova i file delle app in cache e residui.
  - **Resti delle applicazioni (CorpseFinder)**: rileva i file delle app disinstallate.
  - **Pulitore di sistema (SystemCleaner)**: individua i file di sistema che possono essere rimossi.

  Tocca ogni sezione per controllare i dettagli ed escludi i file che vuoi conservare.

## 4. **Metti in ordine il tuo dispositivo**
{: id="4-tidy-your-device" }

- Dopo aver controllato i risultati, tocca il pulsante **Elimina** per rimuovere la spazzatura rilevata.

## 5. **Configura la Pianificazione (facoltativo)**
{: id="5-set-up-the-scheduler-optional" }

- Per automatizzare scansioni regolari, usa la **Pianificazione (Scheduler)**.
- Tocca l'icona **+** per creare una pianificazione, selezionando quali strumenti (Pulizia App, Pulitore di sistema, ecc.) eseguire a intervalli regolari.

---

Ora sei pronto! Completando la configurazione e seguendo questi passaggi, puoi mantenere facilmente in ordine il tuo dispositivo con SD Maid 2/SE.
