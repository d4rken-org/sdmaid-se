# Tutoriel de démarrage rapide pour SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Bienvenue dans SD Maid 2/SE ! Suivez ces étapes simples pour commencer :

## 1. **Installer l’appli et terminer la configuration**
{: id="1-install-and-complete-setup" }

- Téléchargez et installez SD Maid 2/SE.
- Ouvrez l’appli : vous serez guidé à travers un processus de **configuration initiale**.
  - Accordez les autorisations requises, comme l’**accès au stockage**, afin que SD Maid puisse analyser votre appareil et y travailler.
  - Terminez les éventuelles étapes de configuration supplémentaires, comme l’activation de fonctionnalités facultatives selon vos préférences (par ex. service d’accessibilité, options de planification).

## 2. **Lancer une analyse**
{: id="2-run-a-quick-access-scan" }

- Une fois la configuration terminée, appuyez sur le bouton rond d’analyse (icône de loupe) au centre de la barre inférieure du tableau de bord pour lancer une analyse de tout le système.
- SD Maid analyse votre appareil à la recherche de fichiers indésirables, de restes de données d’applis, de caches système et d’autres fichiers inutiles.

## 3. **Examiner les résultats**
{: id="3-review-the-results" }

- Après l’analyse, SD Maid classe les résultats par catégorie :
  - **Nettoyeur d’applis (AppCleaner)** : trouve les fichiers d’applis mis en cache et résiduels.
  - **Recherche de cadavres (CorpseFinder)** : détecte les fichiers d’applis désinstallées.
  - **Nettoyeur système (SystemCleaner)** : identifie les fichiers système qui peuvent être supprimés.

  Appuyez sur chaque section pour en examiner les détails, et excluez les fichiers que vous souhaitez conserver.

## 4. **Faire le ménage sur votre appareil**
{: id="4-tidy-your-device" }

- Une fois les résultats examinés, appuyez sur le bouton **Supprimer** pour retirer les fichiers indésirables détectés.

## 5. **Configurer le Programmateur (facultatif)**
{: id="5-set-up-the-scheduler-optional" }

- Pour automatiser des analyses régulières, utilisez le **Programmateur (Scheduler)**.
- Appuyez sur l’icône **+** pour créer une planification, en choisissant les outils (Nettoyeur d’applis, Nettoyeur système, etc.) à exécuter à intervalles réguliers.

---

Vous voilà prêt ! En terminant la configuration et en suivant ces étapes, vous pouvez facilement garder votre appareil propre avec SD Maid 2/SE.
