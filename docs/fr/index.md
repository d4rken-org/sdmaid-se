# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (alias SD Maid 2) est un outil de gestion de fichiers pour Android spécialisé dans la maintenance. Son objectif principal est de libérer de l’espace et de supprimer les données indésirables.

* Vous découvrez SD Maid ? Commencez par le [tutoriel](/fr/tutorial).
* Besoin d’aide pour accorder les accès ? Consultez [Configuration](/fr/setup).
* Une question ? Consultez la [FAQ](/fr/faq), ou posez-la sur [Discord](https://discord.gg/8Fjy6PTfXu) ou dans les [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Vous avez trouvé un bug ? Consultez [Bugs](/fr/bugs) pour savoir comment le signaler et enregistrer un journal de débogage.

## Outils
{: #tools }

* [Nettoyeur d’applis (AppCleaner)](/fr/appcleaner) : supprime les fichiers superflus, par exemple les caches
* [Recherche de cadavres (CorpseFinder)](/fr/corpsefinder) : supprime les données appartenant à des applis qui ne sont plus installées
* [Nettoyeur système (SystemCleaner)](/fr/systemcleaner) : filtres configurables par l’utilisateur pour des fichiers divers
* [Analyseur de mémoire (StorageAnalyzer)](/fr/storageanalyzer) : vue d’ensemble du stockage
* [Déduplicateur (Deduplicator)](/fr/deduplicator) : trouve les données en double
* [Compression des médias (Media Squeeze)](/fr/mediasqueeze) : compresse les photos et les vidéos
* [Balayeur (Swiper)](/fr/swiper) : suppression assistée par balayage
* [Vérificateur d’applis (AppControl)](/fr/appcontrol) : contrôle et désactive des applis
* [Programmateur (Scheduler)](/fr/scheduler) : planifie des actions de nettoyage
