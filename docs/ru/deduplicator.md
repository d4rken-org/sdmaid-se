# Дедупликатор (Deduplicator)
{: #deduplicator }

«Дедупликатор» (Deduplicator) находит на устройстве повторяющиеся файлы: точные копии, а по желанию и изображения, видео или аудио, которые выглядят или звучат похоже. Он объединяет их в наборы и удаляет все файлы набора, кроме одного.

Сканирование бесплатно. Для удаления требуется обновление до полной версии.

## Методы обнаружения
{: #detection-methods }

Каждый метод можно включить в `Настройки > Дедупликатор`.

### Контрольная сумма содержимого
{: #content-checksum }

По умолчанию включено. Находит файлы с полностью одинаковым содержимым, байт в байт, независимо от их имён. Это безопасный метод: каждый файл в таком наборе является настоящей копией.

### Похожее содержимое
{: #perceptual-hash }

По умолчанию выключено. Находит изображения, которые выглядят похоже, например одно и то же фото, сохранённое в другом формате или размере или с небольшими правками. Изображения сравниваются в оттенках серого, поэтому изображения, отличающиеся только цветом, могут совпасть.

### Отпечаток медиа
{: #media-fingerprint }

По умолчанию выключено. Находит видео и аудиофайлы, которые звучат похоже, а также беззвучные видео, которые выглядят похоже. Сравниваются только файлы примерно одинаковой длительности.

Похожие файлы не идентичны. Серийные снимки, отредактированные версии или копии с изменённым размером могут оказаться в одном наборе. **Проверяйте наборы, найденные методами «Похожее содержимое» или «Отпечаток медиа», прежде чем удалять их.** У каждого похожего файла показано, насколько близко он совпадает.

## Что сканируется
{: #what-gets-scanned }

По умолчанию «Дедупликатор» ищет во всём доступном хранилище: внутренней памяти, на SD-картах, USB-накопителях, в `Android/data` и `Android/media`. `Android/obb` не включается. Поиск можно ограничить в разделе [Поиск расположений](#search-locations).

Для доступа к `Android/data` на Android 13 и новее требуется [root](/ru/setup#root-access) или [доступ через ADB](/ru/setup#shizuku).

Учитываются только файлы больше [минимального размера](#minimum-size). По умолчанию включаются только распространённые типы файлов, см. [Пропускать неизвестные типы файлов](#skip-uncommon-file-types).

## Какой файл сохраняется
{: #which-file-is-kept }

При удалении набора SD Maid сохраняет один файл и удаляет остальные. Какой именно файл сохранить, определяет стратегия удаления в `Настройки > Дедупликатор > Стратегия удаления`.

SD Maid проверяет правила по порядку. Решает первое правило, которое даёт однозначного победителя. Перетаскивайте правила, чтобы изменить их порядок, нажмите на правило, чтобы изменить его режим.

| Правило | По умолчанию |
|---|---|
| Тип дубликата | Точные совпадения сохраняются вместо похожих файлов |
| Выбор мест | Сохраняются файлы в выбранных вами папках. По умолчанию папки не заданы. |
| Индексация медиа | Сохраняются файлы, о которых знают галерея и другие медиаприложения |
| Место хранения | Сохраняются файлы во внутренней памяти. SD-карты и USB-накопители считаются внешними. |
| Глубина папки | Сохраняются файлы в папках с меньшей вложенностью |
| Дата изменения | Сохраняются более старые файлы |
| Размер файла | Сохраняются более крупные файлы |

**Выбор мест** помогает выбрать, какой файл сохранить внутри группы, вместе с остальными правилами. Между группами он не выбирает. В наборе, где есть и точные копии, и похожие файлы, то, какая группа сохраняется, решает правило «Тип дубликата»: по умолчанию удаляется каждый файл из группы похожих, даже если он лежит в выбранном месте. Например, если фото с камеры и две одинаковые уменьшенные копии из мессенджера оказались в одном наборе, по умолчанию сохраняется одна копия из мессенджера, а оригинал с камеры удаляется. Проверяйте такие наборы перед удалением и [исключайте](/ru/exclusions) папки, файлы в которых никогда не должны удаляться.

Пометить отдельный файл как тот, который нужно сохранить, нельзя. Чтобы сохранить другой файл, измените стратегию удаления или сами выберите файлы для удаления.

Изменение стратегии удаления сбрасывает текущие результаты. После этого выполните сканирование заново.

## Удаление
{: #deleting }

### Удаление всего набора
{: #deleting-a-whole-set }

При удалении набора сохраняется один файл, а **все остальные файлы этого набора** удаляются. В наборе с похожими файлами сюда входят и файлы, которые лишь похожи на сохраняемый, а не идентичны ему.

Переключите список результатов в режим списка, чтобы увидеть значок удаления у каждого файла, который будет удалён при удалении всего набора. В режиме сетки, который используется по умолчанию, эти значки не показываются.

### Удаление отдельных файлов
{: #deleting-individual-files }

Выделите файлы долгим нажатием и удалите их. В каждом наборе должен остаться хотя бы один файл, если только не включён параметр [Разрешить функцию «Удалить всё»](#make-delete-all-possible).

В подробностях набора вид `Папки` группирует файлы по папкам. Удаление папки там удаляет дубликаты в этой папке. Если в папке находятся все файлы набора, файл, который сохранился бы при удалении всего набора, не трогается. Если включён параметр [Разрешить функцию «Удалить всё»](#make-delete-all-possible), в окне подтверждения можно удалить их все.

### Удаление с главного экрана
{: #deleting-from-the-dashboard }

Удаление с карточки «Дедупликатора» на главном экране после подтверждения удаляет в каждом наборе все файлы, кроме одного. Запускает ли главная кнопка главного экрана также и «Дедупликатор», задаётся в разделе [В одно нажатие](#one-tap).

## Исключения
{: #exclusions }

Пути, исключённые для «Дедупликатора» или в целом, не сканируются. Исключение набора из результатов исключает каждый файл в нём, включая тот, который был бы сохранён. См. [Исключения](/ru/exclusions).

«Дедупликатор» не может запускаться [по расписанию](/ru/scheduler).

## В одно нажатие
{: #one-tap }

`Настройки > Общее > Инструменты в одно нажатие` определяет, включают ли главная кнопка главного экрана, ярлык `Сканирование + Удаление` и виджет «Дедупликатор». По умолчанию выключено. Ярлык и виджет сканируют и удаляют без подтверждения, используя вашу стратегию удаления. На главном экране `Режим одного нажатия` делает то же самое, но если результаты уже ждут, удаление всё равно сначала спросит подтверждение. Включайте «Дедупликатор», только если [Контрольная сумма содержимого](#content-checksum) является единственным методом обнаружения.

## Настройки
{: #settings }

### Поиск расположений
{: #search-locations }

Папки для поиска. По умолчанию все доступные области. Долгое нажатие сбрасывает значение.

### Стратегия удаления
{: #deletion-strategy }

Какой файл набора сохраняется, см. [Какой файл сохраняется](#which-file-is-kept).

### Разрешить функцию «Удалить всё»
{: #make-delete-all-possible }

Показывает параметры для удаления всех файлов набора, так что не остаётся ни одной копии. По умолчанию выключено.

### Минимальный размер
{: #minimum-size }

Пропускать файлы меньше этого размера. По умолчанию 512 КБ.

### Пропускать неизвестные типы файлов
{: #skip-uncommon-file-types }

Включать только распространённые изображения, видео, аудиофайлы, документы, архивы и APK-файлы. По умолчанию включено. Тип определяется по расширению файла.

### Метод обнаружения
{: #detection-method }

Включите [Контрольная сумма содержимого](#content-checksum), [Похожее содержимое](#perceptual-hash) и [Отпечаток медиа](#media-fingerprint).
