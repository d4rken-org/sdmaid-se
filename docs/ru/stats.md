# Статистика и история
{: #stats-and-history }

SD Maid 2/SE отслеживает количество удалённых файлов и общий объём места, освобождённого при очистках. Это позволяет следить за результатом ваших очисток с течением времени.

<img src="/assets/images/stats/overview-2.webp" width="150">

## Основные возможности:
{: #key-features }

- **Удалённые файлы и освобождённое место**: SD Maid записывает общее количество удалённых файлов и объём освобождённого места в каждом сеансе очистки.
  
- **История операций**: вы можете просмотреть историю выполненных операций, где видно, сколько файлов было затронуто, сколько места освобождено и завершилась ли операция успешно или произошла ошибка.

- **Подробные журналы**: для каждой задачи очистки в разделе **История** доступен подробный журнал, который помогает понять, что было очищено, и выявить возможные проблемы.

Чтобы воспользоваться этой функцией, откройте раздел **История** в SD Maid 2/SE.
