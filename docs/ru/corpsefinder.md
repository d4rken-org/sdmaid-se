# Мусор (CorpseFinder)
{: #corpse-finder }

Инструмент `Мусор` (CorpseFinder) находит файлы, принадлежащие приложениям, которые больше не установлены.


## Уровень риска
{: #risklevel }

По умолчанию все параметры уровня риска выключены. Включайте их, только если понимаете, что делаете, и перед удалением чего-либо сначала проверьте результаты.
Включение параметра уровня риска повышает вероятность того, что будут удалены файлы, которые вы удалять не хотели.

Уровни риска в основном относятся к расположениям из белого списка, например к корню вашего общего хранилища (`/storage/emulated/0`). У таких расположений нет общего шаблона именования, и SD Maid может определить владельца только по базе данных, которая ведётся вручную.


### Включать желаемые остатки
{: #include-desirable-remnants }

Желаемые остатки являются файлами с известными владельцами, которые не установлены, но внутренне помечены SD Maid как `KEEPER`. Обычно это файлы, созданные пользователем, например сделанные вами фотографии.

### Включать общие названия
{: #include-common-names }

Некоторые приложения используют очень распространённые названия. Наверняка существуют сотни приложений для заметок, которые создают папку `/sdcard/Notes` для хранения данных. SD Maid может знать одно из таких приложений, и оно может быть не установлено на вашем телефоне, но SD Maid не может быть уверена, что на телефоне нет другого приложения, которое использует эту папку, причём SD Maid не знает, что и это приложение использует эту папку. 

## Фильтр
{: #filter }

Каждый фильтр отвечает за определённую область данных. Включив фильтр, вы заставите инструмент «Мусор» искать и в этой дополнительной области.

### Карта памяти
{: #sdcard }

* Обычно здесь пользователь размещает файлы
* Общее хранилище (как встроенное, так и съёмное), за исключением определённых подпапок в `Android/data`.
* У файлов здесь нет схемы именования.

Примеры:

```bash
/storage/emulated/0/SDMaid
/storage/DEAD-BEEF/SDMaid
/sdcard/SDMaid
```

### Публичные медиафайлы
{: #public-media }

* Хранит общедоступные медиафайлы приложений, например медиафайлы, полученные через WhatsApp. Папки названы по именам пакетов приложений.
* Подпапка общего хранилища, имеющая особое значение для ОС. 

Примеры:

```bash
/storage/emulated/0/Android/media/eu.darken.sdmse
/storage/DEAD-BEEF/Android/media/eu.darken.sdmse
/sdcard/Android/media/eu.darken.sdmse
```

### Публичные данные приложений
{: #public-app-data }

* Дополнительные файлы приложений.
* Папки названы по именам пакетов приложений.
* Подпапка общего хранилища, имеющая особое значение для ОС.

Примеры:

```bash
/storage/emulated/0/Android/data/eu.darken.sdmse
/storage/DEAD-BEEF/Android/data/eu.darken.sdmse
/sdcard/Android/data/eu.darken.sdmse
```

### OBB-файлы ресурсов
{: #obb-resources }

* Обычно дополнительные файлы ресурсов для игр.
* Папки и файлы названы по именам пакетов приложений.
* Подпапка общего хранилища, имеющая особое значение для ОС.

Примеры:

```bash
/storage/emulated/0/Android/obb/eu.darken.sdmse
/storage/DEAD-BEEF/Android/obb/eu.darken.sdmse
/sdcard/Android/obb/eu.darken.sdmse
```

### Приватные данные приложений
{: #private-app-data }

* Папки и файлы названы по именам пакетов приложений.
* Подпапка общего хранилища, имеющая особое значение для ОС.

Примеры:

```bash
/data/data/eu.darken.sdmse
```

### Dalvik кэш
{: #dalvik-cache }

* Хранит оптимизированные версии кода приложений для более быстрого выполнения.
* Находится в системном разделе, часто в папках для конкретной архитектуры.
* Файлы названы по имени пакета приложения.

Примеры:

```bash
/data/dalvik-cache/arm64/data@app@eu.darken.sdmse@base.apk@classes.dex
/data/dalvik-cache/arm/data@app@eu.darken.sdmse@base.apk@classes.dex
```

### Библиотеки приложений
{: #app-libraries }

* Содержит нативные библиотеки, используемые приложениями, например файлы `.so`.
* Обычно находятся в папке данных приложения, в папке `lib`.
* Файлы названы в соответствии с архитектурой и требованиями библиотеки.

Примеры:

```bash
/data/app/eu.darken.sdmse-1/lib/arm64/libexample.so
/data/app/eu.darken.sdmse-2/lib/arm/libexample.so
```

### Источники приложений
{: #app-sources }

* Имеются в виду APK-файлы, которые служат исходным кодом приложений.
* Хранятся в определённых папках для системных, пользовательских или вендорских приложений.
* Файлы названы по имени пакета и версии приложения.

Примеры:

```bash
/data/app/eu.darken.sdmse-1/base.apk
/system/app/ExampleApp/ExampleApp.apk
```

### Приватные источники приложений
{: #private-app-sources }

* Похожи на источники приложений, но хранятся в защищённых папках для повышенной безопасности.
* Доступны только системе или соответствующему приложению.
* Файлы названы по имени пакета приложения.

Примеры:

```bash
/data/app-private/eu.darken.sdmse/base.apk
```
