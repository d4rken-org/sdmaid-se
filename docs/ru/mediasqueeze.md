# Сжатие медиа (Media Squeeze)
{: #media-squeeze }

«Сжатие медиа» (Media Squeeze) сжимает фото и видео, чтобы они занимали меньше места. Вы жертвуете частью качества ради освобождённого места.

**Сжатие необратимо снижает качество, и отменить его нельзя.** Исходный файл заменяется, копия не сохраняется. Перед началом проверьте настройки и предпросмотр.

Сканирование бесплатно. Для сжатия требуется обновление до полной версии.

## Как это работает
{: #how-it-works }

1. Выберите папки для поиска. Расположения по умолчанию нет, выберите, например, папку камеры.
2. Задайте качество сжатия и минимальный возраст.
3. Выполните сканирование. Для каждого результата показаны его размер и ожидаемая экономия.
4. Нажмите на отдельный элемент, выделите несколько долгим нажатием или используйте `Сжать все`. Сначала окно подтверждения покажет общий размер и ожидаемую экономию.

Если в выделении только фото или только видео, кнопка `Сравнение` в окне подтверждения показывает исходную и сжатую версии рядом. Для видео сравнивается один кадр, и сравнение лишь приблизительное.

### Что происходит с файлом
{: #what-happens-to-a-file }

* Он перекодируется в своём же формате: JPEG остаётся JPEG, WebP остаётся WebP, MP4 остаётся MP4.
* Разрешение изображения не меняется, кроме [очень больших фотографий](#compress-very-large-photos).
* У видео перекодируется только видеодорожка с меньшим битрейтом. Аудиодорожка копируется без изменений.
* Дата, местоположение, данные камеры и другие метаданные EXIF фотографий сохраняются. Если SD Maid не может прочитать или сохранить метаданные EXIF фотографии, она оставляет фотографию без изменений.
* Метаданные XMP не сохраняются, например сведения о фотосферах и панорамах или оценки из фоторедакторов.
* Дата изменения файла сохраняется, поэтому галереи продолжают сортировать его на том же месте.
* Если сжатая версия не меньше исходной, оригинал остаётся нетронутым.

Ожидаемая экономия является грубой оценкой на основе типа файла и качества, а не измерением. Фактическая экономия может отличаться.

### Расположения
{: #locations }

«Сжатию медиа» нужен прямой доступ к файлам и доступ на запись в их папки. Root и ADB оно не использует. Некоторые расположения, выбранные через системное средство выбора папок Android, например USB-накопители, использовать нельзя, и они удаляются из выбора.

## Ранее сжатые файлы
{: #previously-compressed-files }

SD Maid запоминает, какие файлы она уже сжала и какие не стали меньше, и пропускает их при последующих сканированиях. Файл распознаётся по содержимому, поэтому это работает и после переименования или перемещения файла. Повторное сжатие файла стоит ещё больше качества и почти ничего не экономит.

История хранится на вашем устройстве и входит в резервную копию настроек SD Maid. После её очистки ранее сжатые файлы снова могут попасть в результаты, если только у них нет маркера EXIF при включённом параметре [Вписать маркер EXIF](#write-exif-marker). Очистка истории не изменяет никакие файлы.

## Фотографии, которые по умолчанию пропускаются
{: #photos-that-are-skipped-by-default }

Некоторые фотографии содержат данные, которые при сжатии сохранить нельзя. SD Maid пропускает их, если обнаруживает такие данные, если только вы не включите соответствующую настройку. Обнаружение неполное: фотографии в форматах, которые оно не распознаёт, сжимаются и теряют эти данные.

* **HDR-фото и фото с данными глубины**: HDR-фото становятся обычными, а портретные фото теряют данные, на которых основано размытие фона.
* **Motion Photos**: неподвижное изображение сохраняется, видеоклип удаляется.
* **Очень большие фотографии** (8192 пикселя и более в ширину или высоту): их ширина и высота уменьшаются вдвое, а при необходимости ещё раз вдвое, пока обе не станут меньше 8192 пикселей. Панорама шириной 20 000 пикселей в итоге будет шириной 5 000 пикселей.

Файлы HEIC, содержащие несколько изображений, пропускаются всегда.

В сводке сканирования подсчитываются фотографии, пропущенные из-за данных HDR или глубины, Motion Photos и очень большого размера, а также недоступные файлы. Файлы, пропущенные потому, что они уже были сжаты, не учитываются, как и многокадровые файлы HEIC, если у них нет также данных HDR или глубины.

## Настройки
{: #settings }

Качество сжатия, места для поиска и минимальный возраст задаются на экране «Сжатия медиа» перед сканированием. Всё остальное находится в `Настройки > Сжатие медиа`.

### Качество сжатия
{: #compression-quality }

По умолчанию 80. Более низкое качество означает меньшие файлы, но худшее изображение. Ниже 40 изображения могут стать непригодными. При 95 и выше экономия невелика.

### Минимальный возраст
{: #minimum-age }

Включать только файлы старше этого возраста. По умолчанию 90 дней, по дате изменения файла.

### Минимальный размер файла
{: #minimum-file-size }

Пропускать файлы меньше этого размера. По умолчанию 512 КБ.

### JPEG
{: #jpeg }

Включать изображения JPEG (`.jpg`, `.jpeg`). По умолчанию включено.

### WebP
{: #webp }

Включать изображения WebP (`.webp`). По умолчанию включено. Анимированные файлы WebP не распознаются и потеряют анимацию.

### HEIC/HEIF
{: #heicheif }

Включать изображения HEIC/HEIF (`.heic`, `.heif`). По умолчанию выключено. Требуется Android 9 или новее. Карты усиления HDR, данные глубины и части Live/Motion Photo для HEIC сохранить нельзя.

### MP4 видео
{: #mp4-video }

Включать видео MP4 (`.mp4`). По умолчанию выключено. Для сжатия видео нужно свободное место примерно 110% от его размера в том же хранилище.

### Сжать HDR & фотографии глубины
{: #compress-hdr--depth-photos }

См. [Фотографии, которые по умолчанию пропускаются](#photos-that-are-skipped-by-default). По умолчанию выключено.

### Сжимать Motion Photos
{: #compress-motion-photos }

Сохраняет неподвижное изображение и удаляет видеоклип. По умолчанию выключено.

### Сжимать очень большие фотографии
{: #compress-very-large-photos }

Включает фотографии шириной или высотой 8192 пикселя и более и уменьшает их разрешение, см. [Фотографии, которые по умолчанию пропускаются](#photos-that-are-skipped-by-default). По умолчанию выключено.

### Пропустить ранее сжатые
{: #skip-previously-compressed }

Пропускать файлы, которые SD Maid уже сжала. По умолчанию включено.

### Вписать маркер EXIF
{: #write-exif-marker }

Добавляет маркер в пользовательский комментарий EXIF фотографии, чтобы SD Maid распознавала её как сжатую даже после очистки истории сжатия. SD Maid проверяет наличие маркера, только пока эта настройка включена. По умолчанию выключено. Применяется только к JPEG и WebP.

### История сжатия
{: #compression-history }

Показывает, сколько файлов в истории. Нажмите, чтобы очистить историю.

## Исключения
{: #exclusions }

«Сжатие медиа» пропускает пути, [исключённые](/ru/exclusions) в целом. Можно также исключать результаты прямо из списка результатов, это влияет только на «Сжатие медиа».

«Сжатие медиа» не может запускаться [по расписанию](/ru/scheduler).
