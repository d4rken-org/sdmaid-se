# Менеджер (AppControl)
{: #appcontrol }
«Менеджер» (AppControl) объединяет в одном месте все действия по управлению установленными приложениями. После сканирования вы получите список установленных приложений с поиском. Системные приложения по умолчанию не показываются, их показ нужно включить в настройках.
Некоторые параметры могут быть доступны (возможны), только если SD Maid получила root-права.

Некоторые действия можно выполнить сразу для нескольких приложений, некоторые только для отдельных элементов. Чтобы выполнить действие для нескольких приложений, нажмите и удерживайте приложение, а затем нажимайте на другие приложения, чтобы выделить их.

## Действия
{: #actions }
Некоторые из этих действий доступны только в сведениях о приложении, которые открываются нажатием на элемент списка.

### Запустить приложение
{: #run-app }
Запускает приложение, то есть его основную активность, обычно то же действие, которое выполнил бы и лаунчер.

### Принудительное завершение
{: #force-stop }
Пытается принудительно остановить приложение. Лучше всего работает с root или ADB/Shizuku, в остальных случаях используется служба специальных возможностей.

### Экспорт APK
{: #export-apk }
Пытается скопировать файл `.apk` приложения из внутреннего закрытого хранилища в папку загрузок вашего общего хранилища. Если приложение зашифровано, для этого действия нужен root, незашифрованные приложения можно экспортировать и без root.

### Заморозить приложение
{: #freeze-app }
Требуется root или ADB/Shizuku. Отключает приложение. Приложение не будет видно и не сможет запуститься само. Чтобы оно снова работало, его нужно включить. Данные не теряются, и это состояние сохраняется, даже если удалить SD Maid. Любое хорошее приложение для включения и отключения приложений может включить приложения, отключённые с помощью SD Maid, и наоборот.

### Удалить приложение
{: #delete-app }
Удаляет приложение и его данные.


## Настройки
{: #settings }
### Определение размеров
{: #determine-size }
Можно отключить, чтобы ускорить загрузку списка приложений. Определение размера приложения занимает много времени.

### Определение активности
{: #determine-activity }
Можно отключить, чтобы ускорить загрузку списка приложений. Определение того, было ли приложение недавно активно, занимает много времени.
