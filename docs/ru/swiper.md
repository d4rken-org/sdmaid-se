# Свайпер (Swiper)
{: #swiper }

«Свайпер» (Swiper) помогает разбирать определённые папки быстрее, чем файловый менеджер. Вы просматриваете файлы по одному и свайпом решаете для каждого: оставить, удалить или пропустить. Ничего не удаляется, пока вы не просмотрите свои решения и не подтвердите их.

## Начало сессии
{: #starting-a-session }

1. Откройте «Свайпер» на главном экране и нажмите `Выберите папки`. Можно выбрать папки, отдельные файлы или и то и другое.
2. При желании задайте на карточке сессии фильтр по типу файлов и порядок сортировки.
3. Нажмите `Сканировать`. Поиск в папках выполняется вместе со всеми подпапками.
4. Нажмите `Начать свайп`.

Сессию также можно создать в инструменте [«Анализ памяти» (StorageAnalyzer)](/ru/storageanalyzer): выделите там элементы и выберите `Создать сессию Свайпер`.

Хорошо начать с фотографий камеры, папки Downloads и снимков экрана.

### Типы файлов
{: #file-types }

`Показывать только эти типы файлов` ограничивает сессию изображениями, видео, аудио, документами или архивами. Можно также ввести собственные расширения, например `apk, apks`. Если ничего не отмечено, показываются все файлы. Файлы сопоставляются только по расширению.

### Порядок сортировки
{: #sort-order }

По умолчанию файлы показываются начиная со старых, по дате последнего изменения. Можно также сортировать сначала новые, по имени или сначала большие.

После того как сканирование нашло файлы, фильтр и порядок сортировки изменить нельзя. Чтобы изменить их, начните новую сессию.

### Сканирование всего хранилища
{: #scanning-a-whole-storage }

Если выбрать верхний уровень хранилища, например всё внутреннее хранилище, в сессию попадут все файлы на нём, включая фотографии и медиафайлы приложений. SD Maid попросит подтверждения перед сканированием. Когда вы позже будете удалять файлы из такой сессии, сначала нужно будет отметить `Я понимаю, что эти файлы будут удалены безвозвратно.`

## Свайпы
{: #swiping }

| Жест | Действие по умолчанию |
|---|---|
| Свайп вправо | Оставить |
| Свайп влево | Удалить |
| Свайп вверх | Пропустить |
| Свайп вниз | Отменить последнее решение |

Кнопки внизу делают то же самое. Если включён параметр [Поменять направление свайпа](#swap-swipe-directions), лево и право меняются местами.

* **Пропустить** оставляет файл без решения. Пропущенные файлы появятся снова после остальных.
* **Отменить** шаг за шагом отменяет ваши последние решения, до 50.
* **Долгое нажатие на «Пропустить»** исключает файл из будущих сканирований «Свайпера». При этом создаётся [исключение](/ru/exclusions) пути, а файл удаляется из сессии.
* Кнопки на карточке открывают файл в другом приложении или показывают полноэкранный предпросмотр.
* Нажмите на миниатюру в ленте, чтобы перейти к этому файлу. Новый свайп заменит ваше прежнее решение.

Выйти можно в любой момент. Ваши решения сохраняются вместе с сессией, и её можно продолжить позже. При перезапуске SD Maid файлы, которые она больше не может найти, удаляются из сессии. До этого момента в сессии могут оставаться файлы, которые были удалены или перемещены чем-то другим.

## Просмотр и удаление
{: #reviewing-and-deleting }

Нажмите `Обзор`, чтобы увидеть все решения. Когда файлов без решения не остаётся, обзор открывается сам.

* Меняйте решения для отдельных файлов или выделите сразу несколько файлов долгим нажатием.
* Нажмите на файл, чтобы вернуться к нему.
* `Удалить` сначала показывает, сколько файлов и сколько места будет затронуто и в каких папках, и только потом что-либо делает.

Удаление необратимо. Файлы не перемещаются в корзину, и SD Maid не может их восстановить.

После удаления оставленные и удалённые файлы покидают сессию. Файлы без решения остаются на потом. Когда ничего не останется, сессия удаляется. Если какие-то файлы не удалось удалить, они остаются в сессии, и можно попробовать ещё раз.

Удаление сессии лишь отбрасывает ваши решения. Сами файлы оно не затрагивает.

### Что нужно знать
{: #things-to-know }

* **«Оставить» действует только в текущей сессии.** Если начать новую сессию для той же папки, оставленные файлы появятся снова. Чтобы скрыть файл навсегда, исключите его (долгое нажатие на «Пропустить»).
* **Сессия не подхватывает новые файлы.** Файлы, добавленные в папку после сканирования, не появятся. Чтобы включить их, начните новую сессию.
* **К архивам относятся и APK-файлы.**
* **Скрытые файлы включаются.**

## Бесплатная версия
{: #free-version }

Без обновления до полной версии «Свайпер» ограничен 2 сессиями по 50 файлов в каждой. Если задан порядок сортировки, вы получите первые 50 файлов в этом порядке.

## Настройки
{: #settings }

### Поменять направление свайпа
{: #swap-swipe-directions }

Свайп влево оставляет, вправо удаляет. По умолчанию выключено.

### Показать сведения о файле
{: #show-file-details }

Показывает на экране свайпов имя файла, размер, дату и папку. По умолчанию включено.

### Тактильный отклик
{: #haptic-feedback }

Вибрация, когда вы оставляете или удаляете файл. По умолчанию включено.
