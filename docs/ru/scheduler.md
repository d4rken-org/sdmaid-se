# Расписание (Scheduler)
{: #scheduler }

Функция **Расписание** (Scheduler) в SD Maid 2 позволяет автоматизировать задачи обслуживания с заданными интервалами, чтобы устройство оставалось оптимизированным без ручных усилий. Она поддерживает несколько инструментов, например **Приложения** (AppCleaner), **Мусор** (CorpseFinder) и **Система** (SystemCleaner), которые можно настроить на запуск через регулярные интервалы или в определённое время.

## Как настроить расписание
{: #how-to-set-up-a-schedule }

1. Откройте **Настройки** и выберите **Расписание**.
2. Нажмите кнопку **+**, чтобы создать новое расписание или управлять существующими.
3. Выберите, какие инструменты (например, **Приложения**, **Мусор**, **Система**) должны запускаться по расписанию.
4. Задайте **Интервал повторения в днях** (например, каждые 3 дня) и **Приблизительное время** выполнения.
5. Включите расписание с помощью переключателя.

## Изменение и удаление расписаний
{: #editing-or-deleting-schedules }

1. Перейдите в настройки **Расписание**, чтобы управлять своими расписаниями.
2. Вы можете изменять существующие расписания, настраивать интервалы или удалять их, если они больше не нужны.

Когда расписание активно, SD Maid будет выполнять выбранные задачи в указанное время.

## Дополнительные параметры
{: #additional-options }

Несколько дополнительных параметров настраиваются через главное меню настроек: `Настройки > Расписание`.

- **Пропуск при низком заряде батареи**: если устройство находится в режиме энергосбережения, запланированные задачи будут пропущены.
- **Пропускать, если не заряжается**: запланированные задачи будут выполняться только во время зарядки устройства, чтобы не разряжать батарею.
- **Команды пост-расписания**: можно задать команды оболочки, которые будут выполнены после завершения запланированных задач.
- **Служба специальных возможностей**: по умолчанию расписание пропускает функции, основанные на службе специальных возможностей, так как они не работают, когда устройство заблокировано. Если включить этот параметр, ничего больше не меняя на устройстве, выполнение по расписанию завершится ошибкой. Поэтому, если вы не уверены в своих действиях, оставьте его выключенным. Это полезно только в особых случаях, например на постоянно включённом устройстве Android TV.

## Устранение неполадок
{: #troubleshooting }

### Расписание не выполняется 
{: #scheduler-is-not-executing }

Различайте два случая: расписание вообще не запускается, или выполненные операции не дают нужного результата. Историю выполнения можно посмотреть в [разделе статистики](/ru/stats) SD Maid. Если расписание выполнилось, но завершилось неудачей, там должна быть ошибка.

Если расписание вообще не запускалось, возможно, система не дала SD Maid запуститься ради экономии заряда. После включения первого расписания вы должны были увидеть сообщение с заголовком «Совет» и действием «Исправить», предлагающее отключить оптимизацию батареи. Если вы случайно закрыли это сообщение, вам придётся вручную зайти в системные настройки SD Maid и проверить, не «оптимизирует» ли система SD Maid.

### Служба специальных возможностей
{: #accessibility-service }
Удаление с помощью службы специальных возможностей, например удаление «недоступных элементов» инструментом «Приложения», не работает через расписание. Когда расписание выполняется, устройство обычно заблокировано. Вы не можете нажимать что-либо на выключенном или заблокированном экране, и SD Maid тоже не может.

По умолчанию расписание не выполняет операции, основанные на службе специальных возможностей. Однако вы можете включить параметр «Служба специальных возможностей» в настройках расписания, если понимаете, что делаете.

Обходные пути: получите root на устройстве (пользовательские и системные приложения) или установите Shizuku (только пользовательские приложения). Любой из этих вариантов позволяет SD Maid выполнять аналогичные операции без использования службы специальных возможностей.
