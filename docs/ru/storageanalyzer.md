# Анализ памяти (StorageAnalyzer)
{: #storage-analyzer }

«Анализ памяти» (StorageAnalyzer) отвечает на вопрос «Что занимает столько места в моём хранилище?»

Он может выглядеть как файловый менеджер, но это не файловый менеджер. Всё отсортировано по размеру, поэтому можно идти по самым большим элементам вглубь, пока не найдёте то, что на самом деле заполняет хранилище.

## Хранилища
{: #storages }

На первом экране показано каждое хранилище вашего устройства:

* **Основное хранилище**: встроенная память устройства, включая приложения и системные данные.
* **Дополнительное хранилище**: обычно съёмная SD-карта.
* **Съёмный накопитель**: например, флешка, подключённая по USB.

На каждой карточке показаны свободное и занятое место, а также то, насколько хранилище изменилось за последние 7 дней, см. [Тренд хранилища](#storage-trend).

## Категории
{: #categories }

При открытии хранилище сканируется, и занятое место разбивается на категории:

* **Приложения**: установленные приложения с их кодом, данными, кэшем и медиафайлами.
* **Пользовательские файлы**: фото, видео, загрузки и любые другие данные, которые не принадлежат конкретному приложению.
* **Системные данные**: операционная система и всё, что не удалось отнести к другим категориям.
* **Другие пользователи**: приложения и файлы других пользователей или рабочих профилей на этом устройстве.

Категории «Системные данные» и «Другие пользователи» есть только у основного хранилища.

### Приложения
{: #apps }

Приложения отсортированы по размеру, и их можно искать по имени. Здесь также могут быть показаны системные приложения вместе с их данными. Для системных приложений без установленного обновления встроенный код приложения считается системными данными. Открыв приложение, вы увидите, на что уходит его место:

* **Код приложения**: само приложение. Это место освобождается при удалении или архивировании приложения.
* **Данные приложений**: данные, настройки и кэш.
* **Медиа приложений**: медиафайлы этого приложения, например полученные в WhatsApp фото.
* **Дополнительные файлы приложения**: данные, которые приложение разместило вне своих папок, например фото или загрузки в папке верхнего уровня.

`Показать настройки` открывает страницу системных настроек приложения.

### Почему цифры не совпадают с настройками Android
{: #why-the-numbers-dont-match-androids-settings }

Категории анализатора не будут в точности совпадать с разбивкой в настройках Android.

**Системные данные** являются тем, что остаётся от занятого места после подсчёта приложений, пользовательских файлов и других пользователей. Туда попадает всё, что SD Maid не может увидеть или отнести к чему-либо: защищённые системные области, хранилища других пользователей, которые не удалось измерить, накладные расходы файловой системы и разница между заявленным и фактическим размером хранилища.

Без разрешений [Инвентарь](/ru/setup#app-inventory) и [Статистика использования](/ru/setup#usage-statistics) приложения невозможно измерить. Тогда занимаемое ими место отображается как системные данные.

## Доступ
{: #access }

Что видит анализатор, зависит от доступа, который есть у SD Maid:

* **Без root** код приложений и закрытые данные приложений показываются только в виде итоговых сумм, и просматривать их содержимое нельзя. На Android 13 и новее для `Android/data` также нужен root или доступ через ADB.
* **С [root](/ru/setup#root-access) или [доступом через ADB](/ru/setup#shizuku)** можно просматривать системные данные. Root также позволяет просматривать код приложений и закрытые данные приложений и полностью измерять других пользователей.
* **Без разрешения «Инвентарь»** файлы нельзя сопоставить с приложениями, которым они принадлежат. Пользовательские файлы тогда показываются только для чтения: размеры видны, но удаление, исключение, создание фильтров и сессий «Свайпера» отключены.

Элементы, к которым у SD Maid нет доступа, при нажатии показывают `Отсутствует прямой доступ`.

Папки с более чем 100 000 элементов только подсчитываются, просматривать их нельзя.

## Действия
{: #actions }

Нажмите на файл, чтобы открыть его в другом приложении. Выделите элементы долгим нажатием, затем:

* **Удалить**: удаляет выделенные элементы после подтверждения. Бесплатно.
* **Исключить**: создаёт [исключение](/ru/exclusions) для выделенных путей. Эти исключения действуют для всех инструментов. Сам анализатор исключения не использует, так как ему нужно видеть всё, чтобы правильно подсчитать итоги.
* **Фильтр**: создаёт для выделенных элементов [пользовательский фильтр инструмента «Система»](/ru/systemcleaner#custom-filters). Требуется обновление до полной версии.
* **Создать сессию Свайпер**: начинает сессию [«Свайпера»](/ru/swiper) с выделенными элементами.

Системные данные и содержимое других пользователей можно только просматривать. Удаление там невозможно.

## Тренд хранилища
{: #storage-trend }

SD Maid записывает свободное место в ваших хранилищах каждые несколько часов и после каждой очистки. `Тренд хранилища` показывает это в виде графика с отметками о том, сколько освободила каждая очистка.

* Карточки хранилищ показывают, насколько изменилось каждое хранилище за последние 7 дней.
* Главный экран показывает общее изменение всех хранилищ или, если хранилище заполняется, оценку оставшихся дней.
* Срок хранения снимков задаётся в `Настройки > История > История хранилища`. По умолчанию 90 дней, максимум 365.

График «Тренд хранилища» требует обновления до полной версии. Изменение за 7 дней на карточках хранилищ и на главном экране, а также оценка оставшихся дней доступны бесплатно.

## Настройки
{: #settings }

### Порог низкого объёма хранилища
{: #low-storage-threshold }

Когда свободное место опускается ниже этого значения, SD Maid считает, что место в хранилище заканчивается. По умолчанию `Автоматически`: 5% от размера хранилища, но не более 2 ГБ.

### Предупреждение о нехватке места
{: #low-space-warning }

Требуется обновление до полной версии. Предупреждает, когда свободное место в основном хранилище достигает порога низкого объёма. При наличии хотя бы 5 дней непрерывной истории оно может предупредить и раньше: когда хранилище, судя по тенденции, достигнет порога в течение 14 дней, а свободного места уже не больше 20% от хранилища, но не более 25 ГБ. По умолчанию выключено.
