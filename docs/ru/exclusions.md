# Исключения
{: #exclusions }

Функция исключений SD Maid 2/SE позволяет указать конкретные папки или файлы, которые приложение должно игнорировать при сканировании системы и задачах обслуживания. Это полезно, если есть данные, которые не должны затрагиваться процессами приложения. Если задать исключения, SD Maid 2/SE будет пропускать эти папки или файлы в таких задачах, как «Мусор» (CorpseFinder), «Приложения» (AppCleaner), и в других функциях управления системой.

Проще всего добавить исключение прямо из результатов. Можно нажать кнопку «Исключить» у отдельного элемента или долгим нажатием выделить несколько элементов, а затем выбрать действие «Исключить». Кроме того, исключения можно добавить вручную в настройках приложения, указав пути или шаблоны с подстановочными знаками для более точного контроля.

Исключения можно экспортировать и импортировать через меню. Импорт исключений поддерживается только между близкими версиями SD Maid. Если между версиями импорта и экспорта слишком много обновлений, может возникнуть ошибка. В этом случае можно попробовать импортировать их в более раннюю версию, а затем снова экспортировать исключения.

## Типы
{: #types }

SD Maid поддерживает 3 разных типа исключений:

### Исключения приложений
{: #app-exclusions }

Исключения приложений основаны на имени пакета каждого приложения. Их можно создать в инструменте «Менеджер» (AppControl). Просто выберите приложение в списке и используйте соответствующее действие `Исключить`.

### Исключения путей
{: #path-exclusions }

Исключения путей можно создать, выделив (долгим нажатием) пути в инструменте «Анализ памяти» (StorageAnalyzer).

### Исключения сегментов 
{: #segment-exclusions }
Исключения сегментов являются разновидностью исключений путей, которой не требуется точное совпадение. Сегментом называется часть пути, например папка. Путь `/sdcard/DCIM/Camera` состоит из 3 сегментов. Можно исключить все снимки камеры как во внутреннем хранилище (`/storage/emulated/0/DCIM/Camera`), так и во внешнем (`/sdcard/DCIM/Camera`), создав исключение сегмента для `DCIM/Camera`.

Если отметить параметр `Разрешить частичное совпадение`, можно создать исключение для `DCIM/Cam`, которое совпадёт и с папкой `Cam`, и с папкой `Camera`.

## Инструменты
{: #tools }

Каждый инструмент SD Maid видит данные по-своему. Не все исключения одинаково влияют на все инструменты.

### Мусор
{: #corpsefinder }

Инструмент «Мусор» знает, что такое «приложение» и какие файлы принадлежат приложению. Он учитывает все типы исключений. Если создать исключение приложения, все найденные инструментом «Мусор» файлы, которые, по его мнению, принадлежат исключённому приложению, будут исключены.

Поддерживаемые типы исключений: `APP`, `PATH`, `SEGMENTS`

### Система
{: #systemcleaner }

Инструмент «Система» (SystemCleaner) работает только с путями. Он не знает, что такое «приложение» и какие файлы принадлежат приложению.

Поддерживаемые типы исключений: `PATH`, `SEGMENTS`

### Приложения
{: #appcleaner }

Инструмент «Приложения» учитывает все типы исключений. С помощью исключений можно ускорить сканирование, если есть приложения с большим количеством файлов.

Поддерживаемые типы исключений: `APP`, `PATH`, `SEGMENTS`

### Дедупликатор
{: #deduplicator }

Инструмент «Дедупликатор» (Deduplicator) не знает, что такое «приложения», и работает только с файлами.

Поддерживаемые типы исключений: `PATH`, `SEGMENTS`

### Сжатие медиа
{: #media-squeeze }

«Сжатие медиа» (Media Squeeze) работает только с файлами. Исключённые файлы не сжимаются.

Поддерживаемые типы исключений: `PATH`, `SEGMENTS`

### Свайпер
{: #swiper }

«Свайпер» (Swiper) работает только с файлами. Исключённые файлы не попадают в новые сеансы. Долгое нажатие на `Пропустить` во время свайпа исключает текущий файл.

Поддерживаемые типы исключений: `PATH`, `SEGMENTS`

### Анализ памяти
{: #storageanalyzer }

«Анализ памяти» не поддерживает исключения, так как для расчёта правильных общих размеров нужно просканировать всё содержимое.
