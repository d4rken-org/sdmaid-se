# Переводы
{: #translations }

Переводы ведутся через Crowdin:
<https://crowdin.com/project/sdmaid-se>

Переводы регулярно загружаются перед публикацией новых обновлений приложения. Завершённые строки на Crowdin автоматически попадут в ближайшие выпуски.

## Вопросы и проблемы
{: #questions--issues }

Если у вас есть вопросы или вы нашли проблему, оставьте комментарий прямо к нужной строке в Crowdin.  
Комментарии к строкам дают контекст и помогают быстрее решать проблемы с переводом.

Используйте GitHub issues только для общих проблем перевода, а не для отдельных строк.

## Частые ошибки
{: #common-pitfalls }

**Заполнители должны оставаться без изменений**

Не переводите заполнители и не меняйте их порядок.

Примеры:
- `%s`, `%d`, `%1$s`
- `{0}`, `{name}`
- `$value`

Правильно:
`Delete %s files` → `Supprimer %s fichiers`

Неправильно:
`Supprimer %d fichiers`

**Экранирование**

Сохраняйте escape-последовательности в точности как есть.

Примеры:
- `\n` = перевод строки
- `\t` = табуляция
- `\"` = кавычка внутри строки
- `\\` = обратная косая черта

Не удаляйте и не удваивайте их.

**Переводы строк**

Если в исходном тексте есть переводы строк, сохраняйте их.

Пример:
`Line1\nLine2`

Не объединяйте текст в одно предложение, если только руководство для языка прямо этого не требует.

**Форматирование и разметка**

Не нарушайте:
- HTML-теги (`<b>`, `<i>`, `<br>`)
- маркеры Markdown
- форматирование Android (`%1$s`, `&lt;`, `&amp;`)

## Языки
{: #languages }

Для некоторых языков нужны особые формулировки, форматирование или выбор тона. Перед переводом ознакомьтесь с руководствами для конкретного языка в этой вики, чтобы терминология и стиль оставались единообразными. Если руководства ещё нет, участники могут его предложить.
