# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (также известная как SD Maid 2) является инструментом для управления файлами на Android, специализирующимся на обслуживании устройства. Её главная задача: освобождать место и удалять ненужные данные.

* Впервые пользуетесь SD Maid? Начните с [руководства](/ru/tutorial).
* Нужна помощь с выдачей доступа? См. раздел [Настройка](/ru/setup).
* Есть вопрос? Загляните в [FAQ](/ru/faq) или спросите в [Discord](https://discord.gg/8Fjy6PTfXu) или в [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Нашли ошибку? В разделе [Ошибки](/ru/bugs) описано, как сообщить о ней и записать журнал отладки.

## Инструменты
{: #tools }

* [Приложения (AppCleaner)](/ru/appcleaner): удаляет расходуемые файлы, например кэш
* [Мусор (CorpseFinder)](/ru/corpsefinder): удаляет данные, принадлежащие приложениям, которые больше не установлены
* [Система (SystemCleaner)](/ru/systemcleaner): настраиваемые пользователем фильтры для произвольных файлов
* [Анализ памяти (StorageAnalyzer)](/ru/storageanalyzer): обзор хранилища
* [Дедупликатор (Deduplicator)](/ru/deduplicator): находит повторяющиеся данные
* [Сжатие медиа (Media Squeeze)](/ru/mediasqueeze): сжимает фото и видео
* [Свайпер (Swiper)](/ru/swiper): удаление с помощью свайпов
* [Менеджер (AppControl)](/ru/appcontrol): управляет приложениями и отключает их
* [Расписание (Scheduler)](/ru/scheduler): планирует действия по очистке
