# Система (SystemCleaner)
{: #system-cleaner }

Инструмент «Система» (SystemCleaner) по сути является универсальной поисковой системой. Он обходит всё доступное хранилище и сопоставляет найденные файлы и папки с набором фильтров.

В отличие от других инструментов, таких как «Мусор» (CorpseFinder) или «Приложения» (AppCleaner), он ничего не знает об установленных приложениях. Он работает исключительно с путями и атрибутами файлов. Поэтому к инструменту «Система» можно применять только исключения путей и сегментов.

Каждый найденный файл проходит через включённые фильтры и относится к первому фильтру, которому он соответствует.

## Настройки
{: #settings }

### Общие фильтры
{: #general-filters }

Общие фильтры ищут **во всех доступных областях хранилища** определённые типы файлов, которые могут появиться в любом месте устройства.

| Фильтр | Описание |
|--------|-------------|
| **Пустые папки** | Пустые папки по всему устройству. Для вложенных папок может потребоваться несколько проходов сканирования. |
| **Снимки экрана** | Снимки экрана старше настраиваемого возраста из разных приложений и мест. |
| **Мусор** (Trashed files) | Файлы в корзинах разных приложений и мест, помеченные для удаления, но ещё не удалённые окончательно. |
| **Лишние APK-файлы** | Установочные файлы (APK), версия которых старше или равна версии уже установленного приложения. |
| **Папки LOST.DIR** | Временные файлы, создаваемые при передаче данных между Android-устройствами. |
| **Файлы Linux** | Файлы и папки, создаваемые при подключении хранилища к компьютеру с Linux. |
| **Файлы Mac** | Файлы и папки, создаваемые при просмотре хранилища в приложении Finder от Apple (например, `.DS_Store`). |
| **Файлы Windows** | Данные, которые проводник Windows может создавать на подключённом хранилище (например, `Thumbs.db`). |
| **Эскизы изображений** | Кэшированные превью изображений и видео (например, папки `.thumbnails`). |
| **Временные системные файлы** | Временные файлы, связанные с системой, обычно недолговечный кэш для текущих операций. |
| **Файлы аналитики** | Данные, связанные с аналитикой и отслеживанием ошибок. |
| **Файлы рекламы** | Файлы, созданные для рекламы или самой рекламой. |
| **Файлы системного журнала** | Файлы журналов системы и системных служб (например, `*.log`) в разных местах. |

### Особые фильтры
{: #specific-filters }

Особые фильтры нацелены на **фиксированные, известные пути** на устройстве, где хранятся определённые типы данных.

| Фильтр | Описание |
|--------|-------------|
| **Остатки сбоя системы** | Если нативные процессы аварийно завершаются (например, игры), здесь создаются файлы «tombstone». |
| **Статистика использования** | Файлы, связанные со статистикой использования приложений. |
| **Ошибки ANR** | Трассировки событий «Application Not Responding» («Приложение не отвечает»). |
| **Локальные временные файлы** | Временные файлы, связанные с системой (например, от Android Studio). |
| **Системные журналы** (datalogger) | Файлы журналов отдельных системных служб. |
| **Кэш загрузок** | Системная папка кэша, используемая для разных целей (например, для OTA-обновлений). |
| **Расположение журналов** | Область, куда система складывает файлы журналов. |
| **Кэш установщика** | Кэшированные данные об установленных приложениях, используемые системным менеджером пакетов. |
| **Недавние задачи** | Данные, связанные с историей задач в системном переключателе задач. |

### Пользовательские фильтры
{: #custom-filters }

Помимо общих фильтров, которые предоставляет приложение, вы можете создавать пользовательские фильтры с собственными критериями. Пользовательские фильтры создаются в разделе **Настройки > Система > Управление пользовательскими фильтрами**.

> **Внимание**: применение пользовательских фильтров может быть рискованным. Всегда проверяйте результаты сканирования перед удалением!

#### Доступные критерии
{: #available-criteria }

| Критерий | Описание |
|-----------|-------------|
| **Метка фильтра** | Название вашего фильтра |
| **Области данных** | Места хранения для сканирования (оставьте пустым для всех доступных областей) |
| **Ограничения типов файлов** | Целевые файлы, папки или символические ссылки (оставьте пустым для всех) |
| **Критерии пути** | Правила сопоставления путей к файлам |
| **Исключения** (путей) | Пути, исключаемые из сопоставления |
| **Критерии имени** | Правила сопоставления имён файлов |
| **Минимальный размер** | Совпадают только файлы больше этого размера |
| **Максимальный размер** | Совпадают только файлы меньше этого размера |
| **Минимальный возраст** | Совпадают только файлы старше этого возраста |
| **Максимальный возраст** | Совпадают только файлы новее этого возраста |
| **Path Regex** (регулярные выражения пути) | Для опытных: регулярные выражения для сопоставления путей |

#### Режимы критериев пути
{: #path-criteria-modes }

| Режим | Описание | Пример |
|------|-------------|---------|
| **Начинается с** | Путь начинается с ключевого слова | `Downloads/temp` совпадает с `/sdcard/Downloads/temp/file.txt` |
| **Содержит** | Путь содержит ключевое слово | `cache` совпадает с `/sdcard/app/cache/data.bin` |
| **Заканчивается на** | Путь заканчивается ключевым словом | `backup/old` совпадает с `/sdcard/backup/old` |
| **Соответствует** | Путь в точности равен ключевому слову | `Download/temp` совпадает только с этим точным путём |

#### Режимы критериев имени
{: #name-criteria-modes }

| Режим | Описание | Пример |
|------|-------------|---------|
| **Начинается с** | Имя файла начинается с ключевого слова | `temp_` совпадает с `temp_file.txt` |
| **Содержит** | Имя файла содержит ключевое слово | `.bak` совпадает с `document.bak.old` |
| **Заканчивается на** | Имя файла заканчивается ключевым словом | `.tmp` совпадает с `cache.tmp` |
| **Соответствует** | Имя файла в точности совпадает | `thumbs.db` совпадает только с `thumbs.db` |

По умолчанию всё сопоставление выполняется **без учёта регистра**.

#### Области данных
{: #data-areas }

Распространённые области, на которые можно нацелиться:

| Область | Описание |
|------|-------------|
| **SDCARD** | Основное хранилище (внутреннее или SD-карта) |
| **PUBLIC_MEDIA** | Папки медиафайлов (DCIM, Pictures, Music и т. д.) |
| **PUBLIC_DATA** | Общие данные приложений |
| **PRIVATE_DATA** | Закрытое хранилище приложений (требуется root) |
| **DOWNLOAD_CACHE** | Системный кэш загрузок (требуется root) |
| **PORTABLE** | Съёмное хранилище (USB/microSD) |

#### Советы
{: #tips }

- **Производительность**: задавайте только необходимые критерии. Слишком большое число регулярных выражений замедляет сканирование.
- **Несколько критериев**: должны совпасть все заданные критерии (логика И).
- **Долгое нажатие**: долгое нажатие на записи открывает дополнительные параметры.
- **Проверка**: используйте предпросмотр сканирования, прежде чем включать удаление.
- **Импорт/экспорт**: фильтры можно экспортировать и делиться ими с другими пользователями.

#### Устаревшие параметры
{: #deprecated-options }

Параметр `rootOnly` из SD Maid 1 **больше недоступен**. Вместо него используйте **Области данных**, чтобы управлять тем, какие места хранения сканируются.
