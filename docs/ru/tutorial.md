# Краткое руководство по SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Добро пожаловать в SD Maid 2/SE! Чтобы начать, выполните эти простые шаги:

## 1. **Установите приложение и завершите настройку**
{: id="1-install-and-complete-setup" }

- Скачайте и установите SD Maid 2/SE.
- Откройте приложение, и оно проведёт вас через **первоначальную настройку**.
  - Выдайте необходимые разрешения, например **доступ к хранилищу**, чтобы SD Maid могла сканировать ваше устройство и работать с ним.
  - Выполните дополнительные шаги настройки, например включите необязательные функции по своему усмотрению (служба специальных возможностей, параметры расписания и т. п.).

## 2. **Запустите сканирование**
{: id="2-run-a-quick-access-scan" }

- После завершения настройки нажмите круглую кнопку сканирования (значок лупы) в центре нижней панели главного экрана, чтобы запустить сканирование всей системы.
- SD Maid просканирует устройство на наличие мусорных файлов, остатков данных приложений, системного кэша и других ненужных файлов.

## 3. **Просмотрите результаты**
{: id="3-review-the-results" }

- После сканирования SD Maid распределит найденное по категориям:
  - **Приложения (AppCleaner)**: находит кэшированные и остаточные файлы приложений.
  - **Мусор (CorpseFinder)**: обнаруживает файлы удалённых приложений.
  - **Система (SystemCleaner)**: определяет системные файлы, которые можно удалить.

  Нажмите на каждый раздел, чтобы просмотреть подробности, и исключите файлы, которые хотите сохранить.

## 4. **Наведите порядок на устройстве**
{: id="4-tidy-your-device" }

- Просмотрев результаты, нажмите кнопку **Удалить**, чтобы удалить найденный мусор.

## 5. **Настройте расписание (необязательно)**
{: id="5-set-up-the-scheduler-optional" }

- Чтобы автоматизировать регулярные сканирования, используйте **Расписание (Scheduler)**.
- Нажмите значок **+**, чтобы создать расписание, и выберите, какие инструменты («Приложения», «Система» и т. д.) запускать через регулярные промежутки времени.

---

Теперь всё готово! Завершив настройку и выполнив эти шаги, вы сможете легко поддерживать порядок на устройстве с помощью SD Maid 2/SE.
