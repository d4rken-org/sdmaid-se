# Preguntas frecuentes
{: #frequently-asked-questions }

## ¿Puedo migrar de SD Maid a SD Maid SE?
{: #can-i-migrate-from-sd-maid-to-sd-maid-se }

Son dos aplicaciones distintas. Puedes importar exclusiones y filtros personalizados de SD Maid 1.

## Transferir el estado Pro desde SD Maid 1
{: #transfer-pro-status-from-sd-maid-1 }

SD Maid 2/SE es una aplicación independiente y las actualizaciones a Pro de SD Maid 1 no son transferibles.
Aunque me gustaría hacerlo, la economía de la aplicación no lo permite.
Aun así, 12 años de actualizaciones de SD Maid 1 por una única compra fue un trato bastante bueno, ¿no? 🙂 

## Uso el SD Maid normal, ¿cómo empiezo a usar SD Maid SE?
{: #im-using-regular-sd-maid-how-do-i-start-using-sd-maid-se }

Solo tienes que descargar SD Maid SE y seguir las instrucciones. SD Maid SE está disponible para Android 8.0+ (API26+).

## ¿Cuál es la diferencia entre SD Maid 1/Legacy y SD Maid 2/SE?
{: #what-is-the-difference-between-sd-maid-1legacy-and-sd-maid-2se }

* SD Maid 2/SE funciona mejor y da resultados más completos, sobre todo en las versiones más recientes de Android.
* Una interfaz nueva con temas.
* Más fácil de usar para quienes no son "usuarios avanzados", con mejor configuración y gestión de errores.
* SD Maid 2/SE recibirá actualizaciones y funciones nuevas, y se mantendrá al día con los cambios de las aplicaciones y de Android.
* SD Maid 1/Legacy pasará a modo de mantenimiento y se limitará a actualizaciones de seguridad.

## ¿Por qué estás creando SD Maid SE?
{: #why-are-you-creating-sd-maid-se }

[El SD Maid normal](https://play.google.com/store/apps/details?id=eu.thedarken.sdm) ha sufrido con todos los cambios de almacenamiento que Google ha introducido en las versiones más recientes de Android. Me cuesta mantenerlo funcionando bien en las versiones nuevas de Android sin romperlo en las antiguas. Al crear una aplicación nueva puedo aprovechar más de 10 años de experiencia sin tener que preocuparme por la compatibilidad con versiones anteriores. Borrón y cuenta nueva para recuperar la diversión que tenía trabajando en SD Maid. 

## ¿Por qué SD Maid SE no es una actualización del SD Maid normal?
{: #why-is-sd-maid-se-not-an-update-for-regular-sd-maid }

Hacer cambios importantes en [el SD Maid normal](https://play.google.com/store/apps/details?id=eu.thedarken.sdm) es imposible sin molestar a los usuarios. Quiero reescribir toda la aplicación y hacer cambios drásticos. Hacerlo en una aplicación existente es difícil y, además, no es algo que querría que otro desarrollador le hiciera a una de mis aplicaciones.

## ¿Por qué no puedo transferir SD Maid 1 Pro a SD Maid 2/SE?
{: #why-cant-i-transfer-sd-maid-1-pro-to-sd-maid-2se }

SD Maid 1 tuvo más de 10 años de actualizaciones; fue un trato bastante bueno.
Creo que es justo tener una nueva actualización a Pro para una aplicación nueva.
Tengo que poner el límite en algún sitio; si no, no será viable seguir con el desarrollo.
Nadie está obligado a cambiar. Si compraste SD Maid 1 Pro, sigues teniendo SD Maid 1 Pro y puedes usarlo. 

También hay algunos obstáculos técnicos. No es posible ver qué otras compras tiene el usuario en su cuenta.

## ¿Por qué faltan algunas funciones en SD Maid SE?
{: #why-are-some-features-missing-in-sd-maid-se }

SD Maid SE se centra en las funciones más populares del SD Maid normal para que la carga de trabajo sea asumible y el desarrollo siga siendo divertido. Creo que las aplicaciones deberían hacer solo unas pocas cosas, y hacerlas bien. El SD Maid normal sufrió un poco por acumular funciones al intentar contentar a demasiados usuarios. Funciones como el Explorador nunca fueron gran cosa en comparación con otras aplicaciones de exploración independientes. SD Maid no necesita competir en ese terreno.

## ¿Ha muerto el SD Maid normal?
{: #is-regular-sd-maid-dead }

No. Seguirá recibiendo parches de seguridad y algunas correcciones de errores, pero no funciones nuevas ni actualizaciones que mejoren la compatibilidad con nuevas versiones de Android.
Al principio, el SD Maid normal y SD Maid SE tendrán un rendimiento parecido y, con el tiempo, a medida que salgan nuevas versiones de Android, SD Maid SE superará al SD Maid normal en rendimiento, compatibilidad y funciones.

## ¿2 o SE?
{: id="2-or-se" }

`SD Maid 2/SE`, `SD Maid 2` y `SD Maid SE` son correctos. Interna y oficialmente, la aplicación se llama `SD Maid SE`.
Renombré la aplicación antigua como `SD Maid 1` y la nueva como `SD Maid 2/SE` para reducir la confusión y destacar que es su sucesora.

## ¿Qué significa SE en SD Maid SE?
{: #what-does-the-se-in-sd-maid-se-stand-for }

¿Qué significa `SD` en `SD Maid`? 🤷

## ¿Cómo puedo actualizar SD Maid 2/SE a Pro sin Google Play?
{: #how-can-i-upgrade-sd-maid-2se-without-google-play }

Además de la versión normal de SD Maid 2/SE, hay una versión `FOSS` disponible en GitHub y F-Droid; [consulta aquí](https://github.com/d4rken-org/sdmaid-se?tab=readme-ov-file#download).

La versión FOSS no tiene dependencias de Google y se puede actualizar a Pro mediante una donación voluntaria. Puedes donar lo que quieras, desde tan poco como quieras :frowning: hasta tanto como puedas :heart_eyes:. Actualmente no es una comprobación obligatoria y confía en ti igual que tú confías tus datos a SD Maid.

Actualmente no hay ninguna diferencia funcional entre la versión de Google Play y la versión `FOSS`, solo algunas pequeñas diferencias visuales.

## ¿Debería usar SD Maid 1 o 2?
{: #should-i-use-sd-maid-1-or-2 }

* Si tu dispositivo tiene Android 7 (API 25) o anterior: sigue usando SD Maid 1. 
* Si tu dispositivo tiene al menos Android 8 (API 26): podrías usar SD Maid 2/SE.
* Si tu dispositivo tiene Android 12 (API 32) o posterior: plantéate cambiar a SD Maid 2/SE.
* Si tu dispositivo tiene Android 14 (API 34): deberías usar SD Maid 2/SE.

# Usar SD Maid SE
{: #using-sd-maid-se }

## ¿Qué puedo hacer gratis y qué requiere la actualización a Pro?
{: #what-can-i-do-for-free-and-what-requires-the-upgrade }

Todas las herramientas de SD Maid SE pueden **escanear gratis**: puedes ver exactamente qué se limpiaría antes de decidir si actualizas a Pro.

**Funciones gratuitas:**
- Buscador de restos (CorpseFinder): escanear y eliminar restos de aplicaciones desinstaladas
- Limpiador del sistema (SystemCleaner): escanear y eliminar basura del sistema con los filtros incluidos
- Control de las aplicaciones (AppControl): ver y gestionar las aplicaciones instaladas
- Analizador del Almacenamiento (Analyzer): analizar el uso del almacenamiento y eliminar archivos

**Requiere la actualización a Pro:**
- Limpiador de aplicaciones (AppCleaner): eliminar cachés de aplicaciones y archivos prescindibles (escanear es gratis)
- Eliminar archivos duplicados (Deduplicator): eliminar archivos duplicados (escanear es gratis)
- Compresión y transcodificación de imágenes/videos (Media Squeeze): comprimir fotos y videos (escanear es gratis)
- Analizador del Almacenamiento: el gráfico de Tendencia de almacenamiento, el aviso de espacio bajo y la creación de filtros del Limpiador del sistema a partir del análisis
- Programador (Scheduler): activar la limpieza automática programada
- Swiper: archivos y sesiones ilimitados

La actualización a Pro está disponible como **compra única** o como **suscripción** en Google Play. La versión FOSS se puede desbloquear mediante una donación en GitHub Sponsors.

## ¿Por qué necesita SD Maid SE el servicio de accesibilidad y cómo soluciono los problemas con él?
{: #why-does-sd-maid-se-need-the-accessibility-service-and-how-do-i-fix-issues-with-it }

SD Maid SE usa el servicio de accesibilidad para automatizar la limpieza de cachés. En las versiones modernas de Android no hay ninguna API que permita a una aplicación borrar directamente la caché de otra. En su lugar, SD Maid SE va a la página de ajustes de cada aplicación y pulsa por ti el botón "Borrar caché"; para eso necesita el servicio de accesibilidad.

**Problemas frecuentes:**

*"El servicio de accesibilidad se desactiva una y otra vez"*
Algunos fabricantes (Xiaomi, Huawei, Samsung, OnePlus) restringen de forma agresiva los servicios en segundo plano. Puede que tengas que:
- Desactivar la optimización de batería para SD Maid SE
- Bloquear la aplicación en la lista de aplicaciones recientes
- Revisar los ajustes de "App Management" (gestión de aplicaciones) o "Auto-start" (inicio automático) de tu fabricante

*"No puedo activar el servicio de accesibilidad"*
En algunos dispositivos, el sistema bloquea el acceso de accesibilidad a las aplicaciones instaladas desde fuentes en las que no confía, o lo restringe por motivos de seguridad. Si instalaste desde Google Play y aun así no puedes activarlo, prueba a:
- Reiniciar el dispositivo
- Desinstalar y volver a instalar SD Maid SE
- Comprobar si la aplicación de seguridad de tu fabricante está bloqueando el permiso

Usar **Shizuku** o **ADB** como método de acceso alternativo evita por completo el servicio de accesibilidad y puede resolver estos problemas. Consulta la entrada de preguntas frecuentes sobre Shizuku más abajo para más detalles.

## ¿Qué es Shizuku y por qué lo recomienda SD Maid SE?
{: #what-is-shizuku-and-why-does-sd-maid-se-recommend-it }

[Shizuku](https://shizuku.rikka.app/) es una aplicación independiente de código abierto que permite a otras aplicaciones realizar operaciones con privilegios elevados sin acceso root. Usa la interfaz de depuración integrada de Android (ADB) para conceder estos permisos. [Porter](https://porter.darken.eu), un fork mantenido de Shizuku, funciona de la misma manera. Si ambos están instalados, SD Maid usa Porter. Consulta [Configuración: acceso ADB](/es/setup#shizuku).

SD Maid SE puede usar Shizuku para limpiar las cachés de las aplicaciones y acceder a los archivos de forma más completa que solo con el servicio de accesibilidad. Usar Shizuku es **opcional**, pero se recomienda porque es:
- **Más rápido**: no hace falta navegar por la interfaz de Ajustes para cada aplicación
- **Más fiable**: evita los problemas del servicio de accesibilidad en algunos dispositivos
- **Más completo**: puede acceder a datos a los que el método del servicio de accesibilidad no llega

**Cómo configurarlo:**
1. Instala [Shizuku desde Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) o desde [GitHub](https://github.com/RikkaApps/Shizuku)
2. Sigue las instrucciones integradas de Shizuku para iniciarlo (requiere un único comando ADB desde una computadora, o se puede iniciar de forma inalámbrica en Android 11+)
3. Abre SD Maid SE → Configuración → `Acceso ADB` → selecciona "Intenta usar acceso ADB"

**Nota:** Shizuku tiene que reiniciarse después de cada reinicio del dispositivo, salvo que uses el método de depuración inalámbrica en Android 11+.

## ¿Funciona SD Maid SE en Android 16?
{: #does-sd-maid-se-work-on-android-16 }

Android 16 introdujo cambios en cómo las aplicaciones pueden usar el servicio de accesibilidad y acceder al almacenamiento, lo que puede afectar al funcionamiento de SD Maid SE.

**Problemas conocidos en Android 16:**
- Algunos dispositivos impiden activar el servicio de accesibilidad para SD Maid SE
- Es posible que la limpieza de cachés mediante el servicio de accesibilidad no funcione o quede incompleta
- Las versiones de Android 16 de algunos fabricantes tienen restricciones adicionales

**Qué puedes hacer:**
- Usar **Shizuku** en lugar del servicio de accesibilidad: no le afectan estas restricciones
- Asegurarte de tener la **última versión** de SD Maid SE, ya que se publican correcciones de compatibilidad con regularidad
- Si usas una versión beta o preliminar de Android 16, cuenta con cierta inestabilidad: SD Maid SE está orientado a las versiones estables

SD Maid SE se mantiene activamente y las mejoras de compatibilidad con Android 16 continúan.

## ¿Por qué SD Maid SE es más lento que SD Maid 1?
{: #why-is-sd-maid-se-slower-than-sd-maid-1 }

Hay varios motivos por los que SD Maid SE es más lento:

**1. Ha cambiado el método para borrar la caché**
SD Maid 1 podía usar una API oculta del sistema para borrar todas las cachés de las aplicaciones con una sola llamada. Google eliminó el acceso a esta API en las versiones más recientes de Android. Ahora SD Maid SE tiene que usar métodos alternativos (servicio de accesibilidad, Shizuku o root), que son más lentos por naturaleza.

**2. Compatibilidad más amplia**
SD Maid SE está diseñado para funcionar con muchas versiones de Android y modelos de acceso al almacenamiento. Esta capa adicional de compatibilidad añade sobrecarga. SD Maid 1 estaba hiperoptimizado para escenarios concretos, pero esa optimización dejó de funcionar a medida que Android introducía cambios.

**3. Escaneo más exhaustivo**
SD Maid SE escanea de forma más exhaustiva que SD Maid 1, lo que significa que encuentra más cosas que limpiar, pero tarda más en hacerlo.

**Cómo acelerarlo:**
- **Shizuku / ADB**: bastante más rápido que el servicio de accesibilidad; puede borrar las cachés directamente sin navegar por la interfaz
- **Root**: el método más rápido; acceso directo al sistema de archivos

## ¿Cómo cancelo mi suscripción u obtengo un reembolso?
{: #how-do-i-cancel-my-subscription-or-get-a-refund }

Las suscripciones de SD Maid SE se gestionan a través de **Google Play**, no desde la propia aplicación. Desinstalar SD Maid SE **no** cancela tu suscripción.

**Para cancelar tu suscripción:**
1. Abre la aplicación Google Play Store
2. Toca el icono de tu perfil → Pagos y suscripciones → Suscripciones
3. Busca SD Maid 2/SE y toca "Cancelar suscripción"

**Para solicitar un reembolso:**
- Visita la [página de reembolsos de Google Play](https://play.google.com/store/account/orderhistory) en las 48 horas siguientes a la compra para obtener reembolsos automáticos
- Para compras más antiguas, contacta con el soporte de Google Play a través de Play Store

**Nota:** SD Maid SE también ofrece una opción de **compra única** si prefieres no gestionar una suscripción periódica.

## ¿Puede SD Maid SE eliminar archivos importantes?
{: #can-sd-maid-se-delete-important-files }

SD Maid SE está diseñado para dirigirse solo a datos prescindibles: cachés, archivos temporales y restos de aplicaciones desinstaladas. **No** elimina archivos personales como fotos, música o documentos, a menos que se lo indiques expresamente (p. ej., mediante el explorador de archivos del Analizador del Almacenamiento o con filtros personalizados del Limpiador del sistema).

Antes de cualquier eliminación, SD Maid SE te muestra exactamente qué se va a eliminar, para que puedas revisarlo y desmarcar elementos.

**Si quieres proteger archivos o carpetas concretos:**
- Mantén pulsado un elemento en los resultados del escaneo y elige "Excluir"
- O ve a Ajustes → Administrador de exclusiones para añadir rutas manualmente

Las exclusiones se mantienen entre escaneos e impiden que SD Maid SE toque nunca esos archivos.

**Consejo:** si no estás seguro, ejecuta primero un escaneo sin eliminar nada. Revisa los resultados para entender qué considera SD Maid SE prescindible en tu dispositivo.

## Mi antivirus dice que SD Maid SE es malicioso o contiene un virus
{: #my-antivirus-says-sd-maid-se-is-malicious-or-contains-a-virus }

Es un **falso positivo**. Si compruebas SD Maid SE en [VirusTotal](https://www.virustotal.com/), verás que la inmensa mayoría de los motores antivirus (normalmente más de 65 de 67) lo consideran limpio. Solo uno o dos motores pueden marcarlo con una etiqueta heurística genérica como "Evo-gen [Trj]".

**¿Por qué ocurre esto?**

SD Maid SE requiere permisos poco habituales para una aplicación normal, sobre todo el servicio de accesibilidad y un acceso amplio al almacenamiento. Algunos motores antivirus usan una detección heurística que marca como sospechosa cualquier aplicación que solicite estos permisos, sin importar lo que la aplicación haga realmente. Estos permisos son imprescindibles para que SD Maid SE funcione (p. ej., para automatizar la limpieza de cachés o escanear el almacenamiento).

**¿Qué debes hacer?**

Infórmalo como falso positivo desde tu aplicación antivirus. La mayoría de las aplicaciones antivirus tienen una opción para marcar una detección como incorrecta. Esto ayuda a mejorar la precisión de su detección para todos los usuarios.

**¿Puedes confiar en SD Maid SE?**

SD Maid SE tiene una [versión FOSS de código totalmente abierto](https://github.com/d4rken-org/sdmaid-se) con [compilaciones reproducibles](https://f-droid.org/en/docs/Reproducible_Builds/). Cualquiera puede auditar el código fuente y verificar de forma independiente que el APK publicado coincide con el código fuente. No hay nada oculto.

**Una nota sobre los antivirus y Android**

El modelo de seguridad integrado de Android ya ofrece una protección sólida mediante el aislamiento de aplicaciones (sandbox), el sistema de permisos y Google Play Protect. Las aplicaciones antivirus de terceros en Android tienen una eficacia limitada porque se ejecutan en el mismo sandbox que cualquier otra aplicación: no pueden inspeccionar a fondo otras aplicaciones como lo hace un antivirus de escritorio. Los falsos positivos en aplicaciones legítimas que usan permisos avanzados son un efecto secundario habitual de esta limitación.

Si aún tienes dudas o alguna preocupación, puedes escribir por correo a **support@darken.eu**.

## El Programador no se ejecuta automáticamente
{: #the-scheduler-doesnt-run-automatically }

El Programador necesita ciertas condiciones para funcionar de forma fiable:

**1. Requiere la actualización a Pro**
Activar programaciones es una función Pro. La versión gratuita permite crear programaciones, pero no activarlas.

**2. El servicio de accesibilidad o Shizuku deben estar activos**
Si tu programación incluye el Limpiador de aplicaciones, el servicio de accesibilidad (o Shizuku) tiene que estar en ejecución cuando se active la programación. Si el sistema cerró el servicio en segundo plano, la limpieza programada fallará.

**3. Optimización de batería**
Muchos fabricantes cierran de forma agresiva las aplicaciones en segundo plano. Para evitarlo:
- Desactiva la optimización de batería para SD Maid SE
- En Xiaomi/MIUI: activa "Auto-start" (inicio automático) y bloquea la aplicación en recientes
- En Huawei/EMUI: añade SD Maid SE a "Protected apps" (aplicaciones protegidas)
- En Samsung: exclúyela de "Sleeping apps" (aplicaciones en suspensión) y "Deep sleeping apps" (aplicaciones en suspensión profunda)
- En OnePlus: desactiva "Smart battery optimization" (optimización inteligente de la batería) para SD Maid SE

Para indicaciones específicas de cada fabricante, consulta [dontkillmyapp.com](https://dontkillmyapp.com/).

**4. Consentimiento para la automatización**
La primera vez que SD Maid SE ejecuta una tarea automatizada, necesita tu consentimiento para la automatización. Si no lo has concedido, las ejecuciones programadas se omitirán.
