# Tutorial de inicio rápido de SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

¡Te damos la bienvenida a SD Maid 2/SE! Sigue estos sencillos pasos para empezar:

## 1. **Instala y completa la configuración**
{: id="1-install-and-complete-setup" }

- Descarga e instala SD Maid 2/SE.
- Abre la aplicación y se te guiará por un proceso de **configuración inicial**.
  - Concede los permisos necesarios, como el **acceso al almacenamiento**, para que SD Maid pueda escanear y trabajar en tu dispositivo.
  - Completa los pasos de configuración adicionales, como activar funciones opcionales según tus preferencias (p. ej., el servicio de accesibilidad o las opciones de programación).

## 2. **Ejecuta un escaneo**
{: id="2-run-a-quick-access-scan" }

- Una vez completada la configuración, toca el botón redondo de escanear (icono de lupa) en el centro de la barra inferior del panel principal para iniciar un escaneo de todo el sistema.
- SD Maid escaneará tu dispositivo en busca de archivos basura, restos de datos de aplicaciones, cachés del sistema y otros archivos innecesarios.

## 3. **Revisa los resultados**
{: id="3-review-the-results" }

- Después del escaneo, SD Maid clasificará lo que haya encontrado:
  - **Limpiador de aplicaciones (AppCleaner)**: encuentra archivos de caché y archivos residuales de las aplicaciones.
  - **Buscador de restos (CorpseFinder)**: detecta archivos de aplicaciones desinstaladas.
  - **Limpiador del sistema (SystemCleaner)**: identifica archivos del sistema que se pueden eliminar.

  Toca cada sección para revisar los detalles y excluye los archivos que quieras conservar.

## 4. **Ordena tu dispositivo**
{: id="4-tidy-your-device" }

- Cuando hayas revisado los resultados, toca el botón **Borrar** para eliminar la basura detectada.

## 5. **Configura el Programador (opcional)**
{: id="5-set-up-the-scheduler-optional" }

- Para automatizar escaneos periódicos, usa el **Programador** (Scheduler).
- Toca el icono **+** para crear una programación y elige qué herramientas (Limpiador de aplicaciones, Limpiador del sistema, etc.) se ejecutarán a intervalos regulares.

---

¡Ya está todo listo! Si completas la configuración y sigues estos pasos, podrás mantener tu dispositivo ordenado fácilmente con SD Maid 2/SE.
