# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (también conocida como SD Maid 2) es una herramienta de gestión de archivos para Android especializada en el mantenimiento. Su objetivo principal es liberar espacio y eliminar datos no deseados.

* ¿Eres nuevo en SD Maid? Empieza con el [tutorial](/es/tutorial).
* ¿Necesitas ayuda para conceder acceso? Consulta [Configuración](/es/setup).
* ¿Tienes una pregunta? Revisa las [preguntas frecuentes](/es/faq) o pregunta en [Discord](https://discord.gg/8Fjy6PTfXu) o en [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* ¿Encontraste un error? En [Errores](/es/bugs) se explica cómo informar de él y grabar un registro de depuración.

## Herramientas
{: #tools }

* [Limpiador de aplicaciones (AppCleaner)](/es/appcleaner): elimina archivos prescindibles, p. ej., cachés
* [Buscador de restos (CorpseFinder)](/es/corpsefinder): elimina datos que pertenecen a aplicaciones que ya no están instaladas
* [Limpiador del sistema (SystemCleaner)](/es/systemcleaner): filtros configurables por el usuario para archivos de todo tipo
* [Analizador del Almacenamiento (StorageAnalyzer)](/es/storageanalyzer): resumen del almacenamiento
* [Eliminar archivos duplicados (Deduplicator)](/es/deduplicator): encuentra datos duplicados
* [Compresión y transcodificación de imágenes/videos (Media Squeeze)](/es/mediasqueeze): comprime fotos y videos
* [Swiper](/es/swiper): borrado asistido mediante deslizamientos
* [Control de las aplicaciones (AppControl)](/es/appcontrol): controla y desactiva aplicaciones
* [Programador (Scheduler)](/es/scheduler): programa acciones de limpieza
