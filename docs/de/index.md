# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (auch bekannt als SD Maid 2) ist ein Dateiverwaltungswerkzeug für Android, das auf Wartung spezialisiert ist. Sein Hauptzweck ist es, Speicherplatz freizugeben und unerwünschte Daten zu entfernen.

* Neu bei SD Maid? Beginne mit dem [Tutorial](/de/tutorial).
* Brauchst du Hilfe beim Gewähren von Zugriff? Siehe [Einrichtung](/de/setup).
* Hast du eine Frage? Sieh in die [FAQ](/de/faq) oder frag auf [Discord](https://discord.gg/8Fjy6PTfXu) oder in den [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Einen Fehler gefunden? Unter [Fehler](/de/bugs) steht, wie du ihn meldest und ein Debug-Protokoll aufzeichnest.

## Werkzeuge
{: #tools }

* [App-Reiniger (AppCleaner)](/de/appcleaner): löscht entbehrliche Dateien, z. B. Caches
* [Leichenfinder (CorpseFinder)](/de/corpsefinder): entfernt Daten, die zu Apps gehören, die nicht mehr installiert sind
* [System-Reiniger (SystemCleaner)](/de/systemcleaner): vom Nutzer konfigurierbare Filter für beliebige Dateien
* [Speicheranalyse (StorageAnalyzer)](/de/storageanalyzer): Speicherübersicht
* [Duplikat-Entferner (Deduplicator)](/de/deduplicator): findet doppelte Daten
* [Medienkomprimierung (Media Squeeze)](/de/mediasqueeze): komprimiert Fotos und Videos
* [Swiper](/de/swiper): Löschen per Wischgeste
* [App-Kontrolle (AppControl)](/de/appcontrol): steuert und deaktiviert Apps
* [Planer (Scheduler)](/de/scheduler): plant Reinigungsvorgänge
