# Tutorial Memulai Cepat SD Maid 2/SE
{: #quick-start-tutorial-for-sd-maid-2se }

Selamat datang di SD Maid 2/SE! Ikuti langkah-langkah sederhana ini untuk memulai:

## 1. **Pasang dan Selesaikan Penyiapan**
{: id="1-install-and-complete-setup" }

- Unduh dan pasang SD Maid 2/SE.
- Buka aplikasi, dan Anda akan dipandu melalui proses **penyiapan awal**.
  - Berikan izin yang diperlukan seperti **akses penyimpanan** agar SD Maid dapat memindai dan bekerja di perangkat Anda.
  - Selesaikan langkah penyiapan tambahan seperti mengaktifkan fitur opsional sesuai preferensi Anda (mis. layanan aksesibilitas, opsi penjadwalan).

## 2. **Jalankan Pemindaian**
{: id="2-run-a-quick-access-scan" }

- Setelah penyiapan selesai, ketuk tombol pindai bundar (ikon kaca pembesar) di tengah bilah bawah dasbor untuk memulai pemindaian seluruh sistem.
- SD Maid akan memindai perangkat Anda untuk mencari berkas sampah, sisa data aplikasi, cache sistem, dan berkas tidak perlu lainnya.

## 3. **Tinjau Hasilnya**
{: id="3-review-the-results" }

- Setelah pemindaian, SD Maid akan mengelompokkan temuan:
  - **Pembersih Aplikasi (AppCleaner)**: Menemukan berkas cache dan sisa berkas aplikasi.
  - **PencariMayat (CorpseFinder)**: Mendeteksi berkas dari aplikasi yang sudah dicopot.
  - **Pembersih Sistem (SystemCleaner)**: Mengidentifikasi berkas sistem yang dapat dihapus.

  Ketuk setiap bagian untuk meninjau detailnya, dan kecualikan berkas apa pun yang ingin Anda simpan.

## 4. **Rapikan Perangkat Anda**
{: id="4-tidy-your-device" }

- Setelah Anda meninjau hasilnya, ketuk tombol **Hapus** untuk menghapus sampah yang terdeteksi.

## 5. **Siapkan Penjadwal (Opsional)**
{: id="5-set-up-the-scheduler-optional" }

- Untuk mengotomatiskan pemindaian rutin, gunakan **Penjadwal (Scheduler)**.
- Ketuk ikon **+** untuk membuat jadwal, lalu pilih alat mana (Pembersih Aplikasi, Pembersih Sistem, dll.) yang dijalankan secara berkala.

---

Sekarang semuanya siap! Dengan menyelesaikan penyiapan dan mengikuti langkah-langkah ini, Anda dapat dengan mudah menjaga perangkat tetap rapi menggunakan SD Maid 2/SE.
