# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE (alias SD Maid 2) adalah alat pengelola berkas untuk Android yang berfokus pada pemeliharaan. Tujuan utamanya adalah mengosongkan ruang penyimpanan dan menghapus data yang tidak diinginkan.

* Baru mengenal SD Maid? Mulailah dengan [tutorial](/id/tutorial).
* Butuh bantuan memberikan akses? Lihat [Penyiapan](/id/setup).
* Punya pertanyaan? Periksa [FAQ](/id/faq), atau tanyakan di [Discord](https://discord.gg/8Fjy6PTfXu) atau di [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Menemukan bug? Lihat [Bug](/id/bugs) untuk cara melaporkannya dan merekam catatan debug.

## Alat
{: #tools }

* [Pembersih Aplikasi (AppCleaner)](/id/appcleaner): menghapus berkas yang tidak diperlukan, mis. cache
* [PencariMayat (CorpseFinder)](/id/corpsefinder): menghapus data milik aplikasi yang sudah tidak terpasang
* [Pembersih Sistem (SystemCleaner)](/id/systemcleaner): filter yang dapat diatur pengguna untuk berbagai berkas
* [Penganalisis Penyimpanan (StorageAnalyzer)](/id/storageanalyzer): ikhtisar penyimpanan
* [Penghapus Duplikat (Deduplicator)](/id/deduplicator): menemukan data duplikat
* [Optimasi Media (Media Squeeze)](/id/mediasqueeze): mengompres foto dan video
* [Pemilah (Swiper)](/id/swiper): penghapusan dengan bantuan usapan
* [Pengendali Aplikasi (AppControl)](/id/appcontrol): mengendalikan dan menonaktifkan aplikasi
* [Penjadwal (Scheduler)](/id/scheduler): menjadwalkan tindakan pembersihan
