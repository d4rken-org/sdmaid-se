# SD Maid 2/SE
{: #sd-maid-2se }

SD Maid SE（又名 SD Maid 2）是一款专注于系统维护的 Android 文件管理工具。它的核心用途是释放存储空间并清除不需要的数据。

* 第一次使用 SD Maid？请从[教程](/zh-hans/tutorial)开始。
* 需要帮助授予访问权限？请参阅[设置](/zh-hans/setup)。
* 有疑问？请查看[常见问题](/zh-hans/faq)，或在 [Discord](https://discord.gg/8Fjy6PTfXu) 或 [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions) 中提问。
* 发现了错误？请参阅[错误](/zh-hans/bugs)，了解如何报告错误以及如何记录调试日志。

## 工具
{: #tools }

* [应用清理（AppCleaner）](/zh-hans/appcleaner)：删除可舍弃的文件，例如缓存
* [卸载残留（CorpseFinder）](/zh-hans/corpsefinder)：清除属于已卸载应用的数据
* [系统清理（SystemCleaner）](/zh-hans/systemcleaner)：可由用户配置的过滤器，用于清理各类零散文件
* [存储分析器（StorageAnalyzer）](/zh-hans/storageanalyzer)：存储空间概览
* [去重工具（Deduplicator）](/zh-hans/deduplicator)：查找重复数据
* [媒体压缩（Media Squeeze）](/zh-hans/mediasqueeze)：压缩照片和视频
* [Swiper](/zh-hans/swiper)：通过滑动辅助删除
* [应用控制（AppControl）](/zh-hans/appcontrol)：管理和停用应用
* [计划任务（Scheduler）](/zh-hans/scheduler)：定时执行清理操作
