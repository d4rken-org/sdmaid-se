# 存储分析器（Storage Analyzer）
{: #storage-analyzer }

存储分析器（StorageAnalyzer）回答的问题是：“我的存储空间到底被什么占满了？”

它看起来像一个文件浏览器，但它并不是文件浏览器。所有内容都按大小排序，因此您可以顺着最大的项目一路往下，找到真正占满存储空间的东西。

## 存储
{: #storages }

第一个界面会显示您设备上的每个存储：

* **内部存储**（Primary storage）：设备的内置存储，包括应用和系统数据。
* **外部存储**（Secondary storage）：通常是可移动的 SD 卡。
* **便携式存储**（Portable storage）：例如通过 USB 连接的闪存盘。

每张卡片都会显示可用空间和已用空间，以及该存储在过去 7 天内的变化量，请参阅[存储趋势](#storage-trend)。

## 类别
{: #categories }

打开某个存储会对其进行扫描，并将已用空间划分为以下类别：

* **应用**：已安装的应用，包括其代码、数据、缓存和媒体。
* **用户文件**：照片、视频、下载内容以及其他不属于特定应用的数据。
* **系统数据**：操作系统，以及所有无法归入其他类别的内容。
* **其他用户**：此设备上其他用户或工作资料的应用和文件。

只有内部存储才有“系统数据”和“其他用户”。

### 应用
{: #apps }

应用按大小排序，并可按名称搜索。系统应用也可以在这里列出，包括其数据。对于没有安装更新的系统应用，内置的应用代码计入系统数据。打开一个应用可以查看其空间的去向：

* **应用代码**：应用本身。卸载或归档该应用可以释放这部分空间。
* **应用数据**：数据、设置和缓存。
* **应用媒体**：该应用的媒体文件，例如接收到的 WhatsApp 照片。
* **额外应用文件**：应用存放在其自身文件夹之外的数据，例如顶层文件夹中的照片或下载内容。

`显示设置`会打开该应用的系统设置页面。

### 为什么数字与 Android 设置中的不一致
{: #why-the-numbers-dont-match-androids-settings }

分析器的类别不会与 Android 设置中的分类完全一致。

**系统数据**是已用空间在计入应用、用户文件和其他用户之后剩余的部分。SD Maid 无法看到或无法归类的任何内容都会归入这里：受保护的系统区域、无法测量的其他用户存储、文件系统开销，以及存储标称容量与实际容量之间的差值。

如果没有[应用列表](/zh-hans/setup#app-inventory)和[使用情况](/zh-hans/setup#usage-statistics)权限，就无法测量应用的大小。这时它们所占的空间会显示为系统数据。

## 访问权限
{: #access }

分析器能看到哪些内容，取决于 SD Maid 拥有的访问权限：

* **没有 root 时**，应用代码和私有应用数据只显示总量，无法进一步浏览。在 Android 13 及更高版本上，`Android/data` 也需要 root 或 ADB 访问权限。
* **拥有 [root](/zh-hans/setup#root-access) 或 [ADB 访问权限](/zh-hans/setup#shizuku)时**，您可以浏览系统数据。root 还允许浏览应用代码和私有应用数据，并完整测量其他用户。
* **没有应用列表权限时**，文件无法与其所属的应用相对应。此时用户文件以只读方式显示：您可以看到大小，但删除、排除、创建过滤器和 Swiper 会话等功能都会被停用。

对于 SD Maid 无法访问的项目，点按后会显示`无法直接访问`。

包含超过 100,000 个项目的文件夹只会统计总量，无法浏览。

## 操作
{: #actions }

点按文件可在其他应用中打开它。长按项目以选择它们，然后：

* **删除**：确认后删除所选项目。可免费使用。
* **排除**：为所选路径创建[排除项](/zh-hans/exclusions)。这些排除项适用于所有工具。分析器本身不使用排除项，因为它需要看到所有内容才能计算出正确的总量。
* **过滤器**：为所选项目创建一个[系统清理自定义过滤器](/zh-hans/systemcleaner#custom-filters)。需要升级。
* **创建 Swiper 会话**：使用所选项目开始一个 [Swiper](/zh-hans/swiper) 会话。

系统数据和其他用户的内容只能浏览，无法在其中删除。

## 存储趋势
{: #storage-trend }

SD Maid 每隔几小时以及每次清理后都会记录存储的可用空间。`存储趋势`会以图表形式显示这些数据，并标注每次清理释放了多少空间。

* 存储卡片会显示每个存储在过去 7 天内的变化量。
* 控制面板会显示所有存储的总变化量；当存储空间正在被填满时，则改为显示预计剩余天数。
* 快照的保留时长在`设置 > 历史 > 存储历史记录`中设置。默认为 90 天，最长 365 天。

存储趋势图表需要升级。存储卡片和控制面板上的 7 天变化量以及剩余天数估算是免费的。

## 设置
{: #settings }

### 低存储阈值
{: #low-storage-threshold }

当可用空间低于此值时，SD Maid 会认为该存储即将耗尽。默认为`自动`：存储容量的 5%，最多 2 GB。

### 低空间警告
{: #low-space-warning }

需要升级。当内部存储的可用空间达到低存储阈值时发出警告。如果有至少 5 天连贯的历史记录，它还可以更早地发出警告：当存储预计会在 14 天内达到阈值，且可用空间已不超过存储容量的 20%（上限为 25 GB）时。默认关闭。
