# Swiper
{: #swiper }

Swiper 能帮您比文件管理器更快地整理特定文件夹。您逐个浏览文件，并通过滑动决定保留、删除或跳过每个文件。在您检查并确认自己的选择之前，不会删除任何内容。

## 开始会话
{: #starting-a-session }

1. 从控制面板打开 Swiper，然后点按`选择文件夹`。您可以选择文件夹、单个文件，或两者兼有。
2. 您还可以在会话卡片上设置文件类型过滤器和排序方式（可选）。
3. 点按`扫描`。搜索文件夹时会包括其所有子文件夹。
4. 点按`开始滑动`。

您也可以从[存储分析器](/zh-hans/storageanalyzer)创建会话：在其中选择项目，然后选择`创建 Swiper 会话`。

相机胶卷、下载文件夹和屏幕截图都是不错的起点。

### 文件类型
{: #file-types }

`仅显示这些文件类型`可将会话限制为图片、视频、音频、文档或压缩包。您也可以输入自己的扩展名，例如 `apk, apks`。如果没有勾选任何类型，则会显示所有文件。文件仅按扩展名进行匹配。

### 排序方式
{: #sort-order }

默认情况下，文件会根据最后修改日期按最旧优先显示。您也可以按最新优先、名称或最大优先进行排序。

扫描找到文件后，过滤器和排序方式就无法再更改。如需更改，请开始一个新会话。

### 扫描整个存储
{: #scanning-a-whole-storage }

如果您选择存储的顶层（例如整个内部存储），那么其中的每个文件都会进入会话，包括照片和应用媒体。SD Maid 会在扫描前要求您确认。之后从这类会话中删除文件时，您必须先勾选`我明白这些文件将被永久删除。`。

## 滑动
{: #swiping }

| 手势 | 默认操作 |
|---|---|
| 向右滑动 | 保留 |
| 向左滑动 | 删除 |
| 向上滑动 | 跳过 |
| 向下滑动 | 撤销上一个决定 |

底部的按钮具有相同的作用。启用[交换滑动方向](#swap-swipe-directions)后，左右方向会互换。

* **跳过**会让文件保持未决定状态。被跳过的文件会在其余文件处理完后再次出现。
* **撤销**会逐步撤回您最近的决定，最多 50 个。
* **长按“跳过”**可将文件从以后的 Swiper 扫描中排除。这会创建一个路径[排除项](/zh-hans/exclusions)，并将该文件从会话中移除。
* 卡片上的按钮可以在其他应用中打开文件，或显示全屏预览。
* 点按缩略图条中的缩略图可跳转到该文件。再次滑动它会替换您之前的决定。

您可以随时离开。您的决定会随会话一起保存，之后可以继续。SD Maid 重新启动时，已找不到的文件会从会话中移除。在此之前，会话中可能仍会列出已被其他程序删除或移动的文件。

## 检查并删除
{: #reviewing-and-deleting }

点按`评论`（Review）可查看所有决定。当没有未决定的文件时，检查界面会自动打开。

* 可以逐个文件更改决定，也可以长按以同时选择多个文件。
* 点按某个文件可跳回到该文件。
* 在执行任何操作之前，`删除`会显示受影响的文件数量、空间大小以及所在的文件夹。

删除是永久性的。文件不会被移到回收站文件夹，SD Maid 也无法恢复它们。

删除后，已保留和已删除的文件会离开会话。未决定的文件会留待以后处理。当没有剩余文件时，会话将被移除。如果某些文件无法删除，它们会留在会话中，您可以再试一次。

移除会话只会丢弃您的决定，不会触及任何文件。

### 注意事项
{: #things-to-know }

* **“保留”只对当前会话有效。**如果您对同一文件夹开始新的会话，已保留的文件会再次出现。要永久隐藏某个文件，请将其排除（长按“跳过”）。
* **会话不会收录新文件。**扫描后添加到文件夹中的文件不会出现。要包含它们，请开始新的会话。
* **压缩包包括 APK 文件。**
* **包括隐藏文件。**

## 免费版
{: #free-version }

未升级时，Swiper 最多只能有 2 个会话，每个会话最多 50 个文件。如果设置了排序方式，您会得到按该顺序排列的前 50 个文件。

## 设置
{: #settings }

### 交换滑动方向
{: #swap-swipe-directions }

向左滑动保留，向右滑动删除。默认关闭。

### 显示文件详情
{: #show-file-details }

在滑动界面上显示文件名、大小、日期和所在文件夹。默认开启。

### 触觉反馈
{: #haptic-feedback }

在您保留或删除文件时振动。默认开启。
