# 常见问题
{: #frequently-asked-questions }

## 我可以从 SD Maid 迁移到 SD Maid SE 吗？
{: #can-i-migrate-from-sd-maid-to-sd-maid-se }

这是两个独立的应用。您可以从 SD Maid 1 导入排除项和自定义过滤器。

## 从 SD Maid 1 转移专业版状态
{: #transfer-pro-status-from-sd-maid-1 }

SD Maid 2/SE 是一个独立的应用，SD Maid 1 的专业版升级无法转移。
虽然我很想这样做，但应用的经济状况不允许。
不过，一次性购买就享受了 12 年的 SD Maid 1 更新，这已经很划算了，不是吗？🙂 

## 我在使用普通版 SD Maid，如何开始使用 SD Maid SE？
{: #im-using-regular-sd-maid-how-do-i-start-using-sd-maid-se }

只需下载 SD Maid SE 并按照说明操作即可。SD Maid SE 适用于 Android 8.0 及以上版本（API26+）。

## SD Maid 1/Legacy 和 SD Maid 2/SE 有什么区别？
{: #what-is-the-difference-between-sd-maid-1legacy-and-sd-maid-2se }

* SD Maid 2/SE 性能更好，结果更彻底，尤其是在较新的 Android 版本上。
* 带有主题的全新界面。
* 对非“高级用户”来说更易于使用，设置流程和错误处理也更完善。
* SD Maid 2/SE 将持续获得更新和新功能，并跟上应用和 Android 的变化。
* SD Maid 1/Legacy 将进入维护模式，仅提供安全更新。

## 为什么要开发 SD Maid SE？
{: #why-are-you-creating-sd-maid-se }

[普通版 SD Maid](https://play.google.com/store/apps/details?id=eu.thedarken.sdm) 深受 Google 在新版 Android 中引入的各种存储变更之苦。我很难让它在新版 Android 上保持良好运行，同时又不破坏它在旧版本上的表现。通过开发一个新应用，我可以充分利用 10 多年的经验，而不必担心向后兼容的问题。一切从头开始，重新找回我开发 SD Maid 时的乐趣。 

## 为什么 SD Maid SE 不是普通版 SD Maid 的一次更新？
{: #why-is-sd-maid-se-not-an-update-for-regular-sd-maid }

对[普通版 SD Maid](https://play.google.com/store/apps/details?id=eu.thedarken.sdm) 做任何重大改动，都不可能不让用户不满。我想重写整个应用并进行大刀阔斧的改动。对一个现有应用这样做既困难，我也不希望别的开发者对我的应用这样做。

## 为什么我不能把 SD Maid 1 Pro 转移到 SD Maid 2/SE
{: #why-cant-i-transfer-sd-maid-1-pro-to-sd-maid-2se }

SD Maid 1 获得了 10 多年的更新，这已经相当划算了。
我认为为一个新应用推出新的专业版升级是公平的。
我必须在某个地方划清界限，否则就无法继续开发下去。
没有人被强迫切换。如果您购买了 SD Maid 1 Pro，您仍然拥有 SD Maid 1 Pro 并可以继续使用。 

此外还有一些技术障碍。应用无法查看用户账号中还有哪些其他购买记录。

## 为什么 SD Maid SE 缺少一些功能？
{: #why-are-some-features-missing-in-sd-maid-se }

SD Maid SE 专注于普通版 SD Maid 最受欢迎的功能，以便让工作量保持在可维护的范围内，并保持开发的乐趣。我认为应用应该只做少数几件事，并把它们做好。普通版 SD Maid 在一定程度上受到了功能膨胀的影响，因为我试图满足太多用户的需求。像文件浏览器（Explorer）这样的功能，与其他独立的文件浏览器应用相比从来都不算出色。SD Maid 没有必要在这方面与它们竞争。

## 普通版 SD Maid 已经停止维护了吗？
{: #is-regular-sd-maid-dead }

没有。它仍会获得安全补丁和一些错误修复，但不会再有新功能，也不会再有提升新版 Android 兼容性的更新。
一开始，普通版 SD Maid 和 SD Maid SE 的表现会差不多；随着时间推移和新版 Android 的发布，SD Maid SE 将在性能、兼容性和功能上超越普通版 SD Maid。

## 2 还是 SE？
{: id="2-or-se" }

`SD Maid 2/SE`、`SD Maid 2` 和 `SD Maid SE` 都可以。在内部以及官方场合，该应用的名称是 `SD Maid SE`。
我将旧应用重命名为 `SD Maid 1`，将新应用命名为 `SD Maid 2/SE`，以减少混淆并强调两者的承继关系。

## 如何在没有 Google Play 的情况下升级 SD Maid 2/SE？
{: #how-can-i-upgrade-sd-maid-2se-without-google-play }

除了 SD Maid 2/SE 的普通版本外，还有一个可通过 GitHub 和 F-Droid 获取的 `FOSS` 版本，[请参阅此处](https://github.com/d4rken-org/sdmaid-se?tab=readme-ov-file#download)。

FOSS 版本不依赖任何 Google 组件，可以通过自愿捐赠来升级。您可以随意捐赠任意金额，从您想给的最少金额 :frowning: 到您能给的最多金额 :heart_eyes: 都可以。目前这并不是强制检查，而是信任您，就像您信任 SD Maid 处理您的数据一样。

目前 Google Play 版本和 `FOSS` 版本在功能上没有区别，只有一些细微的视觉差异。

## 我应该使用 SD Maid 1 还是 2？
{: #should-i-use-sd-maid-1-or-2 }

* 如果您的设备运行 Android 7（API 25）或更早版本：请继续使用 SD Maid 1。 
* 如果您的设备运行 Android 8（API 26）或更高版本：您可以使用 SD Maid 2/SE。
* 如果您的设备运行 Android 12（API 32）或更高版本：请考虑切换到 SD Maid 2/SE。
* 如果您的设备运行 Android 14（API 34）：您应该使用 SD Maid 2/SE。

# 使用 SD Maid SE
{: #using-sd-maid-se }

## 哪些功能可以免费使用，哪些需要升级？
{: #what-can-i-do-for-free-and-what-requires-the-upgrade }

SD Maid SE 中的所有工具都可以**免费扫描**：在决定是否升级之前，您可以确切地看到会清理哪些内容。

**免费功能：**
- 卸载残留（CorpseFinder）：扫描并删除已卸载应用的残留
- 系统清理（SystemCleaner）：使用内置过滤器扫描并删除系统垃圾
- 应用控制（AppControl）：查看和管理已安装的应用
- 存储分析器（Analyzer）：分析存储使用情况并删除文件

**需要升级的功能：**
- 应用清理（AppCleaner）：删除应用缓存和可舍弃的文件（扫描免费）
- 去重工具（Deduplicator）：删除重复文件（扫描免费）
- 媒体压缩（Media Squeeze）：压缩照片和视频（扫描免费）
- 存储分析器：存储趋势图表、低空间警告，以及根据分析结果创建系统清理过滤器
- 计划任务（Scheduler）：启用定时自动清理
- Swiper：不限文件数量和会话数量

在 Google Play 上，升级可以通过**一次性购买**或**订阅**获得。FOSS 版本可以通过 GitHub Sponsors 捐赠解锁。

## 为什么 SD Maid SE 需要无障碍服务？如何解决与之相关的问题？
{: #why-does-sd-maid-se-need-the-accessibility-service-and-how-do-i-fix-issues-with-it }

SD Maid SE 使用无障碍服务来自动清理缓存。在现代 Android 系统上，没有任何 API 允许应用直接清除其他应用的缓存。因此，SD Maid SE 会替您打开每个应用的设置页面并点按“清除缓存”按钮，这就需要无障碍服务。

**常见问题：**

*“无障碍服务总是自动关闭”*
一些厂商（小米、华为、三星、一加）会严格限制后台服务。您可能需要：
- 为 SD Maid SE 停用电池优化
- 在最近使用的应用列表中锁定该应用
- 检查厂商提供的“App Management”（应用管理）或“Auto-start”（自启动）设置

*“我无法启用无障碍服务”*
在某些设备上，系统会阻止从其不信任的来源安装的应用获取无障碍访问权限，或出于安全原因对其加以限制。如果您是从 Google Play 安装的，但仍然无法启用，请尝试：
- 重新启动设备
- 卸载并重新安装 SD Maid SE
- 检查厂商的安全应用是否阻止了该权限

使用 **Shizuku** 或 **ADB** 作为替代的访问方式可以完全绕开无障碍服务，从而解决这些问题。更多详情请参阅下方关于 Shizuku 的常见问题条目。

## 什么是 Shizuku？为什么 SD Maid SE 推荐使用它？
{: #what-is-shizuku-and-why-does-sd-maid-se-recommend-it }

[Shizuku](https://shizuku.rikka.app/) 是一个独立的开源应用，可让其他应用在没有 root 权限的情况下执行需要更高权限的操作。它利用 Android 内置的调试接口（ADB）来授予这些权限。[Porter](https://porter.darken.eu) 是 Shizuku 的一个持续维护的分支，工作方式相同。如果两者都已安装，SD Maid 会使用 Porter。请参阅[设置：ADB 访问权限](/zh-hans/setup#shizuku)。

与仅使用无障碍服务相比，SD Maid SE 可以借助 Shizuku 更彻底地清理应用缓存和访问文件。使用 Shizuku 是**可选的**，但推荐使用，因为它：
- **更快**：无需逐个应用地操作设置界面
- **更可靠**：避免了某些设备上无障碍服务的问题
- **更彻底**：可以访问无障碍服务方式无法触及的数据

**设置方法：**
1. 从 [Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) 或 [GitHub](https://github.com/RikkaApps/Shizuku) 安装 Shizuku
2. 按照 Shizuku 内置的说明启动它（需要在电脑上执行一次 ADB 命令；在 Android 11 及以上版本上也可以通过无线方式启动）
3. 打开 SD Maid SE → 设置 → `ADB 访问权限` → 选择“尝试使用 ADB 访问权限”

**注意：**除非您在 Android 11 及以上版本上使用无线调试方式，否则每次设备重启后都需要重新启动 Shizuku。

## SD Maid SE 能在 Android 16 上运行吗？
{: #does-sd-maid-se-work-on-android-16 }

Android 16 对应用使用无障碍服务和访问存储的方式做出了更改，这可能会影响 SD Maid SE 的功能。

**Android 16 上的已知问题：**
- 某些设备会阻止为 SD Maid SE 启用无障碍服务
- 通过无障碍服务清理缓存可能无法工作，或清理不完整
- 某些厂商的 Android 16 版本有额外的限制

**您可以这样做：**
- 使用 **Shizuku** 代替无障碍服务：它不受这些限制的影响
- 确保您运行的是 SD Maid SE 的**最新版本**，因为兼容性修复会定期发布
- 如果您使用的是 Android 16 的测试版/预览版，请预料到可能会不稳定：SD Maid SE 的目标是稳定版本

SD Maid SE 一直在积极维护中，针对 Android 16 的兼容性改进也在持续进行。

## 为什么 SD Maid SE 比 SD Maid 1 慢？
{: #why-is-sd-maid-se-slower-than-sd-maid-1 }

SD Maid SE 较慢有以下几个原因：

**1. 缓存清理方式发生了变化**
SD Maid 1 可以使用一个隐藏的系统 API，一次调用即可清除所有应用缓存。Google 在新版 Android 中移除了对该 API 的访问。SD Maid SE 现在必须使用其他方式（无障碍服务、Shizuku 或 root），而这些方式本身就更慢。

**2. 更广泛的兼容性**
SD Maid SE 旨在兼容众多 Android 版本和存储访问模型。这层额外的兼容性会带来开销。SD Maid 1 针对特定场景做了极致优化，但随着 Android 不断变化，这些优化逐渐失效。

**3. 更彻底的扫描**
SD Maid SE 的扫描比 SD Maid 1 更彻底，这意味着它能找到更多可清理的内容，但所需时间也更长。

**加快速度：**
- **Shizuku / ADB**：比无障碍服务快得多，可以直接清除缓存，无需操作界面
- **Root**：最快的方式，可直接访问文件系统

## 如何取消订阅或申请退款？
{: #how-do-i-cancel-my-subscription-or-get-a-refund }

SD Maid SE 的订阅通过 **Google Play** 管理，而不是通过应用本身。卸载 SD Maid SE **不会**取消您的订阅。

**取消订阅：**
1. 打开 Google Play 商店应用
2. 点按您的个人资料图标 → 付款和订阅 → 订阅
3. 找到 SD Maid 2/SE，然后点按“取消订阅”

**申请退款：**
- 在购买后 48 小时内访问 [Google Play 的退款页面](https://play.google.com/store/account/orderhistory)，即可自动退款
- 对于更早的购买，请通过 Play 商店联系 Google Play 支持团队

**注意：**如果您不想管理定期订阅，SD Maid SE 也提供**一次性购买**选项。

## SD Maid SE 会删除重要文件吗？
{: #can-sd-maid-se-delete-important-files }

SD Maid SE 的设计目标仅限于可舍弃的数据：缓存、临时文件以及已卸载应用的残留。除非您明确要求（例如通过存储分析器的文件浏览器或自定义的系统清理过滤器），否则它**不会**删除照片、音乐或文档等个人文件。

在执行任何删除之前，SD Maid SE 都会准确地向您显示将要删除的内容，以便您检查并取消选择某些项目。

**如果您想保护特定的文件或文件夹：**
- 在扫描结果中长按某个项目，然后选择“排除”
- 或前往 设置 → 管理排除项，手动添加路径

排除项在每次扫描中都会保持有效，并确保 SD Maid SE 永远不会触碰这些文件。

**提示：**如果您不确定，可以先运行一次扫描而不删除任何内容。查看结果，了解 SD Maid SE 认为您设备上的哪些内容是可舍弃的。

## 我的杀毒软件说 SD Maid SE 是恶意软件或含有病毒
{: #my-antivirus-says-sd-maid-se-is-malicious-or-contains-a-virus }

这是**误报**。如果您在 [VirusTotal](https://www.virustotal.com/) 上检查 SD Maid SE，就会发现绝大多数杀毒引擎（通常 67 个中有 65 个以上）都报告它是安全的。只有一两个引擎可能会用“Evo-gen [Trj]”之类的通用启发式标签标记它。

**为什么会出现这种情况？**

SD Maid SE 需要一些对普通应用来说不常见的权限，最主要的是无障碍服务和广泛的存储访问权限。一些杀毒引擎使用启发式检测，会将任何请求这些权限的应用标记为可疑，而不管该应用实际做了什么。这些权限对于 SD Maid SE 正常工作至关重要（例如自动清理缓存、扫描存储）。

**您应该怎么做？**

在您的杀毒应用中将其报告为误报。大多数杀毒应用都有将检测结果标记为错误的选项。这有助于为所有用户提高检测准确性。

**SD Maid SE 值得信任吗？**

SD Maid SE 拥有完全[开源的 FOSS 版本](https://github.com/d4rken-org/sdmaid-se)，并支持[可复现构建](https://f-droid.org/en/docs/Reproducible_Builds/)。任何人都可以审查源代码，并独立验证发布的 APK 与源代码一致。没有任何隐藏的内容。

**关于杀毒应用和 Android**

Android 内置的安全模型已经通过应用沙盒、权限系统和 Google Play 保护机制提供了强有力的保护。Android 上的第三方杀毒应用效果有限，因为它们与其他所有应用运行在同一个沙盒中：它们无法像桌面杀毒软件那样深入检查其他应用。使用高级权限的正规应用遭到误报，是这一局限性的常见副作用。

如果您仍然不确定或有任何疑虑，欢迎发送电子邮件至 **support@darken.eu** 与我联系。

## 计划任务不会自动运行
{: #the-scheduler-doesnt-run-automatically }

计划任务需要满足特定条件才能可靠运行：

**1. 需要升级**
启用计划是专业版功能。免费版允许您创建计划，但不能激活它们。

**2. 无障碍服务或 Shizuku 必须处于活动状态**
如果您的计划包含应用清理，那么在计划触发时，无障碍服务（或 Shizuku）需要正在运行。如果系统在后台终止了该服务，计划的清理就会失败。

**3. 电池优化**
许多厂商会严格地终止后台应用。为避免这种情况：
- 为 SD Maid SE 停用电池优化
- 在小米/MIUI 上：启用“Auto-start”（自启动），并在最近任务中锁定该应用
- 在华为/EMUI 上：将 SD Maid SE 添加到“Protected apps”（受保护应用）
- 在三星上：将其从“Sleeping apps”（休眠应用）和“Deep sleeping apps”（深度休眠应用）中排除
- 在一加上：为 SD Maid SE 停用“Smart battery optimization”（智能电池优化）

有关各厂商的具体指导，请参阅 [dontkillmyapp.com](https://dontkillmyapp.com/)。

**4. 自动化授权**
SD Maid SE 第一次运行自动化任务时，需要您授权进行自动化操作。如果您尚未授权，计划的运行将被跳过。
