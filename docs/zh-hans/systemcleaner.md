# 系统清理（System Cleaner）
{: #system-cleaner }

系统清理（SystemCleaner）工具本质上是一个通用搜索引擎。它会遍历所有可访问的存储，并将找到的文件和文件夹与一组过滤器进行匹配。

与卸载残留（CorpseFinder）或应用清理（AppCleaner）等其他工具不同，它并不了解已安装的应用。它完全基于文件路径和属性工作。因此，只有路径排除项和分段排除项才能应用于系统清理。

找到的每个文件都会依次经过已启用的过滤器，并归属于第一个匹配的过滤器。

## 设置
{: #settings }

### 通用过滤器
{: #general-filters }

通用过滤器会**在所有可访问的存储区域中**搜索可能出现在设备任何位置的特定文件类型。

| 过滤器 | 说明 |
|--------|-------------|
| **空文件夹** | 设备各处的空文件夹。嵌套的文件夹可能需要多次扫描。 |
| **截图** | 来自多个应用和位置、早于可配置时间的截图。 |
| **回收站文件** | 各种应用和位置的回收站中已标记为删除但尚未被永久移除的文件。 |
| **过时的安装包** | 版本早于或等于已安装应用版本的安装文件（APK）。 |
| **LOST.DIR 文件夹** | 在 Android 设备之间传输数据时创建的临时文件。 |
| **Linux 文件** | 将存储连接到 Linux 计算机时创建的文件和文件夹。 |
| **Mac 文件** | 使用 Apple 的 Finder 应用浏览存储时创建的文件和文件夹（例如 `.DS_Store`）。 |
| **Windows 文件** | Windows 文件资源管理器可能在已连接的存储上创建的数据（例如 `Thumbs.db`）。 |
| **略缩图** | 图片和视频的缓存预览（例如 `.thumbnails` 文件夹）。 |
| **临时系统文件** | 与系统相关的临时文件，通常是正在进行的操作所使用的短期缓存。 |
| **分析文件** | 与分析统计和错误跟踪相关的数据。 |
| **广告文件** | 为广告创建或由广告创建的文件。 |
| **系统日志文件** | 各个位置中的系统及系统服务日志文件（例如 `*.log`）。 |

### 特定过滤器
{: #specific-filters }

特定过滤器针对设备上存储特定类型数据的**固定、已知路径**。

| 过滤器 | 说明 |
|--------|-------------|
| **系统崩溃残留文件** | 如果原生进程（例如游戏）崩溃，会在这里创建“tombstone”文件。 |
| **使用情况统计信息** | 与应用使用情况统计相关的文件。 |
| **ANR 报错** | 来自“应用无响应”（Application Not Responding）事件的跟踪记录。 |
| **本地临时文件** | 与系统相关的临时文件（例如来自 Android Studio 的文件）。 |
| **系统日志文件（datalogger）** | 特定于系统服务的日志文件。 |
| **下载缓存** | 用于多种用途（例如 OTA 更新）的系统缓存文件夹。 |
| **日志投递箱** | 供系统存放日志文件的区域。 |
| **安装器缓存** | 系统软件包管理所使用的、与已安装应用相关的缓存数据。 |
| **最近任务** | 与系统任务切换器中的任务历史相关的数据。 |

### 自定义过滤器
{: #custom-filters }

除了应用提供的通用过滤器外，您还可以使用自己的条件创建自定义过滤器。自定义过滤器可以在**设置 > 系统清理 > 管理自定义过滤器**中创建。

> **警告**：自定义过滤器可能有风险。删除之前请务必检查扫描结果！

#### 可用条件
{: #available-criteria }

| 条件 | 说明 |
|-----------|-------------|
| **过滤标签** | 过滤器的名称 |
| **数据区域** | 要扫描的存储位置（留空则扫描所有可访问的区域） |
| **文件类型限制** | 目标为文件、文件夹或符号链接（留空则全部包括） |
| **路径筛选规则** | 用于匹配文件路径的规则 |
| **排除列表** | 不参与匹配的路径 |
| **名称筛选条件** | 用于匹配文件名的规则 |
| **最小大小** | 只匹配大于此大小的文件 |
| **最大大小** | 只匹配小于此大小的文件 |
| **最小时间** | 只匹配早于此时间的文件 |
| **最大时间** | 只匹配晚于此时间的文件 |
| **Path Regex**（路径正则表达式） | 高级：用于匹配路径的正则表达式 |

#### 路径匹配模式
{: #path-criteria-modes }

| 模式 | 说明 | 示例 |
|------|-------------|---------|
| **以关键词开始的路径** | 路径以关键词开头 | `Downloads/temp` 匹配 `/sdcard/Downloads/temp/file.txt` |
| **包含关键词的路径** | 路径包含关键词 | `cache` 匹配 `/sdcard/app/cache/data.bin` |
| **以关键词结尾的路径** | 路径以关键词结尾 | `backup/old` 匹配 `/sdcard/backup/old` |
| **关键词与路径匹配** | 路径与关键词完全相同 | `Download/temp` 只匹配这一确切路径 |

#### 文件名比较模式
{: #name-criteria-modes }

| 模式 | 说明 | 示例 |
|------|-------------|---------|
| **以关键词开始的文件名** | 文件名以关键词开头 | `temp_` 匹配 `temp_file.txt` |
| **包含关键词的文件名** | 文件名包含关键词 | `.bak` 匹配 `document.bak.old` |
| **以关键词结尾的文件名** | 文件名以关键词结尾 | `.tmp` 匹配 `cache.tmp` |
| **关键词与文件名匹配** | 文件名完全相同 | `thumbs.db` 只匹配 `thumbs.db` |

默认情况下，所有匹配都**不区分大小写**。

#### 数据区域
{: #data-areas }

您可以选择的常见区域：

| 区域 | 说明 |
|------|-------------|
| **SDCARD** | 主存储（内部存储或 SD 卡） |
| **PUBLIC_MEDIA** | 媒体文件夹（DCIM、Pictures、Music 等） |
| **PUBLIC_DATA** | 共享的应用数据 |
| **PRIVATE_DATA** | 应用私有存储（需要 root） |
| **DOWNLOAD_CACHE** | 系统下载缓存（需要 root） |
| **PORTABLE** | 可移动存储（USB/microSD） |

#### 提示
{: #tips }

- **性能**：只定义必要的条件。正则表达式过多会降低扫描速度。
- **多个条件**：所有指定的条件都必须匹配（AND 逻辑）。
- **长按**：长按条目可获得更多选项。
- **测试**：在启用删除之前，先使用扫描预览。
- **导入/导出**：过滤器可以导出并与其他用户分享。

#### 已弃用的选项
{: #deprecated-options }

SD Maid 1 中的 `rootOnly` 选项**已不再可用**。请改用**数据区域**来控制要扫描哪些存储位置。
