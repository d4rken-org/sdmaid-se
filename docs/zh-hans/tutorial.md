# SD Maid 2/SE 快速入门教程
{: #quick-start-tutorial-for-sd-maid-2se }

欢迎使用 SD Maid 2/SE！按照以下简单步骤即可开始使用：

## 1. **安装并完成设置**
{: id="1-install-and-complete-setup" }

- 下载并安装 SD Maid 2/SE。
- 打开应用后，系统会引导您完成**初始设置**流程。
  - 授予所需权限，例如**存储访问权限**，以便 SD Maid 能够扫描您的设备并对其进行操作。
  - 根据您的偏好完成其他设置步骤，例如启用可选功能（如无障碍服务、计划选项）。

## 2. **运行扫描**
{: id="2-run-a-quick-access-scan" }

- 设置完成后，点按控制面板底部栏中间的圆形扫描按钮（放大镜图标）以开始全系统扫描。
- SD Maid 会扫描您的设备，查找垃圾文件、应用残留数据、系统缓存以及其他不需要的文件。

## 3. **查看结果**
{: id="3-review-the-results" }

- 扫描结束后，SD Maid 会对发现的内容进行分类：
  - **应用清理（AppCleaner）**：查找应用的缓存文件和残余文件。
  - **卸载残留（CorpseFinder）**：检测已卸载应用留下的文件。
  - **系统清理（SystemCleaner）**：识别可以删除的系统文件。

  点按各个部分即可查看详情，并排除您想保留的任何文件。

## 4. **整理您的设备**
{: id="4-tidy-your-device" }

- 查看完结果后，点按**删除**按钮即可清除检测到的垃圾。

## 5. **设置计划任务（可选）**
{: id="5-set-up-the-scheduler-optional" }

- 如需自动定期扫描，请使用**计划任务（Scheduler）**。
- 点按 **+** 图标创建一个计划，并选择要定期运行的工具（应用清理、系统清理等）。

---

一切就绪！完成设置并按照上述步骤操作后，您就可以轻松地使用 SD Maid 2/SE 让设备保持整洁。
