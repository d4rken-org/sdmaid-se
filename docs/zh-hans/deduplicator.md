# 去重工具（Deduplicator）
{: #deduplicator }

去重工具（Deduplicator）会查找您设备上的重复文件：完全相同的副本，以及（可选）看起来或听起来相似的图片、视频或音频。它会将这些文件归入多个集合，并删除每个集合中除一个文件之外的所有文件。

扫描是免费的。删除需要升级。

## 检测方法
{: #detection-methods }

您可以在`设置 > 去重工具`中启用各个检测方法。

### 内容校验和
{: #content-checksum }

默认开启。查找内容逐字节完全相同的文件，与文件名无关。这是最安全的方法：这类集合中的每个文件都是真正的副本。

### 感知哈希
{: #perceptual-hash }

默认关闭。查找看起来相似的图片，例如以不同格式或尺寸保存的同一张照片，或稍作编辑的照片。图片会以灰度方式进行比较，因此仅颜色不同的图片也可能被匹配。

### 媒体指纹
{: #media-fingerprint }

默认关闭。查找听起来相似的视频和音频文件，以及看起来相似的无声视频。只会比较时长大致相同的文件。

相似的文件并不完全相同。连拍照片、编辑过的版本或调整过尺寸的副本都可能被归入同一个集合。**在删除通过感知哈希或媒体指纹找到的集合之前，请先检查它们。**每个相似文件都会显示其匹配程度。

## 扫描范围
{: #what-gets-scanned }

默认情况下，去重工具会搜索所有可访问的存储：内部存储、SD 卡、USB 存储、`Android/data` 和 `Android/media`。不包括 `Android/obb`。您可以在[搜索位置](#search-locations)中限制搜索范围。

在 Android 13 及更高版本上，访问 `Android/data` 需要 [root](/zh-hans/setup#root-access) 或 [ADB 访问权限](/zh-hans/setup#shizuku)。

只有大于[最小文件大小](#minimum-size)的文件才会被纳入考虑。默认情况下只包含常见文件类型，请参阅[跳过不常见的文件类型](#skip-uncommon-file-types)。

## 保留哪个文件
{: #which-file-is-kept }

删除一个集合时，SD Maid 会保留一个文件并删除其余文件。保留哪一个由`设置 > 去重工具 > 删除策略`中的删除策略决定。

SD Maid 会按顺序检查每条规则。第一条能决出明确胜者的规则即为决定性规则。拖动规则可以调整顺序，点按规则可以更改其模式。

| 规则 | 默认 |
|---|---|
| 重复类型 | 优先保留完全相同的文件，而非相似文件 |
| 偏好位置 | 保留您所选文件夹中的文件。默认未设置任何文件夹。 |
| 媒体索引 | 保留图库和其他媒体应用已知的文件 |
| 存储位置 | 保留内部存储上的文件。SD 卡和 USB 存储视为外部存储。 |
| 文件夹深度 | 保留浅层文件夹中的文件 |
| 修改日期 | 保留较旧的文件 |
| 文件大小 | 保留较大的文件 |

**偏好位置**会与其他规则一起，帮助决定在一个组内保留哪个文件。它不会在组与组之间做选择。如果一个集合中既有完全相同的副本，也有相似文件，则由“重复类型”决定保留哪一组：默认情况下，相似组中的每个文件都会被删除，即使它位于偏好位置中。例如，如果您用相机拍摄的照片和来自某个通讯应用的两份完全相同、经过缩放的副本被归入同一个集合，默认设置会保留其中一份通讯应用副本，并删除相机拍摄的原图。在删除这类集合之前请先检查，并[排除](/zh-hans/exclusions)那些其中文件绝不能被删除的文件夹。

无法将某个单独的文件标记为要保留的文件。要保留其他文件，请更改删除策略，或自行选择要删除的文件。

更改删除策略会丢弃当前结果。更改之后请重新扫描。

## 删除
{: #deleting }

### 删除整个集合
{: #deleting-a-whole-set }

删除一个集合会保留一个文件，并删除**该集合中的所有其他文件**。在包含相似文件的集合中，这也包括那些与保留文件只是相似、并不完全相同的文件。

将结果列表切换为列表布局后，删除整个集合时会被删除的每个文件上都会显示一个删除图标。默认的网格布局不会显示这些图标。

### 删除单个文件
{: #deleting-individual-files }

长按选择文件，然后删除它们。每个集合中至少要保留一个文件，除非您启用了[使“全部删除”成为可能](#make-delete-all-possible)。

在集合详情中，`文件夹`视图会按文件夹对文件进行分组。在这里删除一个文件夹，会删除该文件夹中的重复文件。如果该文件夹包含某个集合的所有文件，那么删除整个集合时会被保留的那个文件将不会被删除。启用[使“全部删除”成为可能](#make-delete-all-possible)后，确认对话框会允许您将它们全部删除。

### 从控制面板删除
{: #deleting-from-the-dashboard }

从去重工具的控制面板卡片中删除，会在确认后删除每个集合中除一个文件之外的所有文件。控制面板的主按钮是否也会运行去重工具，在[一键操作](#one-tap)中设置。

## 排除项
{: #exclusions }

被去重工具排除或被全局排除的路径不会被扫描。从结果中排除一个集合，会排除其中的每个文件，包括原本会被保留的那个文件。请参阅[排除项](/zh-hans/exclusions)。

去重工具无法由[计划任务](/zh-hans/scheduler)运行。

## 一键操作
{: #one-tap }

`设置 > 常规 > 一键模式执行的操作`决定控制面板的主按钮、`扫描 + 删除`快捷方式以及小部件是否包含去重工具。默认关闭。快捷方式和小部件会按照您的删除策略直接扫描并删除，不会进行确认。在控制面板上，`一键执行模式`的作用相同，但如果已有结果等待处理，“删除”仍会先询问。只有在[内容校验和](#content-checksum)是唯一的检测方法时，才应将去重工具包含在内。

## 设置
{: #settings }

### 搜索位置
{: #search-locations }

要搜索的文件夹。默认为所有可访问的区域。长按可将其重置。

### 删除策略
{: #deletion-strategy }

决定保留集合中的哪个文件，请参阅[保留哪个文件](#which-file-is-kept)。

### 使“全部删除”成为可能
{: #make-delete-all-possible }

显示可删除集合中所有文件的选项，这样不会留下任何副本。默认关闭。

### 最小文件大小
{: #minimum-size }

跳过小于此大小的文件。默认为 512 KB。

### 跳过不常见的文件类型
{: #skip-uncommon-file-types }

只包含常见的图片、视频、音频文件、文档、压缩包和 APK 文件。默认开启。文件类型由文件扩展名决定。

### 检测方法
{: #detection-method }

启用[内容校验和](#content-checksum)、[感知哈希](#perceptual-hash)和[媒体指纹](#media-fingerprint)。
