# 统计与历史
{: #stats-and-history }

SD Maid 2/SE 会记录清理过程中删除的文件数量以及释放的总空间。这样，用户就可以随时了解清理操作的长期效果。

<img src="/assets/images/stats/overview-1.webp" width="150">
<img src="/assets/images/stats/overview-2.webp" width="150">

## 主要功能：
{: #key-features }

- **已删除文件和已释放空间**：SD Maid 会记录每次清理中删除的文件总数以及释放的存储空间大小。
  
- **操作历史**：您可以查看已执行操作的历史记录，其中显示受影响的文件数量、释放的空间大小，以及操作是否成功或是否出错。

- **详细日志**：每个清理任务都在**历史**（Stats）部分提供详细日志，可帮助用户了解清理了哪些内容，并发现潜在问题。

要使用此功能，请前往 SD Maid 2/SE 中的**历史**部分。
