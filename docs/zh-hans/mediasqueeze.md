# 媒体压缩（Media Squeeze）
{: #media-squeeze }

媒体压缩（Media Squeeze）会压缩照片和视频，让它们占用更少的空间。您用一部分画质换回存储空间。

**压缩会永久降低质量，且无法撤销。**原始文件会被替换，不会保留任何副本。开始之前，请检查您的设置和预览。

扫描是免费的。压缩需要升级。

## 工作原理
{: #how-it-works }

1. 选择要搜索的文件夹。没有默认位置，例如可以选择您的相机文件夹。
2. 设置压缩质量和最短时间。
3. 扫描。每个结果都会显示其大小和预计节省的空间。
4. 点按单个项目，长按以选择多个项目，或使用`全部压缩`。确认对话框会先显示总大小和预计节省的空间。

如果所选内容只包含照片或只包含视频，确认对话框中的`查看对比`会并排显示原始版本和压缩后的版本。对于视频，对比的只是单个画面，仅供参考。

### 文件会发生什么变化
{: #what-happens-to-a-file }

* 文件会以其原有格式重新编码：JPEG 仍为 JPEG，WebP 仍为 WebP，MP4 仍为 MP4。
* 图片分辨率保持不变，[超大照片](#compress-very-large-photos)除外。
* 对于视频，只有视频轨道会以较低的比特率重新编码。音频轨道会原样复制。
* 照片的日期、位置、相机以及其他 EXIF 元数据都会保留。如果 SD Maid 无法读取或保留某张照片的 EXIF 元数据，就不会改动这张照片。
* XMP 元数据不会保留，例如照片球和全景照片信息，或照片编辑器中的评分。
* 文件的修改日期会保留，因此图库仍会将其排在原来的位置。
* 如果压缩后的版本没有变小，原始文件将保持不变。

预计节省的空间是根据文件类型和质量粗略估算的，并非实际测量结果。实际节省的空间可能有所不同。

### 位置
{: #locations }

媒体压缩需要直接访问文件，并对其所在文件夹拥有写入权限。它不使用 root 或 ADB。通过 Android 文件夹选择器选取的某些位置（例如 USB 驱动器）无法使用，会从所选内容中移除。

## 之前压缩过的文件
{: #previously-compressed-files }

SD Maid 会记住它已经压缩过的文件，以及压缩后没有变小的文件，并在之后的扫描中跳过它们。它通过文件内容来识别文件，因此即使文件被重命名或移动过，这一机制依然有效。再次压缩一个文件会进一步损失质量，而节省的空间却很少。

这份历史记录保存在您的设备上，并且是 SD Maid 设置备份的一部分。清除历史记录后，之前压缩过的文件将重新符合压缩条件，除非这些文件带有 EXIF 标记且已启用[写入 EXIF 标记](#write-exif-marker)。清除历史记录不会更改任何文件。

## 默认跳过的照片
{: #photos-that-are-skipped-by-default }

有些照片包含压缩无法保留的数据。如果 SD Maid 检测到这类数据，就会跳过这些照片，除非您启用了相应的设置。检测并不完全：对于它无法识别的格式，照片会被压缩并丢失这些数据。

* **HDR 照片和深度照片**：HDR 照片会变成普通照片，人像照片会丢失背景虚化所依赖的数据。
* **动态照片**（Motion Photos）：保留静态图像，删除视频片段。
* **超大照片**（宽度或高度达到或超过 8192 像素）：其宽度和高度会减半，必要时再次减半，直到两者都小于 8192 像素。一张宽 20,000 像素的全景照片最终宽度为 5,000 像素。

包含多张图像的 HEIC 文件总是会被跳过。

扫描摘要会统计因 HDR 或深度数据、动态照片和超大尺寸而被跳过的照片，以及无法访问的文件。因之前已压缩过而被跳过的文件不计入统计；多图像 HEIC 文件也不计入，除非它们同时带有 HDR 或深度数据。

## 设置
{: #settings }

压缩质量、搜索位置和最短时间需要在扫描前于媒体压缩界面中设置。其他所有设置都位于`设置 > 媒体压缩`中。

### 压缩质量
{: #compression-quality }

默认值为 80。质量越低，文件越小，但视觉质量也越低。低于 40 时，图片可能无法使用。在 95 及以上时，几乎节省不了多少空间。

### 最短时间
{: #minimum-age }

只包含比此时间更早的文件。默认为 90 天，以文件的修改日期为准。

### 最小文件大小
{: #minimum-file-size }

跳过小于此大小的文件。默认为 512 KB。

### JPEG
{: #jpeg }

包含 JPEG 图片（`.jpg`、`.jpeg`）。默认开启。

### WebP
{: #webp }

包含 WebP 图片（`.webp`）。默认开启。动态 WebP 文件无法被识别，压缩后会丢失动画。

### HEIC/HEIF
{: #heicheif }

包含 HEIC/HEIF 图片（`.heic`、`.heif`）。默认关闭。需要 Android 9 或更高版本。对于 HEIC，HDR 增益图、深度数据以及实况/动态照片（Live/Motion Photo）部分都无法保留。

### MP4 视频
{: #mp4-video }

包含 MP4 视频（`.mp4`）。默认关闭。压缩一个视频需要在同一存储上有约为其大小 110% 的可用空间。

### 压缩 HDR&深度照片
{: #compress-hdr--depth-photos }

请参阅[默认跳过的照片](#photos-that-are-skipped-by-default)。默认关闭。

### 压缩动态照片
{: #compress-motion-photos }

保留静态图像，删除视频片段。默认关闭。

### 压缩超大照片
{: #compress-very-large-photos }

包含宽度或高度达到或超过 8192 像素的照片，并降低其分辨率，请参阅[默认跳过的照片](#photos-that-are-skipped-by-default)。默认关闭。

### 跳过已压缩的图片
{: #skip-previously-compressed }

跳过 SD Maid 已经压缩过的文件。默认开启。

### 写入 EXIF 标记
{: #write-exif-marker }

在照片的 EXIF 用户备注中添加一个标记，这样即使压缩历史已被清除，SD Maid 也能识别出它已被压缩。只有启用此设置时，SD Maid 才会检查该标记。默认关闭。仅适用于 JPEG 和 WebP。

### 压缩历史
{: #compression-history }

显示历史记录中有多少个文件。点按即可清除历史记录。

## 排除项
{: #exclusions }

媒体压缩会跳过被全局[排除](/zh-hans/exclusions)的路径。您也可以从结果列表中排除结果，这只会影响媒体压缩。

媒体压缩无法由[计划任务](/zh-hans/scheduler)运行。
