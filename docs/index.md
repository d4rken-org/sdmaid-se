# SD Maid 2/SE

SD Maid SE (AKA SD Maid 2) is a file management tool for Android that specialises in maintenance. Its core purpose is freeing up space and removing unwanted data.

* New to SD Maid? Start with the [tutorial](/tutorial).
* Need help granting access? See [Setup](/setup).
* Have a question? Check the [FAQ](/faq), or ask on [Discord](https://discord.gg/8Fjy6PTfXu) or in [GitHub Discussions](https://github.com/d4rken-org/sdmaid-se/discussions).
* Found a bug? See [Bugs](/bugs) for how to report it and record a debug log.

## Tools

* [AppCleaner](/appcleaner): deletes expendable files, e.g. caches
* [CorpseFinder](/corpsefinder): removes data that belongs to apps that are no longer installed
* [SystemCleaner](/systemcleaner): user configurable filters for random files
* [StorageAnalyzer](/storageanalyzer): storage overview
* [Deduplicator](/deduplicator): finds duplicate data
* [Media Squeeze](/mediasqueeze): compresses photos and videos
* [Swiper](/swiper): swipe assisted deletion
* [AppControl](/appcontrol): controls and disables apps
* [Scheduler](/scheduler): schedules cleaning actions
