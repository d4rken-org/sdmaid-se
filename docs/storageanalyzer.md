# Storage Analyzer

The storage analyzer, as the name indicates, analyzes your storage.

It may look like a file browser, but it is not a file browser.

It's goal is to answer "What takes up so much space on my XYZ storage?"

You can browse your device, separated by individual storage hardware your device contains.
